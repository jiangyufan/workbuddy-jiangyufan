## 一、案件管理与流程协同类。
痛点：案件信息散落在微信聊天记录、邮件、文件夹和脑子里，期限遗漏、任务遗漏是悬在每个律师头上的达摩克利斯之剑。

TOOL 01。案件全景工作台。

功能简介：以时间轴+看板双视图展示案件全生命周期，集成待办提醒、里程碑追踪、关联文档一键跳转，解决案件信息散落在多个文件中的痛点。

使用方法：登录后进入仪表盘，创建案件卡片并设置关键节点（立案、举证期限、开庭等），系统自动推送到期提醒，支持拖拽调整案件状态。

技术方案：Vue3 + Pinia状态管理 + Element Plus。关键技术点：响应式看板布局、基于WebSocket的实时提醒推送、拖拽排序交互。TOOL 02。举证期限倒计时器。

功能简介：可视化展示所有在办案件的各类法定期限（举证、上诉、申请执行等），支持自定义提醒规则，避免因遗漏期限造成不可逆后果。

使用方法：录入案件后自动根据案由计算各类期限，以日历热力图形式呈现紧急程度，点击日期可跳转至对应案件详情页。

技术方案：React + FullCalendar日历组件 + Ant Design。关键技术点：日期计算引擎、日历热力图渲染、多层级提醒策略配置。TOOL 03。庭审准备清单生成器。

功能简介：根据案件类型自动生成庭审准备checklist（证据原件核对、授权委托书、代理词打印等），支持逐项勾选和团队分工。

技术方案：Next.js + TailwindCSS + localStorage持久化。关键技术点：模板引擎动态渲染、本地存储与云端同步、PDF导出打印适配。TOOL 04。案件冲突检索系统。

功能简介：新建案件时自动检索所内已有案件库，检测是否存在利益冲突（同一案件原被告代理、关联公司代理等），生成冲突报告。

使用方法：输入当事人名称后系统模糊匹配历史案件数据，高亮显示潜在冲突项，支持人工确认排除或标记回避。技术方案：Vue3 + Elasticsearch前端集成 + ECharts。关键技术点：模糊搜索与高亮匹配、冲突关系图谱可视化、数据脱敏展示。

TOOL 05。跨团队协作空间。功能简介：为多律师协作的复杂案件提供共享工作区，支持任务分配、进度同步、文件版本管理和内部讨论。

使用方法：创建案件协作空间后邀请成员加入，通过看板分配任务（如A律师负责证据整理、B律师负责法律检索），所有操作实时同步。

技术方案：React + Socket.IO + Quill富文本编辑器。关键技术点：实时协同编辑（OT算法）、权限分级控制、操作日志审计追踪。

## 二、法律文书与智能写作类。
LEGAL DRAFTING。痛点：80%的律师每天花3小时以上在文书工作上，而其中至少一半是「换个名字改个数」的重复劳动。TOOL 06。智能合同审查助手。

功能简介：上传合同文本后自动标注风险条款（违约金过高、管辖权不利、保密义务缺失等），提供修改建议和替代条款。

使用方法：拖拽上传Word/PDF合同，系统逐条扫描并高亮风险点，点击标注可查看风险等级和修改建议，支持一键替换为推荐条款。

技术方案：React + Monaco Editor + 自定义标注组件。关键技术点：文本差异对比算法、富文本行内标注渲染、条款匹配与推荐引擎。TOOL 07。起诉状/答辩状模板工厂。

功能简介：内置数百种案由对应的文书模板，用户填写案件要素（当事人信息、诉讼请求、事实理由）后自动生成格式规范的文书。

使用方法：选择案由后进入分步表单，逐步填写当事人、诉求、事实等字段，系统自动套用法律术语并生成文书，支持在线编辑微调后导出。

技术方案：Vue3 + FormKit表单引擎 + docxtemplater。关键技术点：动态表单联动、Word文档模板填充引擎、法律术语自动替换。TOOL 08。法律意见书生成器。

功能简介：输入客户问题和事实背景，系统自动检索相关法条和判例，生成结构化的法律意见书初稿（含事实概述、法律分析、结论建议）。

使用方法：在结构化表单中录入咨询问题和关键事实，系统调用后端AI生成分析框架，律师在富文本编辑器中修改完善后导出正式文档。

技术方案：Next.js + TipTap富文本编辑器 + Markdown渲染。关键技术点：结构化内容生成、法条引用自动格式化、文档版本对比。TOOL 09。合同条款对比工具。

功能简介：上传两份合同（如我方版本与对方修改版），逐条对比差异，高亮新增、删除和修改的内容，生成对比报告。

使用方法：上传两份文档后系统自动对齐条款结构，以红绿标注差异内容，支持逐条接受/拒绝修改，最终生成对比摘要报告。

技术方案：React + diff-match-patch算法 + PDF.js。关键技术点：文本diff算法、条款结构对齐、双栏同步滚动对比。TOOL 10。裁判文书脱敏编辑器。

功能简介：对需要公开或存档的裁判文书自动识别并脱敏敏感信息（身份证号、银行账号、未成年人姓名等），支持自定义脱敏规则。

使用方法：粘贴文书内容后系统自动识别敏感信息并标红，律师可逐条确认脱敏方式（完全遮盖/部分遮盖/替换），一键生成脱敏版本。
