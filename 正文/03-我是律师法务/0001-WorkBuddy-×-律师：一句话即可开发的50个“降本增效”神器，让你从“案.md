LITIGATION · 诉讼业务。1 诉前评估计算器。功能简介。

输入案件基本事实（标的额、管辖地、案由），自动计算诉讼费、保全费、律师费参考区间、预估审理周期，生成《诉讼风险评估报告》。

- 选择案由→②填写标的额、当事人数量→③选择管辖法院→④一键生成评估报告PDF

技术方案。React + 诉讼费计算规则引擎 + jsPDF生成报告。关键技术点。动态表单联动、诉讼费阶梯算法、PDF导出（jsPDF/html2canvas）。2 证据链可视化构建器。将零散证据拖拽至时间轴，自动串联证据之间的逻辑关系，生成证据链图谱，辅助律师构建举证体系。

- 上传/录入证据清单→②拖拽至时间轴→③连线标注证据关联→④导出证据关系图

Vue3 + D3.js力导向图 + 拖拽交互（vuedraggable）。D3.js数据可视化、Canvas/SVG渲染、拖拽排序、图片预览。3 庭审对抗模拟器。输入己方主张和证据，AI模拟对方可能的抗辩点和法官提问，帮助律师做庭前预演。

- 输入案件摘要和己方观点→②选择案由模板→③系统生成对方抗辩清单和法官问题清单→④逐项准备应答

React + 大模型API调用 + Markdown渲染 + 对话式交互。LLM Prompt Engineering、流式输出（SSE）、Markdown实时渲染。4 法律文书智能排版器。将起诉状、答辩状、代理词等按法院格式要求一键排版，自动调整字体、行距、页边距、页码，支持多法院模板。

- 粘贴/导入文书文本→②选择目标法院模板→③一键排版→④预览并导出Word/PDF

Vue3 + contenteditable富文本 + docx.js导出 + 模板引擎。富文本编辑、Word文档生成（docx.js）、CSS打印样式、模板切换。5 案件进度看板。以看板形式管理所有在办案件的诉讼阶段（立案→送达→开庭→判决→执行），支持提醒和筛选。

- 新建案件卡片→②拖拽至对应阶段列→③设置关键日期提醒→④按案由/法院/紧急度筛选

React + 拖拽看板（react-beautiful-dnd）+ LocalStorage/IndexedDB持久化。

拖拽交互、IndexedDB本地存储、日期计算与提醒、响应式布局。6 阅卷笔录结构化录入器。针对刑事案件大量卷宗，提供结构化录入界面（按卷→册→页→内容），支持关键词标注和快速检索。

- 创建案件卷宗结构→②逐页录入/拍照OCR→③高亮标注关键内容→④全文检索定位

Vue3 + OCR API对接 + 虚拟滚动列表 + 全文检索（fuse.js）。虚拟列表渲染（万级数据）、模糊搜索、图片标注、分级树形结构。7 类案检索对比工具。输入案件关键要素，展示类案裁判要点对比表，标注与本案的异同，辅助撰写代理词中的类案引用。

- 输入案由+关键事实→②调用案例API获取类案→③自动生成对比表格→④导出引用段落

React + 表格组件（ag-grid）+ 案例API + 差异高亮算法。动态表格渲染、文本差异对比、API异步加载、导出功能。8 保全/执行申请生成器。根据案件信息自动生成财产保全申请书、强制执行申请书、执行异议书等格式化文书。

- 选择文书类型→②填写当事人信息、保全标的、财产线索→③预览→④一键导出Word

Vue3 + 表单引擎 + 模板字符串插值 + docx.js。动态表单校验、模板引擎、文件下载（Blob）、多模板切换。9 庭审发问提纲生成器。根据案件争议焦点，结构化生成对被告/证人/鉴定人的发问提纲，按逻辑递进排列。

- 输入争议焦点→②选择发问对象→③系统生成问题清单（含追问预案）→④编辑调整→⑤打印

React + 树形编辑器 + 打印CSS优化 + AI辅助生成。树形结构编辑、打印样式（打印CSS适配）、AI接口调用。10 上诉/申诉期限倒计时。录入判决日期和类型，自动计算上诉期、申诉期、执行申请期等法定期限，倒计时提醒。

- 录入判决/裁定日期→②选择文书类型→③自动计算各期限截止日→④浏览器通知提醒

Vue3 + 日期计算库（dayjs）+ Notification API + 日历视图。法定期限算法（含节假日扣除）、Web Notification、倒计时动画。11 质证意见模板生成器。针对对方证据清单，逐项生成“三性”（真实性、合法性、关联性）质证意见框架，律师只需补充具体理由。

- 导入/录入对方证据清单→②对每项证据选择质证方向→③生成质证意见初稿→④补充具体理由

React + 动态列表 + 模板插值 + 富文本编辑。动态增删表单项、条件渲染、富文本（TipTap/Quill）、批量操作。12 调解方案对比器。针对同一纠纷生成2-3种调解/和解方案，以表格对比各方案的金额、时间成本、执行风险。

- 输入纠纷基本信息→②设定各方案参数→③自动生成对比矩阵→④导出给客户选择

Vue3 + 对比表格组件 + 滑块交互 + 图表（ECharts）。多列对比布局、滑块动态计算、雷达图/柱状图可视化。

13 尽调清单生成器。根据交易类型（IPO/并购/投资）自动生成尽职调查资料清单，支持按行业定制，一键导出发送客户。

- 选择交易类型和行业→②勾选需要的调查模块→③自定义增删条目→④导出Excel/PDF发送

React + 树形多选组件 + Excel导出（SheetJS）+ 模板库。树形checkbox、SheetJS（xlsx）导出、模板CRUD、拖拽排序。14 合同审查红线标注器。上传合同文本，按条款类型（违约、管辖、知识产权等）高亮标注风险点，生成审查意见批注。

- 粘贴/上传合同文本→②选择审查维度→③系统高亮风险条款→④律师添加批注→⑤导出审查报告

Vue3 + 文本高亮引擎 + 侧边批注栏 + PDF导出。文本分段高亮（Range API）、批注锚点定位、PDF批注导出。15 合同版本对比工具。上传合同两个版本（如甲方版vs乙方修改版），自动逐条对比差异，红绿标注增删改。

- 上传V1和V2两份文档→②自动逐段对比→③红/绿/黄标注差异→④导出对比报告

React + diff算法（jsdiff）+ 并排/行内视图切换 + Word解析。文本diff算法、Word/PDF解析（mammoth.js）、并排滚动同步。16 交易结构图绘制器。拖拽式绘制股权架构、交易路径、资金流向图，支持多层嵌套，用于尽调报告和交易方案展示。

- 拖入节点（公司/个人/SPV）→②连线标注关系（持股/借款/担保）→③调整布局→④导出SVG/PNG

Vue3 + 流程图库（LogicFlow/AntV X6）+ 自定义节点。图形拖拽引擎、自定义节点渲染、SVG导出、自动布局算法。17 合规自查清单。按行业（互联网/金融/医疗/制造）生成合规自查表，逐项打勾评估，自动生成合规风险评级报告。

- 选择行业和规模→②逐项填写合规状态→③上传佐证材料→④生成雷达图评级报告

React + 动态问卷引擎 + ECharts雷达图 + PDF报告生成。动态表单生成、文件上传预览、评分算法、雷达图渲染。18 股权架构计算器。输入各轮融资金额和估值，自动计算各股东持股比例、稀释路径，模拟未来融资的稀释效果。

- 录入初始股权→②逐轮添加融资事件→③实时计算稀释后比例→④可视化股权饼图/桑基图

Vue3 + 实时计算引擎 + ECharts饼图/桑基图 + 场景模拟。股权稀释算法、多场景模拟、图表联动、滑块交互。19 NDA/标准合同快速生成器。选择合同类型（NDA/劳动合同/租赁/服务），填写关键条款，一键生成规范合同文本。

- 选择合同模板→②填写甲乙方信息、核心条款→③预览合同→④导出Word/PDF

React + 表单引擎 + 模板字符串 + 条款条件显示。条件渲染（不同条款组合）、表单校验、多格式导出。20 项目交割倒计时。针对并购/IPO项目，列出所有交割条件和先决事项，逐项确认完成状态，生成交割备忘录。

- 导入交割条件清单→②逐项标记完成/未完成→③上传完成凭证→④生成交割进度报告

Vue3 + 进度条组件 + 文件上传 + 甘特图（dhtmlx-gantt）。进度追踪、文件管理、甘特图渲染、状态机管理。21 监管政策追踪仪表盘。按行业订阅监管政策更新，以时间线+标签形式展示新规，标注对客户业务的影响等级。

- 设置关注行业和关键词→②系统聚合政策信息→③按影响等级筛选→④一键生成客户简报

React + RSS/API聚合 + 时间线组件 + 标签筛选。信息聚合与去重、时间线渲染、标签过滤、定时刷新。22 会议纪要智能整理器。商务谈判/项目会议后，粘贴录音转文字稿，自动提取决议事项、待办、责任人、截止日期。

- 粘贴会议文字记录→②AI提取结构化信息→③律师确认修改→④导出纪要并分配待办

23 商标近似检索模拟器。输入拟注册商标名称/图形描述，按尼斯分类初步评估近似风险，给出注册建议。

- 输入商标名称/描述→②选择尼斯分类→③系统展示近似规则分析→④生成风险评估

- 录入专利权利要求→②逐条填写对应技术特征→③标注相同/等同/不同→④导出对比表
