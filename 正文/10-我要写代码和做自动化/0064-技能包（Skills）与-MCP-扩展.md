# 技能包（Skills）与 MCP 扩展
**是什么：**WorkBuddy 内置 20+ 官方技能包，全部遵循 MCP 规范，并支持一键导入官方技能或零代码新建自定义技能。

**怎么操作：**

**一键导入官方技能：**从技能商店分类浏览、搜索并一键安装，安装后自动注册到 Agent 可用列表，支持版本更新与卸载。

**零代码新建技能：**填写技能基本信息（名称、图标、描述）→ 配置触发指令与参数规则 → 编写 Prompt 模板或绑定 MCP 工具 → 测试验证 → 发布上线，保存后即时生效并可分享给团队。

每个技能包包含"提示词模板 + 工具调用链 + 输出格式规范"，AI 自动识别任务类型并匹配合适技能包执行。

**适合场景：**热门技能包括视频速记、发票汇总、多语言翻译、海报生成；技能分类覆盖内容创作、翻译润色、代码助手、会议纪要、数据分析、流程自动化、语音转写、思维导图、营销策划等。MCP 协议让 WorkBuddy 作为 MCP Client 连接任意 MCP Server，实现工具能力无限扩展。
