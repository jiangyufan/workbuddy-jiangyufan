那么如何让这只小龙虾更好用，自然需要技能（Skill）的加载。

使用过程中，发现 WorkBuddy 只内置了部分文档处理的 skills，其余插件基本都没有安装，但官方又存在庞大的技能库，基本上 OpenClaw 有的技能腾讯的 SkillHub 里面都有。

技能本质上是给 AI 助手加装能力模块，通俗点讲，技能类似插件，很多软件、浏览器都是加装插件后才算是完全体，小龙虾也一样，并且技能可算是小龙虾最核心功能，解决了大模型调用的许多痛点，没有技能，你的小龙虾可能就只是一个不太完整的 AI 聊天工具。

技能市场里的东西良莠不齐，恶意技能也是层出不穷，作为新手，我也是在学习中，但过程中发现很多文章中所谓的“必装技能”在 WorkBuddy 的技能市场中根本搜索不到，比如最常见的许多文章都在推荐的“Enhanced Docx Document Generation”、“Batch File Processing”等，可能通过其它形式可以安装，但对新手就很不友好了。

于是，就想着根据自身实测体验，写一篇 WorkBuddy 必备技能供各位同样是新手的你参考，每个技能都会简单介绍，最后也会给出技能列表，建议新手收藏。

技能安装非常简单，点击主界面的“技能”，然后在技能页面的右上角搜索框输入技能名称，在搜索结果中点击相应技能，然后点击安装即可，全程无需输入任何命令，这也是为什么我会推荐 WorkBuddy 的原因之一。

## 推荐必装的12个插件。
1. Skill Vetter（安全审查）

一句话：装技能之前先体检，把恶意插件挡在门外。

技能市场的东西，不是每一个都靠谱，有些来路不明的技能，可能会读取你的文件、调用账号权限，你甚至不知道它在后台干了什么。Skill Vetter 是 WorkBuddy 的防火墙，每次安装新技能前自动扫描，识别潜在的安全风险，高风险技能直接拦截，这个技能没什么存在感，但它是整个技能生态的安全底座。其他技能装之前，先把它装上。

1. Tavily Search（实时联网搜索）

一句话：AI 不再活在过去，让它联网搜索最新信息。

大部分 AI 有一个根本缺陷：训练数据有截止日期，几乎市面上所有的 AI 训练截止日期都还在去年，所以它不知道最近发生了什么，这也是 AI 产生幻觉的主要原因之一。所以实时联网检索这个技能几乎是必装的。

1. Multi Search Engine（多引擎搜索）

一句话：国内外搜索引擎全覆盖，且无需API。

如果你和我一样不愿意尝试复杂的申请流程获取API，那么Multi Search Engine将会是你最好的选择，整合了 17 个搜索引擎（8个国内 + 9 个国际），一次检索，多端覆盖，省掉大量手动切换搜索引擎的时间，关键是不需要 API Key，而且可以配合Tavily Search 使用获取更多资讯。

1. Agent Memory（永久记忆）

一句话：AI第一次认识你，下次还记得你。

默认状态下，每次对话结束，AI会清空所有记忆。你跟它聊了一个小时，下次开窗口，它对你一无所知。Agent Memory 会把你的工作习惯、常用指令、历史任务、偏好设定，全部持久化存储。下次打开 WorkBuddy，它知道你是谁，知道你上次在做什么，知道你不喜欢什么风格的输出，这种感觉说不清，但用过就懂。

1. Ontology（结构化知识图谱记忆）

一句话：记住你的偏好，用知识图谱的方式让 AI 真正理解你。

Agent Memory 是记住你说过的话，而Ontology再进一步——它通过类型化知识图谱来组织你的信息，人、项目、任务、事件、文档，全部变成有结构的节点和关系，而不是简单的文字堆砌。对于需要管理复杂项目、追踪多线任务的人来说，Ontology能让 AI 真正懂你的业务逻辑，而不只是被动执行指令。

1. Self-Improving + Proactive Agent（自我进化智能体）

一句话：AI记录自己的错误，主动优化策略，用得越多越好用。

在技能市场直接搜索 elf-Improving 即可，这个技能是我个人最喜欢的之一。普通 AI 犯了错，你纠正了下次可能还会再犯错。这个组合技能能让你的 AI 增加复盘能力，它会记录失败的操作、你纠正的内容、更好的方案，把这些经验沉淀下来，下次遇到类似情况自动应用，还会主动预判你可能遇到的问题，提前给出建议，让你的 AI 越用越好用，为什么我们都在说“养”小龙虾，这下你可明白了。

1. Proactive Agent（主动预判智能体）

一句话：从被动执行指令，升级为主动预判需求的智能伙伴。

普通 AI 的工作方式是你说什么，它做什么，你不说，它不做。Proactive Agent 解决的是另一个层面的问题，它会主动思考你接下来可能需要什么，然后提前做好准备或给出建议。长期使用 WorkBuddy 的用户，装了这个之后提示词负担会明显减轻。

1. Adaptive Reasoning（自适应推理）

一句话：自动判断任务难度，智能分配推理深度，省 Token 还省时间。

如果你购买了 Coding Plan 或者某个模型的 API，这个省钱省时间的插件一定是必装的。其实不是每个问题都需要 AI 深度思考好几分钟，但小龙虾的工作习惯就是深度思考，因此哪怕很简单的问题，你也会看到它有漫长的思考过程。Adaptive Reasoning 干的事情很简单：自动评估任务复杂度，简单问题快速回答，复杂问题才启用深度推理模式，这样不仅会响应更快，Token消耗也会更低。

1. Systematic Debugging（系统化调试框架）

一句话：写代码必备，先搞清楚问题出在哪再调试。

很多 AI 调试代码的问题在于急功近利，还没弄清楚根本原因，就开始猜测式地改代码，结果越改越乱。Systematic Debugging 强制执行四阶段调试流程：现象分析、根因定位、方案制定、验证修复。处理复杂 Bug 的时候，这个框架能减少很多无效折腾。

1. Summarize（内容总结）

一句话：网页、PDF、图片、音频，什么都能总结。

信息爆炸时代，真正稀缺的不是信息，是处理信息的时间。Summarize 支持的格式很广：网页扔URL，PDF直接上传，图片识别图文，音频转文字后自动总结。用它处理行业报告、总结论文或者视频的主要内容，真的不要太香。

注意：此技能需要调用 API，而且在技能市场搜索出现的第一个是中文的“内容总结”，而且只能调用国外大模型，默认是调用 gemini-3-flash-preview，还有一个英文的“Summarize”，也是需要调用 API 的，但是从技能介绍中看，可以支持 DeepSeek、Qwen等国内模型。至于如何配置 API，还是老办法，直接在 Chat 界面告诉它你的 API key 即可。

1. Humanizer（去除 AI 写作痕迹）

一句话：让 AI 写的内容读起来像人写的，消除那股机器味。

这个技能解决的是 AI 写作痛点，去除 AI 写作的痕迹，让输出的文字读起来更自然。写公众号文章、报告、邮件、营销文案都用得上，省去大量手动润色的时间。

1. Agent Swarm（多智能体集群编排）

一句话：把复杂任务拆给多个专业 AI 同时干，效率直接翻倍。

这个技能目前我没有测试，因为目前我确实不需要，也不愿折腾，但多智能体调度是小龙虾的高级玩法，所以还是拿出来给有需要的人，建议先仔细看一下技能介绍，介绍很详细，而且有给出了很多模板。
