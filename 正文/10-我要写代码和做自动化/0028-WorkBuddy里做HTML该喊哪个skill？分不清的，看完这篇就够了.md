## 01 三个 skill 是三种工种。

![WORKBUDDY · 技能速查卡｜三个师傅·各管一摊](https://mmbiz.qpic.cn/mmbiz_png/hHdicyWfdctnqaxaltaAfDiayj1CRUQplRhWicAgKqIHrDeHDgt1ytviaD9ZxsA04lA5NZTBw4OtprWGn0hNwAtKXEDib3rjDibtViccQ2bh1oBep8/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=1)

*WORKBUDDY · 技能速查卡｜三个师傅·各管一摊*

这3个skill可以理解为三个不同的师傅给你干活：像装修队——你给需求，它从零给你盖个能跑的网页 / 界面；像路演教练——它把内容排成一套能翻页、带动画的 HTML 幻灯片；像排版编辑——它把你的文章收拾成「粘到公众号里样式不丢」的合规 HTML。

一句话记住：做网页找 frontend-design，做演示找 frontend-slides，发公众号找 gzh-design。

看不懂这些英文触发词。

没关系，说人话就是：你直接跟 WorkBuddy 描述想要啥，它自己会喊对应的 skill 来，不用你记命令。

## 02 frontend-design：你要的是「一个能跑的页面」。

![你要的是「一个能跑的页面」｜它负责产出生产级HTML/CSS/JS,强调设计感,不套千篇一律的「AI味」模板。](https://mmbiz.qpic.cn/mmbiz_png/hHdicyWfdctmoJRauOhWXAMiaEQm2M4eRqIRqBKfxE8szhEtECvNZ6ib1OFFSIBnSfu2gUficG2uvRUavurjCmLrE6H137s37uJomFebSWQ3JoE/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=2)

*你要的是「一个能跑的页面」｜它负责产出生产级HTML/CSS/JS,强调设计感,不套千篇一律的「AI味」模板。*

frontend-design，它负责产出生产级的 HTML/CSS/JS，强调设计感，不会给你套千篇一律的「AI 味」模板。

什么时候喊它。建网站 / 落地页 / 产品页。做仪表盘、数据看板。写可复用的 UI 组件。美化、改版已有网页。甚至生成 HTML/CSS 海报、卡片。怎么触发（直接说人话就行）。「帮我用 frontend-design 做一个 SaaS 产品落地页」。

命中 build web components / pages / landing pages / HTML layouts 这类意图会自动调用。

帮我用 frontend-design 做一个 SaaS 产品落地页： - 风格：编辑杂志风 + 克制留白 - 主色：深墨绿，搭配暖橙点缀 - 板块：Hero、功能三栏、定价表、CTA - 要真实可交互（按钮 hover、滚动渐显） - 单文件 HTML，内联 CSS/JS。

## 03 frontend-slides：你要的是「一套能演讲的网页」。

![你要的是「一套能演讲的网页」｜一个链接发出去就能看，手机也适配，还能在浏览器里直接改文字，不用装任何软件。](https://mmbiz.qpic.cn/mmbiz_png/hHdicyWfdctleH3gVRKPoCCMdoxOEiaojg5w0ApFw62FtojwHQ8ia1GuFsqychdrsPO93FXR7QIZEuOo4kic1g11u6ABgv28j9mPm8DTOquYT2I/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=4)

*你要的是「一套能演讲的网页」｜一个链接发出去就能看，手机也适配，还能在浏览器里直接改文字，不用装任何软件。*

frontend-slides，它产出单个 HTML 文件，浏览器打开就放，方向键翻页，自带进场动画。还能把现成的 .pptx 直接转成网页版——发别人就是一个链接，手机也能看。

命中 build a presentation / convert PPT to web / create slides 会自动调用。

小提醒：给它一个明确的美学方向（极简 / 暗黑 / 复古），比罗列一堆功能更容易出好东西。想从零拿到一个能上线页面的普通用户，或要快速出原型的同学。它给你的是代码，想精修细节还是得动一点点 HTML；另外会消耗积分，记得看当下的额度。

## 04 gzh-design：你要的是「把文章发到公众号」。

![你要的是「把文章发到公众号」｜主题库是灵魂](https://mmbiz.qpic.cn/sz_mmbiz_png/hHdicyWfdctkufkd1wyg2L1iazut9fbZZFGmSHcial0j0YyZ9A7wgnhJTaAdH60Z9UYr7UicXUibhKEtPjJtibE7EBNIcqNHuO4BSXGFOic6sWZkqQ/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=6)

*你要的是「把文章发到公众号」｜主题库是灵魂*

gzh-design，它把 Markdown / Word / PDF / 纯文本，转成「粘贴后样式不丢」的公众号合规 HTML——章节自动编号、关键词下划线、引言卡、目录、代码块、作者签名全包。它是三个里最懂平台规则的，内置校验脚本会替你卡掉公众号禁用的写法。

写公众号文章要排版。md / docx / pdf 转公众号 HTML。想要「一键自动排版」。为公众号做一套自定义主题。

「用 gzh-design 排这篇教程：./my-article.md，题材工具盘点，建议摸鱼绿主题」。

命中「公众号排版 / 微信排版 / gzh / 一键排版」会调用。主题库是它的灵魂：内置摸鱼绿、红白、石墨极简、留白禅意等多套风格，也能按参考图生成专属主题反复用。写公众号、又不想手动调样式的人。

它产出的 HTML 不能含 //class 这些——这是公众号平台红线，校验脚本会兜底，但你自己手改时要留神。

# 标准排版（先推荐主题让你确认） 用 gzh-design 排这篇教程： ./my-article.md 题材是工具盘点，建议用「摸鱼绿」主题 # 全自动，不想被问 直接排，一键自动排版，题材自选、主题自选。

## 05 最容易踩的坑。

![WORKBUDDY ·避坑指南｜PITFALLS·四个最容易踩的坑](https://mmbiz.qpic.cn/sz_mmbiz_png/hHdicyWfdctl6LJ4VsyUR40Dj7kngmkib0OEYYicc9lsruX8IUjWbgtpITcnB0iaxFWlXdGAVpz1PkPaSYAM3e7LUxwibSkyQv5icURDq2gKyCibDM/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=8)

*WORKBUDDY ·避坑指南｜PITFALLS·四个最容易踩的坑*

个人使用下来，总结了几点容易踩的坑：用错 skill。做网页却喊了 gzh-design，出来的东西上不了线。先想清楚「贴哪、给谁用」。frontend-design 里点名「紫色渐变 + Inter」。会触发它最躲的「AI 味」，出来的页面跟别人撞脸。

gzh-design 跳过校验。漏了 包裹，粘到公众号后样式整片丢失。校验脚本跑通再交付。frontend-slides 硬塞内容。一页塞太多，投影直接溢出。让它拆页，别硬扛。一句话总结：先想清楚要什么，再喊对的师傅。
