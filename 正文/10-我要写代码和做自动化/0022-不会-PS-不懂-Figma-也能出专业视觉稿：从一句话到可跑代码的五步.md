# 不会 PS 不懂 Figma 也能出专业视觉稿：从一句话到可跑代码的五步
## 四类人被同一个环节卡住
先看几个日常画面。做产品页，不会画图只能等设计师排期，改稿来回沟通耗半天；做活动海报，配色排版反复调，找模板还怕版权；做汇报 PPT，布局和图表手动堆，一晚上只出三页；设计定稿了，开发还得手动还原尺寸、圆角、渐变，还原度永远对不齐。

这四个画面看着不像一件事，其实是同一件事：创意、绘图、改稿、交付、开发，五个环节被切成五段，跨岗位协作的成本全压在接缝上。

WorkBuddy 的「设计创意」模式接上了 Ardot 这个 AI 设计平台，想做的就是把这五段合成一条线——从文字出设计、对话改稿、专业精修，到一键产出可运行代码。

## 第一步：三十秒把两个账号接上
打开 WorkBuddy 首页，点「新建任务」，把顶部标签从「日常办公」切到「设计创意」——标签栏里就三个：日常办公、代码开发、设计创意。切过去之后，对话框下方会多出「网站设计 / PPT设计 / 视觉海报 / 更多」四个入口。

第一次用会自动弹出 Ardot 授权窗口，靠登录手机号一键完成账号互通，不需要另外注册腾讯设计账号。授权范围就三项：读取画布内容、在线编辑画布、云端双向同步。

这一步别省。授权之后 WorkBuddy 才真正拿到完整的画布操作权限，对话和专业设计编辑器才算双向打通。设计稿全部云端存储，换电脑、重新登录也不会丢，实时同步。

## 第二步：一句话出可编辑的画布
不用找模板、不用手绘，直接描述需求，AI 在 Ardot 画布上实时生成完整的设计文件。关键差别在「可分层编辑」——产出不是一个静态图片，每一层你都能再动。

**覆盖的类型挺全：**移动端 App 界面、官网落地页、品牌 Logo、活动海报和 Banner、商务 PPT、数据可视化页面。它自己给了三条示例指令，可以直接抄：运营说「设计一张 618 产品促销海报，深色科技风，突出限时优惠」；产品说「制作移动端 APP 登录页，简约商务，蓝白主色调」；职场说「生成 AI 行业趋势分析 PPT，深色工程风，包含多组数据图表」。

实测那条是第三条。给了六部分结构后，它把六大趋势切片、关键数据区、中美欧三极格局图、2026 五条预测全落到画布上，风格用 Linear 那种冷峻工程感贯穿整页。它还会主动把设计规范报给你：底色 #0A0A0F 近黑，卡片用 #070711 / #0C0C12 分三层暗色调，强调色 #5E6AD2 只点数字、徽标、线条；字体走双轨制，Fira Code 管标题和数据、Fira Sans 管正文；信度标签三色区分，高信度绿 #4ADE80、中信度黄 #FBBF24、低信度红 #F87171。

## 第三步：三种改稿方式，不用拖拽
初稿出来之后，改稿才是真正耗时间的地方。这里给了三种方式，分别对应三种改稿需求。

**智能框选加对话：**框住画布里的某个元素，输入修改指令发出去。适合局部微调——按钮、文字、色块、图表。

**纯语言全局指挥：**直接在对话框输入调整需求。适合整体风格、背景、字体、页面版式的改动，比如「把页面顶部按钮整体放大 1.2 倍」「全局背景替换深蓝渐变底色」。

**粘贴参考素材：**上传图片或者粘贴网页链接。适合复刻参考视觉风格、统一品牌调性，比如「参考粘贴链接的极简视觉优化整套 PPT」。

每轮调完，它会清楚告诉你这次改了什么，修改全程可追溯，评审沟通时不用凭记忆对稿。

## 第四步：从 80 分到交付，去 Ardot 补最后 20 分
对话负责快速从 0 到 80 分出稿，最后 20 分的交付细节，交给 Ardot 专业编辑器。点画布顶部「浏览器打开进行编辑」就能跳过去。

这一步对不同人价值不一样。产品、运营、开发这类没有设计基础的，AI 初稿常有排版杂乱、间距失衡、配色不协调的问题，Ardot 所见即所得拖拽调整，点选就能改颜色、间距、字体，不用记参数。专业 UI 设计师则相反——AI 生成的图层可能混乱、缺组件规范、导不出切图，Ardot 支持像素级对齐、组件复用、图层管理，一键导出 PNG/SVG/PDF，能直接满足开发交付标准。

**改完不用手动刷新：**浏览器端所有修改实时回流 WorkBuddy 画布；精修完回到对话窗口，AI 还能读到最新版本继续迭代。整条节奏是——3 分钟对话出初稿、5 分钟 Ardot 像素级精修、1 分钟生成前端代码。

## 第五步：设计稿直接变成可跑的代码
设计定稿之后，最容易被吃掉时间的一步是「还原」：设计师标注、开发对着图一点点调。这里有两种触发方式——对话里输入「将当前画布设计稿生成应用代码」，或者点画布顶部「生成应用」的快捷按钮。

实测那一张 PPT 稿，生成了 979 行单文件 HTML，过了 19 项内容校验。它会给出一份参数对照，全是像素级从画布提取的：背景是四段深海军蓝渐变（#021430 → #041D32 → #072A40，卡片 #041D2C）；Header 64px、backdrop-blur 24px、rgba(4,7,23,0.82)；Hero 用 radial-gradient 加 mix-blend-mode:screen、opacity 0.28；标题 88px Fira Code Bold #FAFAFA、letter-spacing -2px；按钮 padding 16px 28px、圆角 4px、底色 #5E6AD2。

代码出来之后还能继续用对话改：换技术栈「用 React 重构页面代码」，加功能「给页面增加深色模式切换」，换样式方案「全部样式替换 TailwindCSS」。设计到开发这一段，沟通成本基本被压缩掉了。

## 五条必须知道的限制
第一，用「设计创意」功能必须先完成 Ardot 账号授权，没授权等于没有画布权限。

第二，设计文件全部云端存储，换设备登录可以继续编辑，但不等于本地有副本。

第三，完整的 Ardot 精细化编辑需要浏览器环境，内置画布只支持基础对话调整——想精修就得跳出去。

第四，代码生成依赖当前画布上有完整设计稿，空白画布点「生成应用」不会触发。

第五，所有 Ardot 设计服务都要遵守官方用户协议与隐私协议，商用前自己确认一遍授权范围。

## 它到底替掉了什么
过去做设计，得在 AI 绘图工具、专业编辑器、代码工具之间来回跳。现在的链路是文字生成 → 对话改稿 → 专业精修 → 代码交付，四步在同一个工作台里跑完。

对运营，是不用等设计师排期就能出海报和物料；对产品，是能自己出页面原型和汇报 PPT；对设计师，是 AI 批量出初稿、自己专注在规范和细节上；对开发，是设计稿一键转代码、少一轮对接。

它并不能让不会设计的人变成设计师——排版审美、层级判断这些还是人的活。但它确实把「不会用设计软件」和「做不出能交付的视觉稿」之间的那堵墙，凿开了一个口子。
