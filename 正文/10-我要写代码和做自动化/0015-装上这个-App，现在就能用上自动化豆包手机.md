# 装上这个 App，现在就能用上自动化豆包手机
![对这个世界还保有好奇心？关注这里就对了](https://mmbiz.qpic.cn/mmbiz_png/4QK9bGpA4N8QkbJT3a4BCOJ1QBBPE0vhM29LPnhsEQ9rpH6JiaVmXAzS6WibMXf6lFic2QNc3Fca8EZQ2RqqzubLv0UWH88Mu0QLxm4bCtC0C0/640?from=appmsg#imgIndex=0)

*对这个世界还保有好奇心？关注这里就对了*

说到这，大伙肯定第一时间想到前阵子的豆包手机。不过豆包手机后来碰壁的窘况大伙也都看到了，今天不过多展开。

但你我都清楚，手机上的 Agent 是挡不住的终局大势，一旦尝过甜头，就不可能再回头了，所以往这个方向使劲的人其实一直不少。

这次要聊的，就是上周刚上线、一上线就火出圈的一个开源插件，叫 DSH Go。可以说，把它装进手机之后，基本上就长成了豆包手机想要长成的那个样子。

上周，我是刷知乎的时候注意到它的，刚上线就 Star 破 4 千，上了知乎热榜。当时我翻了一下，下边回答还不算太多，但基本都在夸软件完成度高、界面漂亮。

*他们也关注了该问题｜试图用ai做点东西的一个普通人。*

我顺手去翻了翻作者的代码仓库，GitHub 上叫 Chimney，原来官方首推的终端界面插件 dsh-TUI 就是他做的，也有七千多星，常玩的 DSH 的老玩家应该对这名字不陌生。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/4QK9bGpA4N9RG2GBZXWc1tejxEiaYtsVn7Cib2Ndb1ZqZHyic7nWf05ibVEiajUQLacjibglbvpKWoovHwbux4HCViag72wUaUdJDhGliavPlhib18Jo/640?wx_fmt=png&amp;from=appmsg#imgIndex=3)

WorkBuddy 或者 Codex 我们都很熟了，虽然有手机 App，但真正执行的任务的还是你电脑里的 Agent 工具，还得在电脑环境里干活。

而 DSH Go 是把一个完整的 Agent 工具直接塞进了手机里，让它直接在手机上跑系统级的自动化操作。

它主要能干两件事：

第一，手机本机直接跑 DSH 引擎，在 App 里一键把 Linux 运行环境搭好，不需要 Root，给它开了系统的无障碍权限，它就能帮你接管屏幕、点击滑动，去操作手机上的各个应用，通俗点说，就是类似豆包手机的玩法。

第二，可以作为客户端，去遥控你电脑或者远程服务器上的 DSH。

单看第一个玩法，我就已经忍不住了，立马安装下载装好，断断续续深度玩了一个星期，前前后后给它派了不少活儿。

先来看一段视频，这是我让它去帮我订了一张高铁票。怎么样，是不是很舒服。我当时就给它发了一句话，把车次要求交代清楚，顺便特意补了一句：付款的时候叫我。

视频中间有加速，但是整个任务也就是跑了两分钟，找到了对应的车次，再选择乘车人的时候，因为他了解我的身份信息，所以自动就帮我选中了我的信息。

你看，就像这种卡点，如果你不给它提供足够的上下文，那它就会卡住等你来点。

如果你喂足上下文，那就只用等着订单锁定去付款就行了，当然，如果你也不想点，也可以让他去帮你付款，但是我建议还是稳重点儿好。

顺手我又测了几个其他场景，先看一个高频场景，让他去不同平台比价格，最近是想入手一个 3D 打印机，我就让它去搜搜看。

它跑完之后把这些附加条件都算进去了，最后给出一张干干净净的对比结果，哪家实际到手最便宜一眼就能看出来，比自己一家家翻省心太多。

你可以只管说出你的需求，剩下的交给 Agent 去帮你跑。我让它打开 AdGuard，把里边所有能开的屏蔽规则全给打开。

它干活很利落，能开的都顺手打开了，碰上需要安装根证书的 HTTPS 过滤环节，老老实实停下来交给我手动确认。

遇到需要 Root 权限的防火墙选项，也保持关闭没乱动，最后还列了一份清单交代哪些开了、哪些没动，让人很放心。

关键是，这些活儿如果他不帮我干，大部分用户估计是真懒得去挨个查，挨个点。

最后再来一个我觉得最爽的，还是之前的老问题，就是微信公众平台会把几年前的旧文章翻出来，给你判个违规，就很烦。出于安全考虑，前阵子我也让 AI 去帮我扒拉了一遍可能会有风险的文章，列了个清单。

所以我立马就想到，总算可以把这个活儿批量完成了。而且我只给他说了一个大概的需求，能看视频就知道这个需求其实很模糊。我只说了可能敏感有风险的文章，然后他自己就去想了几个关键词，去挨个排查了一遍。

如果是那种愣头愣脑的脚本，可能上来就乱砍一气。但它挺克制，先把符合条件的 9 篇候选文章列出来让我挑，然后我就定下来：把 234568 都删掉。

它立马就去删得干干净净，没勾的完好无损。特别是在折叠屏手机上，你在这边刷着红果，他在那边一通忙活，我只能说，真的，太舒服了，太爽了。到这里，我知道大家肯定还想问一个问题：微信呢。答案是，微信确实用不了。

我实测下来，微信界面截屏之后，它读取不到页面上的节点，也就是不知道按钮和文字都在哪，这一块等于被微信给限制了。

去 GitHub 上翻了翻，好几个人也反馈微信页面读出来是空的，加上 DSH Go 从 1.0.5 起不允许看不清就盲点，到这一步只能停下。

官方文档里也专门提醒过，微信这类 App 有风控，曾有手机助手操作后账号被强制下线，所以默认给微信设的是每一步都确认。

微信永远还是最特殊的那一个。

接下来给大家简单理一遍，使用时候的设置，其实也没有什么特别难的地方，跟着引导一步一步操作就行了，作者在交互上下了功夫，基本都做成了点选操作。

平时大家手里的主力机型直接选 arm64 架构的安装包就行，系统要求只要是 Android 8 及以上都能跑。

安装好之后。

装好之后桌面上就多了个 DSH Go 的图标。第一次打开应用的时候，它会让你选把 DSH 引擎安在本机还是远程主机。

选本机的话，它会在 App 内部直接把一整套独立的 Linux 运行环境布好，界面上会标明具体需要的存储和内存空间，完全不需要 Root 权限；要是手头机器配置吃紧，走远程模式会更合适。

我们就先介绍本机安装设置。

装完进入主界面，在设置 › 本机引擎里，有的版本放在设置 › 主机 › 本机引擎，默认已经勾上了打开 App 时自动启动和自动进入安全模式。

平时不用管它，要是哪天不小心折腾崩溃了，它连续启动失败两次就会自动掐断插件加载，方便你排查问题。

![打开 App 时自动启动｜自动进入安全模式](https://mmbiz.qpic.cn/mmbiz_png/4QK9bGpA4NicEvnNX2zTcIUmaCHJtAS5y0hwiaz2AjBcxqD1f0wsY3RukkfP0llV86VSLnVmNnNrt5P8iawkfgQVq3u5AdIIXdeU0J2qfc1evQ/640?from=appmsg#imgIndex=5)

*打开 App 时自动启动｜自动进入安全模式*

本机引擎和模型渠道。

在设置 › 模型里分成了官方、订阅、自定义三类。对我来说最省心的就是走官方的 DeepSeek 渠道。

点进去直接支持用 DeepSeek 官方账号登录，会在浏览器拉起授权，只要本机引擎跑着就能顺利绑定，连填 API Key 的功夫都省了，调用费用直接从账号余额里扣。当然如果你手里有现成的 Key，随时填进去替换也行。

![账号模型的费用从余额中扣除｜[ → 退出登录](https://mmbiz.qpic.cn/mmbiz_png/4QK9bGpA4N9xA0HMPOJ76mq5t7BHpCFRTCo1iaMq4gqpLibTPtqMUt7tjMNyPgpLUafReemLoZOCPZIru4UQBMU1gA3NwnQh17Q4BibuiaQrQtE/640?from=appmsg#imgIndex=6)

*账号模型的费用从余额中扣除｜[ → 退出登录*

DeepSeek 账号和选模型。

接着就是打开手机操控权限。在设置 › 手机操控里把顶部总开关推上去，初次开启时会弹出一页详细说明，告诉你它要读取什么内容、会发给哪个模型，点完同意并开启，正在运行的引擎会自动重启一次完成加载。

手机操控和系统无障碍。准备清单里最关键的是无障碍服务，点去开启跳转到系统的无障碍设置里，找到 DSH 手机操控打上勾就行。

部分定制系统如果安装第三方应用时把无障碍开关置灰了，可以点界面里的无障碍开关点不动这一项，里面内置了主流品牌的处理指引。

无障碍和通知。把无障碍和通知权限放行之后，底下有个挺实用的小功能叫读一下当前屏幕。点一下它就会把当前屏幕抓到的文字吐给你看，纯粹是让你心里有个底，看看它到底能看清哪些元素。既然涉及到接管手机，大家最关心的肯定还是安全性，作者在这块卡得相当严。

*读一下当前屏幕｜看看DSH读到了什么，不发给模型*

确认方式和应用名单，我这台改过，新手按默认。点进确认方式，有三档可以选：

默认的是每次都询问，一旦进到新应用，或者遇到发送、删除、付款这类敏感节点，它一定会弹卡片先请示你；第二档是本任务免确认，同一个任务里只要点过一次允许，后面就不再反复弹窗打扰；最后一档则是完全放手的始终免确认。

新手建议保持默认的每次都询问，我估计你用不了多久，马上就会无脑确认，这个操作反正大家掂量着来就行。应用名单里的限制更细，出厂默认就已经把银行、券商这类涉及真金白银的 App 划进了不碰名单。

像微信这种高频通讯软件，默认也被设定为每一步都确认，我截图里这台把微信改成了照常这一档，但实际上用起来，微信是没有办法完全自动化的。
