# 把备课四步法打包成一个 Skill：YAML 怎么写、怎么导入、怎么改成自己的
上一期学的是装技能加备课四步法：传素材、定目标、出框架、磨细节。但每次备课还是要手动输入四条指令，麻烦。能不能一句话搞定？可以——把这四步打包成一个 Skill，以后说「备课」就自动走完。

这一期就是手把手做这件事。中间还会解决两个常见的卡点：怎么保存成 YAML 文件，以及技能导入要 zip 或者 skill.md，YAML 文件到底能不能用。答案是能，WorkBuddy 支持通过文件自定义 Skill，把一系列指令打包成一个命令。

## 先接上一期：装好技能，跑通四步法
上一期做了两件事。第一，装好三个技能：docx 写文档、baidu-search 查资料、pptx 做课件。第二，跑通备课四步法：传素材、定目标、出框架、磨细节。

这一期在此基础上再进一步：把这四步打包成 Skill，导入后一劳永逸。

## 第一步：拿到 YAML 代码
打开上一期拿到的文档，找到「备课」这个 Skill，复制下方那段 YAML 代码。

拿到代码之后不要直接改后缀，下一步的保存方式才是关键——很多人就是在这里失败的。

## 第二步：用记事本存成 yaml 文件（关键一步）
打开电脑上的「记事本」，粘贴刚才复制的代码，然后「另存为」：保存类型选「所有文件」，文件名写成 xxx.yaml，编码选 UTF-8。

这里有两个必须守住的地方。保存类型一定要选「所有文件」，否则记事本会偷偷给你加上 .txt，变成 xxx.yaml.txt。编码一定选 UTF-8，不然中文可能变乱码。

如果保存后图标还是记事本的样子，说明后缀没改对——回去检查文件名是不是真的以 .yaml 结尾。这是最常见的一处失败。

## 第三步：拖进 WorkBuddy 导入
打开 WorkBuddy，选择刚才保存的 .yaml 文件，拖动到聊天工作区，然后输入指令「导入技能」，确认发送。

就这三步，不需要写代码，也不需要装什么额外工具。

## 第四步：说关键词触发
导入完成后，在对话框里输入对应的关键词——「备课」「改作业」「写通知」「学情分析」——就会自动触发对应的 Skill 流程。以后不用手动一步步下指令了。

这才是 Skill 相对提示词的价值：提示词要你自己记住并复述，Skill 只要一个词。

## 转格式和打包：分享给同事怎么办
**转成 md 格式：**在记事本里打开 .yaml 文件，复制全部内容，粘贴到新记事本，保存为「备课4步法.md」。md 是纯文本说明，对方用记事本就能打开看，适合给人看而不是给机器读。

**直接给 yaml：**同事拿到 .yaml 文件后，打开 WorkBuddy、导入技能、选择文件即可，不需要重新复制代码。

**打包成 zip：**把所有 .md 或 .yaml 文件放进一个文件夹，右键压缩，生成 zip 发给同事。一次发一套，比一个个传省事。

## YAML 配置拆解：你也能自己改
这段配置其实只有三块，看懂了自己就能改。

第一块，触发条件 trigger 里的 keywords。老师说到这些词时 Skill 自动触发，你可以改成「写教案」「做教学设计」等自己习惯的说法。关键词写得越贴近你的口头习惯，触发越顺。

第二块，四个步骤 steps。每个 step 是一个环节，带 name 和 tools：传素材定目标用 docx 和 baidu-search；出教案框架；磨提问板书；出 PPT 大纲用 pptx。你可以改 name、调顺序、加 tools。

第三块，输出格式 output。format 写 markdown，sections 列出教学目标、教案框架、板书提问、PPT 这几段。想要别的结构，改这里就行。

## 同一套方法，复制到更多场景
不只是备课。改作业可以拆成：上传作业、标出错题、写评语、统计成绩。写通知或家长通知：定场景、写草稿、调语气、定稿。学情分析：上传数据、出统计、归因分析、分层建议。

**做法都一样：**复制 YAML 模板，改 trigger 关键词，改 steps 名称，保存成新的 .yaml，导入 WorkBuddy。五分钟一个。

## 用之前先过一眼的三条合规说明
第一，YAML 是纯文本配置文件，不会修改你的系统、不会泄露数据。

第二，Skill 只是「指令打包」，AI 执行时仍然要遵守原有的数据安全规范。打包不等于放权，该脱敏的还是要脱敏。

第三，自定义 Skill 别人看不到，只有你导入的那个账号能用。
