# 别看到什么 Skill 都装：先把任务分成四类，再挑真正需要的那一个
## 第一次接触 Agent，最容易踩的坑不是提示词
很多人第一次接触 Agent，最容易踩的坑不是不会写提示词，而是看到什么 Skill 都想装。

和普通的 AI 对话不同，Agent 不只是给你一段答案，它还可以读取材料、拆解步骤、调用工具，并把结果整理成能够继续使用的文档、表格或演示稿。

能力变强了，风险也就跟着来了：它可能读取你的本地文件、调用第三方服务、执行系统操作。所以装的每一个技能，都是一次授权。

但大多数人把它当成装 App——看到榜单前十就全装上。结果是界面被塞满、模型到处误调用、每次干活还要自己分辨哪个技能在起作用。

**这篇只讲三件事：**Skill 到底是什么、这十项能力怎么选、第一次使用时如何把风险控制住。

## 先说清楚：Skill 到底是什么
很多人会把 Skill 理解成普通插件。这个说法不能算错，但还不够准确。

插件通常只是增加一个单独功能；Skill 更像是交给 Agent 的一套工作方法，里面可能包含任务说明、执行脚本、工具接口、处理步骤和检查标准。

**举例：**让 Agent 整理会议纪要，它不应该只把录音转成文字，还要继续识别会议决策、待办事项、负责人和截止时间。这些步骤被提前封装好，才会变成一项可以重复调用的能力。

**一句话分清：**Agent 是负责执行任务的人，Skill 是它掌握的一项专门能力。

官方文档把 Skill 定义为一组可执行的脚本与工作流。安装并启用后，Agent 才能在你的授权范围内完成更具体的动作。所以安装前要检查来源、权限申请和数据使用范围——不是装得越多越好。

## 别一次全装：先把任务分成四类
这十项 Skill 看起来很多，其实可以放进四个任务盒子里。只要先判断自己现在要做哪类事，选择就会简单很多。

盒子一，不知道该用哪个技能：选 Find Skills。盒子二，需要联网搜索、读取长内容并整理结论：选 Tavily Search 加 Summarize。盒子三，把真实材料变成文档、表格、PPT 或行动清单：选文档三件套、AI PPT 专家、会议纪要。盒子四，记住偏好、吸取错误、保存重复工作：选 Skill Creator、Memory Setup、Self-improving Agent、Code Simplifier。

**记住一句话：**Skill 的数量不是效率，选择是否匹配任务才是。

## 前三项：发现、搜索与总结
Find Skills：它不直接处理任务，而是根据你的目标寻找候选 Skill。新手可以先描述任务，让它说明每项能力的作用、来源、权限和适用范围，确认后再安装。提示词可以这样写：「我需要把一份调研报告整理成汇报 PPT。请寻找适合这个任务的 Skill，并说明作用、来源、权限要求和适用范围。不要直接安装，先把候选结果发给我确认。」

Tavily Search：适合查新闻、竞品、行业动态和近期公开资料。关键不是「找到很多」，而是限定时间范围、规定输出结构、保留原始来源，并区分事实与判断。提示词至少要写清：过去多久、要几条、每条包含什么、是否必须提供原始链接、是否允许使用未经验证的二手消息。

**Summarize：**适合处理 PDF、长文章和视频链接。不要只要求「缩短」，而要让它提炼核心观点、关键数据、结论、行动建议，以及仍然缺少证据的部分。

## 中四项：流程、文档与记忆
Skill Creator：一件事只做一次，直接交代步骤就行；每周每月都要重复，才值得封装。要把输入、执行步骤、检查标准和输出文件说清楚，先生成草稿与测试方案，再用于正式材料。它的价值不是让 AI 凭空发明工作，而是把你已经验证过的流程保存下来。

**文档三件套：**PDF 负责文字识别、提取、合并拆分；Word 负责排版、批量替换和结构整理；Excel 负责数据清洗、图表与透视分析。处理文件时一定要明确「不覆盖原文件」和结果保存位置，并让它开始前列出读取范围和执行步骤。

Memory Setup：适合保存写作语气、项目背景、命名习惯和固定输出格式。但有一条红线——密码、API Key、客户隐私、身份证件和未公开财务数据，不要写进长期记忆。记忆的目标是减少重复沟通，不是无限收集信息。配置前先确认它保存在哪里、如何查看、怎样删除。

## 后三项：改进、代码、PPT 与会议
Self-improving Agent：所谓「自我改进」通常是把错误、修正意见和复盘规则记录下来，供下一次任务参考，并不是底层模型自动重新训练。有效的规则必须可以查看、修改和撤销。

Code Simplifier：只做代码的减法——清理重复逻辑、统一命名、拆分复杂函数、简化结构。必须同时约定三条：功能不能改变、修改前备份、修改后运行测试。行数减少不是目标，可读性与稳定性才是。

**AI PPT 专家：**一次给出观众、场景、时长、页数、核心结论、引用资料和视觉风格，先确认页面大纲再生成完整 PPTX。会议要求更实在：真正有价值的输出是会议结论、已确认决策、含负责人和截止时间的待办，以及仍待确认的问题。材料里没有的信息要标注「待确认」，不能自行补充。

## 在 WorkBuddy 里，实际应该怎么操作：五步从隔离到验收
第一步，先建立独立工作空间。把需要处理的材料复制到单独文件夹，不要一开始就授权整个硬盘或重要资料目录。按任务建立独立空间，既方便管理，也能降低误操作风险。

第二步，在技能市场搜索或查找。知道名称就直接搜；不知道名称就先描述任务。装第三方 Skill 前，检查来源是否可信、申请了哪些权限、是否会把数据发送给第三方。

第三步，只启用当前真正需要的 Skill。官方文档也建议只启用当前任务所需能力——这不只是减少界面干扰，更能降低误调用和不必要的数据访问。

第四步，第一次执行先让它出计划。WorkBuddy 提供 Ask、Plan 和 Craft 等方式，新手处理重要文件时，可以先 Ask 了解能力，再用 Plan 确认读取范围和改动内容，最后才进入 Craft 执行。

第五步，检查产物，而不是只看「完成了」。检查实际生成了哪些文件、原文件是否保留、数据合计是否正确、文档能否打开、PPT 能否正常播放。Agent 说任务完成，不等于结果已经通过验收。

## 一段可以直接复制的通用提示词
「请使用【Skill 名称】处理这个任务。任务材料位于【文件或目录路径】。我的目标是【具体目标】，最终需要输出【文档、表格、PPT 或分析报告】。开始前请说明：需要读取哪些材料、准备执行哪些步骤、会修改哪些文件、是否使用外部服务、是否会把数据发送给第三方。不要覆盖原文件。先把执行计划发给我，我确认后再开始。完成后检查结果，列出新增或修改的文件，并标记仍需人工确认的内容。」

这段提示词没有追求复杂，它的价值在于提前约定了四件事：输入是什么、目标是什么、权限边界在哪、怎么算通过验收。

新手最容易漏掉的是最后一条「标记仍需人工确认的内容」。没有这一条，AI 会把自己不确定的地方也说得像确定的一样，你还得回头一条条查。

## 从一件真实的小事开始
这十项 Skill 不需要一次全部安装。查资料，可以先用搜索和总结；处理办公文件，就从文档、PPT 和会议纪要开始；同一流程反复出现，再考虑创建、记忆和复盘类能力。

**四步走法：**确定任务 → 选择最少的 Skill → 提供真实材料 → 检查最终结果。

对第一次使用 Agent 的普通用户，最好的开始方式不是先研究完整个技能市场，而是挑一件今天真实需要完成的小事，让它从头到尾做一遍。

当你知道怎样描述任务、控制权限、提供材料和验收结果之后，Skill 才会从「看起来很厉害」，变成你每天都能使用的工作能力。
