# 从 0 上手把教师工作做起来：两个「技能」入口别走错，自己的 Skill 这样建
## 装好了，但不知道该点什么
上一篇讲「AI 落地」，讲完很多老师还是会问一句：那我今天到底怎么用？

这篇换一种写法，就从 0 开始——把软件装好，认清界面，学会工作空间和技能，然后跑两个真实场景：一个用来备课，一个用来整理资料、生成总结和汇报稿。

默认读者不想折腾技术。你只要会整理文件夹、会打字、愿意多检查一遍，就够了。

## 装好之后先做六项检查，别急着让它干活
很多人不是不会用 AI，而是卡在配置上。设置没弄好，后面会反复遇到几个小麻烦：任务跑到一半弹确认、缓存和输出文件全堆到 C 盘、积分消耗没概念、技能装了一堆却不知道怎么用。

第一项，确认安装来源。走官网或腾讯软件中心，别用来路不明的网盘安装包。第二项，单独建项目文件夹，不要一上来把整个桌面交给它。

第三项，把工作空间路径改掉。学校电脑 C 盘经常不宽裕，按软件提示改到 D 盘或 E 盘的专门目录，比如 D:\WorkBuddy项目；以后每个任务再在里面单独建文件夹。

第四项，看技能相关开关。「技能自动更新」打开能省心一些；「非高风险技能自动安装」要看学校要求，它的意思不是随便装，而是低风险技能可以减少反复确认——学校统一管理电脑、涉及学生数据和学校账号时，宁可保守一点。

第五项，积分和消耗心里有数。第六项，模型按任务选：日常写材料、整理表格、做初稿，默认模型通常够用；复杂任务、长资料、多文件分析再切更强的。

## 还有一条容易被忽略：长对话要及时新开
对话越长，AI 记住的上下文越多，响应也可能变慢。一个任务结束后，新开一个任务或新会话，反而更清爽。

这条听起来是小事，但它直接影响你对「它到底聪不聪明」的判断。同一个对话里连着干三件不相关的事，它的表现会明显下降。

## 第一次打开，盯住五个地方就够了
界面并不复杂，不用管所有功能。第一，左侧任务区：放的是新建任务、助理、项目、专家、自动化、空间这些入口，刚开始主要用「新建任务」和「空间」。

第二，中间输入框：这是你给它布置任务的地方。别把它当搜索框，它更像你跟一位工作助理交代任务的桌面。

第三，工作模式入口，决定它怎么干活。第四，技能入口。第五，工作空间。

**工作模式的选择很简单：**Ask 只是问清楚，或者让它先看资料、提建议；Plan 是任务比较复杂时先让它列计划，你确认后再执行；Craft 是目标明确，直接生成文档、表格、提纲或初稿。

## 工作空间不是文件夹，是这次任务的资料边界
这是很多老师刚开始最容易忽略的地方。工作空间不是「它能看到的所有文件」，而是「这次任务允许它看的文件」。

比如今天做《圆明园的毁灭》备课包，就单独建一个文件夹，只放这节课相关的资料。不要一上来就把整个硬盘交给 AI。

把工作空间理解成「本次任务的资料边界」，后面很多麻烦事会自然消失——它不会翻到你上学期的成绩表，也不会把不相关的东西混进输出。

## 别急着背提示词，先记住四个问题
刚上手的老师容易去背一堆提示词模板，其实不用。先把任务说清楚就行，说清楚靠四个问题：东西在哪（当前工作空间里有什么资料、哪些文件必须读取）、要做什么（先分析还是先列计划）、输出什么（Word / Excel / PPT 大纲、知识点、数据、学情）、哪里要我确认（命名规则格式要求、不确定处单独列出）。

我常用的表达就是这四个连起来：东西在哪 + 要做什么 + 输出什么 + 哪里需要我确认。

对照一下就很明显。只说「帮我写一份工作总结」，它能给你的只有通用模板。换成：「请只读取当前工作空间里的资料。我要生成一份信息中心学期工作总结，语气适合学校公众号和行政汇报之间，不要太官方。请先列出你看到的资料、可写的板块、缺少的数据，不要直接成稿。」——这句不高级，但有效，它把边界、目标、输出和确认点全说出来了。

## 技能不是「更会聊天」，是「更会干固定的活」
很多老师看到「技能」两个字，会以为是另一个 AI 助手。不用这么理解——在 WorkBuddy 里，技能更像一个小工具，适合处理重复、固定、有明确格式的任务：整理 Word、生成 PPT 大纲、分析表格、检索网页资料、按固定要求输出总结。

说白了，技能是封装好的操作。普通对话像「临时请一个同事帮忙」，技能像「把某类活做成一个标准动作」，以后再遇到同类任务，不必每次从头交代。

**新手最该先装的六类：**办公文档（docx / xlsx / pptx / pdf，做材料最常用）、网页搜索（找公开资料）、浏览器操作（填表、截图、抓取）、语音转文字（会议录音转纪要）、个人知识库（长期积累资料）、自我优化（让 Skill 继续改）。不用全装，先挑跟当前任务有关的 2-3 个。

## 新手最容易走错的一个路口：两个「技能」入口
输入框附近有个「技能」按钮，左侧「专家」里也有个技能区，两个都叫技能，作用完全不一样。

想装技能，走技能市场：点左侧「专家」，顶部切到「技能」，进入「技能市场」——这里能看到推荐、SkillHub、套件、已安装，右上角有搜索框和「添加技能」。用搜索框搜关键词，比如 Word、Excel、PDF、网页搜索、知识库、教育学习，看清说明再点「+」添加。

想用技能，回到对话框：输入框附近的「技能」按钮适合临时选择、查看或调用已装技能，它不是新手安装技能的主入口。

**一句话记：**装技能去技能市场，用技能回对话框。

## 装完别急着上大任务，先给它一道小题
围绕一个真实任务装技能，比如今天要做「学期工作总结」，就搜文档处理、资料整理、网页检索相关的。装好之后先别把大总结丢过去，先给一道小题：

「请只读取当前工作空间。先帮我清点文件夹里的资料：1. 每个文件大致是什么内容；2. 哪些适合写进工作总结；3. 哪些只是附件或佐证材料；4. 还缺哪些关键数据。先不要生成总结。」

这道题跑不顺，就说明资料本身没整理好，或者技能选错了。这时候硬上大任务，只会得到一份看着像样、实际不能用的稿子。

## 手把手：做一个自己的「学校工作总结初稿」Skill
真正让老师用起来的，是把自己的重复工作做成 Skill。这部分特别适合教研组长、办公室、德育处、教务处——学校材料不是不会写，而是每次都在重复同一套要求：标题怎么写、数据怎么放、语气多正式、最后要不要加问题和改进方向。

**第一条原则：**第一次创建不要追求完美。先做一个能跑的 1.0，用旧材料测，哪里不合适再改。

第一步，选一件你最熟悉、最重复的工作。不要一上来做「全能教师助手」，那种东西听起来厉害，实际很难稳定。可以从这些小事开始：学校工作总结初稿、活动简讯初稿、教案检查清单、听课记录整理、公众号推文降 AI 味、迎检材料附件目录。

第二步，找到 skill-creator。这是专门用来创建 Skill 的工具，没装就去技能市场搜「skill-creator」或「技能创建」添加；装过就直接在输入框附近的技能按钮里选它，或者在指令里写明「调用 skill-creator」。选中后输入框上方会出现标签，这时候再写创建需求。

## 创建指令要说清六件事，少一件它就自己猜
别只说「帮我做一个总结 Skill」，太空。创建 Skill 的指令里要有六件事：服务谁、什么场景用、输入什么材料、工作流程几步、输出哪些文件、写作要求与禁忌。

可以直接复制这段，把方括号改成自己的：「调用 skill-creator，帮我创建一个『学校工作总结初稿』Skill。这个 Skill 面向【信息中心/教务处/德育处/教研组】使用。使用场景：每学期或每个项目结束时，根据当前工作空间里的资料，生成一份工作总结初稿。输入材料：1. 通知、方案、会议记录；2. 活动照片说明；3. 数据表、成果清单、获奖记录；4. 往年总结或学校模板。工作流程：1. 先清点当前工作空间资料；2. 判断哪些材料适合写进正文，哪些只能作为附件；3. 先列提纲，等我确认；4. 再生成工作总结初稿；5. 最后生成一份人工复核清单。输出文件：1. 工作总结初稿.docx；2. 附件目录.xlsx；3. 人工复核清单.md。写作要求：少写口号，多写事实、数据和具体做法。不确定的数据标注【需确认】。不要编造资料里没有的事实。涉及学生隐私的信息必须提醒我脱敏。」

这段看着长，但很值。岗位、材料、流程、输出、禁忌全说清楚了，它才知道这个 Skill 该干什么。

## 它反问的时候，别一路点确定
收到创建请求后，它通常会先对齐细节：这个 Skill 主要服务谁？输出偏行政汇报还是偏公众号表达？是否需要生成 Word、Excel、HTML？有没有固定模板或示例？哪些内容不能写？

这些问题不要嫌麻烦。它问得越具体，后面生成的 Skill 越少跑偏。回答时写得像「给新同事交代工作」，不要写得像技术说明。

**比如：**「这个 Skill 主要给教务处和教研组长用。输出要偏学校内部汇报，不要太宣传。Word 初稿要保留小标题，Excel 附件目录要有文件名、来源、可用程度、是否需核实四列。如果资料里没有数据，就写【需补充数据】，不要自己猜。」这样写比「生成一份高质量总结」靠谱得多。

## 最后两步：问清它装在哪，再用旧材料试
创建完成后它通常会生成一个 Skill 文件夹，把核心说明写进一个 md 文件。这里有个好习惯：直接问一句「这个 Skill 已经安装到哪里了？请告诉我 Skill 文件夹位置，以及最核心的说明文件是哪一个。」

你不一定要去改文件，但知道它在哪很重要。以后迁移、备份、共享给同组老师，都用得上。

**然后用旧材料测试：**找一份旧总结和一组旧资料跑一遍。真正好用的 Skill 都是试出来的，第一次就定稿的，多半在真实材料上会翻车。哪里不合适，直接跟它说改哪里，比重新做一个更省事。
