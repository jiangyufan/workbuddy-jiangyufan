# 给 WorkBuddy 装上浏览器，它开始自己上网干活了
上周我让 WorkBuddy 去某个电商后台把上个月的订单导出来，做个表。它答应得挺痛快，结果卡在了第一步——登录页。账号密码填进去，弹出个滑块验证码，它对着那个滑块干瞪眼，来回试了几次，最后跟我说：这一步得你来。

那一刻我突然想明白一件事：WorkBuddy 会整理文件、会读表格、会写文档，一双"手"灵活得很。可它这双手真要伸到互联网上去干活，那条腿其实是瘸的。

后来我给它接了个叫 BrowserAct 的东西，这条腿才算补上。下面说的都是我这几天实际跑下来的感受。

1. Agent 卡住的地方，几乎都在浏览器里

你有没有发现，现在的 AI Agent，本地文件玩得转，一上网就容易掉链子。要登录的网站进不去，遇到验证码就停，反爬一拦就报错，多个账号切来切去还会串号。不是它不聪明，是它面对的那个真实浏览器环境，从一开始就不是为机器人准备的——网站们花了很多力气，专门用来挡自动化程序。

BrowserAct 想解决的就是这一层。它给自己的定位是"给 AI Agent 用的真实浏览器执行层"，说白了，就是让 Agent 上网的时候，看起来、行为上都像个真人在操作浏览器，而不是一段一眼就被识破的脚本。

1. 装起来其实就两步

我原以为要折腾环境，结果比想象中简单。它本身是一套开源的浏览器自动化命令行工具，Windows、macOS、Linux 都能跑，也能接 Codex、Claude Code、Cursor，当然还有 WorkBuddy。

第一步，让 WorkBuddy 从 GitHub 上的 browser-act/skills 把这个 Skill 装进来——直接把仓库地址丢给它，它自己会去拉、去配。第二步，填一个 API key。搞定这两步，WorkBuddy 就不只是"能打开浏览器"了，它能在一个真实浏览器环境里接着往下干活。

1. 三种模式，对应三种活

装好之后我发现它内置了三种浏览器模式，不是摆设，是真对着不同场景来的。

第一种是 chrome 模式，直接复用你本地 Chrome 已经登录好的状态。你自己浏览器里登过的公司后台、各种 SaaS、带 SSO 的内网，它借着现成的 cookie 就进去了，不用再啃登录那道墙。我上周那个导订单的活，卡就卡在这儿，换这个模式立马通。

第二种是 stealth 隐私模式，每次会话给你一套全新指纹，配上代理轮换。抓那些反爬凶的公开数据用它——身份一次一换，不容易被盯上。

第三种是 stealth 固定身份模式，稳定指纹、稳定 IP、稳定账号，适合需要长期维持一个身份去登录、去操作的场景。

三种模式换着用，基本覆盖了"上网干活"这件事的大部分情况。

1. 遇到登录，它会停下来等你

这是我最想夸的一个设计。

这个细节看着小，实际很关键。以前 Agent 一遇到登录、验证码就整个任务崩掉，重跑一遍既费时间又费 token。现在它是"挂起等你搭把手"，人只在那一下介入，其余全自动。人机之间的分工，一下就顺了。

1. 我实测跑了两个活

一个是前面说的小红书，它顺利把数据采下来了。另一个更有意思——我让它去看 GitHub 的 trending 榜单，它自己过了 GitHub 的人机校验，把当天热门项目扒下来，还顺手整理成了一个 HTML 页面。

这两个活以前交给 WorkBuddy 自带的浏览器工具，八成会卡在验证或反爬上。现在是它自己想清楚要干什么、怎么拆步骤，BrowserAct 在真实浏览器里把活落地。一个动脑，一个动手。

1. Skill Forge：把一次性实验变成永久工具

还有个功能我觉得对干活的人特别实在，叫 Skill Forge。

它能把你调通的一套网页操作，固化成一个可复用的模板。什么意思。比如我今天摸索出"登录后台—筛选月份—导出订单—整理成表"这一整套流程，跑通一次之后，就能存成一个 Skill，下次一句话就能再唤起来，不用从头教。

对我这种要定时导数据、或者内容创作者反复去找爆文方向的场景，这等于把一次性的实验，变成了一件永久性的工具。用得越久，攒下的这类模板越多，WorkBuddy 也就越顺手。

1. 能力越强，越得给它立规矩

不过我得泼盆冷水。一个能复用你登录态、能过验证码、能反爬的工具，威力有多大，风险就有多大。它能替你登录进公司后台，也就意味着它握着你相当核心的权限；能绕过网站的防护，就得先问一句这么做合不合规、人家的服务条款答不答应。

好在敏感操作它默认要人来确认，这个设计我很认同——上网这件事，交给 Agent 去跑腿可以，但下单、付款、提交这些真会产生后果的动作，最后那一下还是得攥在自己手里。这跟我一直讲的那套 WorkBuddy 用法是一个道理：能力交出去，判断权留下来。

所以我大概会这么用它：WorkBuddy 负责想清楚干什么、怎么拆，BrowserAct 负责真刀真枪把活干成，重要的动作我自己按下最后那一下。至于它俩长期配合下来坑多不多，等我再多跑几个真实任务，回来跟你细说。
