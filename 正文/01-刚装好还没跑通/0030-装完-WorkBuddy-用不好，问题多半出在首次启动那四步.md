# 装完 WorkBuddy 用不好，问题多半出在首次启动那四步
## 装完了却用不好，问题常出在头十分钟
很多人装完 WorkBuddy，第一件事就是丢一句「帮我写个周报」。结果要么权限报错，要么插件装不上，要么它读了不该读的目录。

这些问题基本不发生在使用阶段，全都发生在安装和首次配置那十分钟里。这篇只讲这十分钟该怎么做，不讲用法。

**顺带说清它是什么：**腾讯云 CodeBuddy 团队做的全场景 AI 桌面智能体工作台，内部代号「小龙虾」。以前 AI 只能跟你聊天，它能直接帮你干活——一句话描述需求，它自主拆解任务、规划步骤、调用工具、执行操作，最后交付能直接验收的文档、表格、PPT 或者整理好的文件。

## 装之前先把三个环境备齐
这一条最容易被跳过，也最容易导致后面莫名其妙失败。建议提前装好三样东西。

Node.js（LTS 版）：90% 以上插件的运行基础，安装时一定要勾「添加到系统环境变量」。Git：插件安装和更新要靠它，没有 Git 可能导致插件安装失败。.NET Desktop Runtime：Windows 专属运行库，下载最新的桌面运行时版。

装完这三样务必重启电脑。别嫌麻烦——没重启就继续装 WorkBuddy，后面出的错你很难判断是环境问题还是软件问题。

*三个环境依赖：Node.js 管 90% 以上插件、Git 管插件安装更新、.NET Desktop Runtime 是 Windows 专属运行库*

## Windows 安装：六步，但有一步千万别省
打开官网 codebuddy.cn/work，点「Windows 版本下载」，安装包大约 150–180MB。

双击 WorkBuddySetup.exe 之后，右键以管理员身份运行——这一步很多人省掉，省掉就可能权限报错。选安装路径建议用默认路径，别放中文目录，中文路径可能导致后续插件安装失败。勾选「创建桌面快捷方式」，点「立即安装」；装完勾「立即启动 WorkBuddy」。

**系统要求：**Windows 10 1903 以上（推荐 Win11），内存 4GB 起（推荐 8GB+），硬盘留 200MB 以上。

**还有一条安装前必看：**先把第三方杀毒软件关掉（360、电脑管家这类），否则很可能把它的自动化模块误判成风险程序。

![Windows 六步里最常被省掉的是第 3 步「右键以管理员身份运行」，省掉就可能权限报错](https://workbuddy.jiangyufan.com/uploads/attach/2026/11/20261121/ca45cc141a1d5918aa278a5231836a22.jpg)

*Windows 六步里最常被省掉的是第 3 步「右键以管理员身份运行」，省掉就可能权限报错*

## macOS 安装：四步，重点是那个「无法验证开发者」
同样去官网 codebuddy.cn/work 下载 .dmg 安装包，双击打开，把 WorkBuddy 图标拖进「应用程序」文件夹。

系统要求 macOS 11.0 以上，推荐 macOS 14 以上。

第一次启动如果提示「无法验证开发者」，别去网上找各种破解办法，正经路径是：打开「系统设置 → 隐私与安全性 → 安全性」，在下面找到那条提示，点「仍要打开」。只需要做一次。

## 首次启动四步之一：登录
支持微信、企业微信、QQ 扫码登录，推荐微信，最省事。

第一次登录会赠送算力积分（不同渠道给的数量不一样，以你登录后看到的为准），够先把基础功能跑一遍。

## 首次启动四步之二：文件夹授权，这一步最需要谨慎
登录之后会弹出文件夹访问授权。这是它能操作你文件的前提，但也是最容易出事的地方。

**推荐授权的：**工作目录，也就是桌面、文档、下载这三个。不要授权的：系统盘、隐私文件夹。

最佳实践是单独建一个工作区目录（比如 D:\WorkBuddy），专门用于 AI 操作，跟个人文件做安全隔离。这样它读写范围清楚，你也不用每次提心吊胆。

![文件夹授权三条线：允许授工作目录、不允许授系统盘和隐私文件夹、最佳实践是单建一个 D:\WorkBuddy 工作区做隔离](https://workbuddy.jiangyufan.com/uploads/attach/2026/11/20261121/ba25169026f491b8980305d2a5e870a2.jpg)

*文件夹授权三条线：允许授工作目录、不允许授系统盘和隐私文件夹、最佳实践是单建一个 D:\WorkBuddy 工作区做隔离*

## 首次启动四步之三：模型怎么选
进入左下角头像 → 设置 → 模型选项。

不用一上来就研究参数。新手直接选「自动模式」，让系统按任务复杂度自动匹配就行。

如果非要手动选，记一个粗线：日常办公用响应快、中文优化好的模型；复杂推理、代码理解类的任务，选推理能力突出的。它内部也会写明每个模型适合什么场景，照着场景对就行。

## 首次启动四步之四：快捷键
默认快捷键是 Ctrl + Alt + W，作用是打开/隐藏 WorkBuddy。

这个键值得花一分钟改一下——改成你手顺的组合。因为它的定位是「随时呼出来派活」，如果每次都要去点图标，用着用着你就懒得用了。

## 三种模式，一句口诀就够了
配好之后进主界面，输入框上方能切三种模式。

**Craft 是直接干：**读指令、拆任务、执行、交付。适合任务明确、不需要犹豫的时候。Plan 是先规划：先出方案，你确认后再执行，适合复杂任务怕跑偏。Ask 是纯聊天：只回答和分析，不动任何文件，适合前期咨询。

**口诀四个字：**简单任务用 Craft，复杂任务用 Plan，不确定先 Ask 清楚。
