# 你是哪种人，就从哪一步开始：程序员、打工人、普通用户的三条路
## 它和网页 AI 的差别，一句话：一个只会说，一个能动手
**先问一个问题：**你用过网页版的 AI 吗？那种感觉大概是——在一个网页里打字提问，它回答你，然后你把回答复制出来，粘贴到别的地方用。

挺好用的，但有个限制：它只能「说」，不能「做」。你让它帮忙整理一个 Excel 文件，它会告诉你「你可以这样做、那样做」，然后你还是得自己打开 Excel，自己动手整。

WorkBuddy 不一样。你说「帮我整理这个 Excel」，它就真的去打开那个文件、整理好、保存到你电脑上。你全程不用切窗口、不用复制粘贴。

这就是最根本的区别，也是后面所有用法的前提——它不是搜索框，是办公搭子。

## 它能做的六件事，其实只有三类
官方那张能力表列了六行：读写文件（直接打开你电脑上的文件看完帮你处理，比如「帮我汇总这个 Excel」）、运行命令（「帮我批量重命名图片」）、写代码（「帮我写一个网页计算器」）、画图（「帮我画一张猫咪头像」）、联网搜索（「帮我查今天的新闻」）、记住偏好（「记住周报格式是三段式」）。

看着是六件，其实只有三类：动你的文件、动你的环境（跑命令、跑代码、画图）、动外面的信息（联网搜索）。第三类里的「记住偏好」比较特殊，它不是一次动作，是让后面每一次都更省话。

如果你以前没用过任何 AI 工具，也不用担心。使用方式就是打字跟它说话，跟微信聊天差不多，只不过对面是一个能帮你干活的 AI。

## 你是程序员：三步都在对话框里
如果你平时写代码，它对你来说就是一个能直接干活的编程助手。

第一步，写代码。「帮我在当前目录下创建一个 Vue3 的表单组件，支持排序和分页，用 TypeScript 写，每行加详细注释。」它会在你的项目目录里创建文件、写好完整代码（类型定义、注释都有），需要装依赖它帮你装。而且它有记忆——你之前告诉过它「我们项目用 Vue3」，它就不会给你 Vue2 的代码。

第二步，修 Bug。「我运行 npm run dev 报了这个错：Cannot find module 'vue-router'，帮我看看怎么回事。」它会先去看你的 package.json，复现问题、找到 vue-router 直接帮你装上、再跑一遍确认不报错了。你不用自己开终端、输命令、等结果。

第三步，提交代码。写完直接在对话框里输入 /commit。这里有个提醒：第一次用 /commit 会让你确认 Git 配置，公司用内部代码平台的话要提前配好仓库地址；不想让它自动推送就用 /commit，别用 /commit-push-pr。

## 你是办公打工人：三个场景比写代码还实用
不写代码完全没关系。办公场景下它可能比写代码还实用。

第一步，写周报。「帮我写这周的工作周报。我这周主要做了：1. 完成了季度报告初稿；2. 参加了三次跨部门会议；3. 处理了客户反馈的 15 个问题。语气正式一点，分『本周完成』和『下周计划』两部分。」不满意就接着说「把第二部分展开一点」，它就改。跟普通 AI 的区别在于：普通 AI 给你一个模板让你填，它直接帮你写好；而且它有记忆，记得你上周的周报内容，能让下周的计划跟上周衔接。

第二步，处理 Excel。把文件放到工作目录里，然后说：「帮我看看『销售数据.xlsx』这个文件，按月份汇总一下销售额，做个趋势分析，最后给我一段总结。」它会读取文件、自动用 Python 做处理、生成分析结果。你不用懂 Python，它帮你写、帮你跑、帮你出结果。

顺便解决一个新手常问的问题——怎么把文件放到工作目录？用鼠标把文件拖到那个文件夹里就行，跟平时整理电脑文件一样。

第三步，写文档。「帮我写一份产品需求文档，主题是『用户积分系统』，包含背景、目标、功能列表、优先级排序。」直接给你一份完整 PRD，格式规整。想调就说「更简洁一点」「加一些数据指标」。

## 你是普通用户：不写代码不做报表，同样好使
就是想用 AI 提一下生活效率，也行。

第一步，画图。「帮我画一张可爱的橘猫头像，卡通风格，背景是浅蓝色。」它内置图像生成能力，直接出图。然后可以反复调：「猫的表情再开心一点」——基于上一张图改，不用从头来。

第二步，学新知识。「给我讲讲什么是区块链，我完全不懂技术，用大白话。」它会用通俗语言解释，而且内置了画图工具——不是干巴巴的文字，它会直接在对话里画出概念图、流程图帮你理解。

第三步，做旅行计划。「帮我规划一个周末两天的杭州旅行，预算 2000 块，两个人，喜欢自然风景和小众咖啡馆。」它会给一份详细行程：几点出发、去哪、吃什么、怎么走、大概花多少钱。接着可以说「把预算压到 1500」或者「加一天行程」。

## 三个技巧，能省掉一半的来回
技巧一，先告诉它你的习惯。比如「记住，我们公司的周报格式是『本周完成 / 下周计划』三段式，每周五提交」。说完这一句，以后你只需要说「帮我写周报」，它就按你指定的格式来，不用每次重复说要求。

技巧二，复杂任务先让它出计划。「我想做 XX，你先给我一个计划，我确认了再执行。」它会先分析任务、列出步骤、等你确认，然后才开始执行。这样能避免一大顿操作猛如虎、结果方向全错。

技巧三，一步一步来，别想一句话说完。不要试图在一句话里把所有要求说完：先说大方向「帮我做一个网页落地页」，看到初版后说「把配色改成蓝色系」，再说「加一个用户评价模块」，最后说「把代码整理一下，加注释」。每一步你都能看到中间结果、及时纠偏——比一次性说「做一个蓝色系带用户评价模块加注释的落地页」效果好得多。

## 三句可以直接复制的开场话
看完还是不知道从哪开始？下面三句挑一句复制进去就行。

**程序员：**「帮我看看当前项目目录的结构，分析一下技术栈，然后告诉我有没有可以优化的地方。」

**办公打工人：**「帮我写一份本周工作周报，我这周的主要工作包括：【填入你的工作内容】，要求正式语气，分『本周完成』和『下周计划』两部分。」

**普通用户：**「帮我画一张【描述你想要的图片】，比如一张夕阳下的海边风景画，油画风格。」

**注意这三句话的共同点：**都不是「问一个问题」，而是「派一个活」。从这一句开始，你的用法就从「搜答案」变成了「派任务」。

## 几个新手常问
它收费吗？目前可以免费使用，具体套餐以官网为准。它会上传我的文件吗？文件在本地处理，只有你主动让它联网搜索时才会访问网络。

苹果 M 芯片能装吗？能，Apple Silicon 和 Intel 都支持。完全不会编程能用吗？能，上面「普通用户」那一段就是为这种情况写的。支持哪些模型？默认使用混元，左下角可以切换其他模型。
