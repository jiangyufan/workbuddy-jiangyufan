# 常见问题官方解答：装不上、黑屏、积分、报错怎么办
Q：怎么用专家。

WorkBuddy 内置 100 多个垂直 Agent，进入专家中心按行业分类（设计、工程技术、市场营销、产品、项目管理、质量测试、运营支持、空间计算、专业服务、游戏开发等），每个专家有能力卡片，点击即进入对话直接说需求。专家团是一群 Agent 协作，团长自动拆任务分给不同专家并行跑；注意多个专家同时跑，积分消耗约为单个专家的 3–5 倍。自建专家：点右上角「我的专家」→ 创建专家 → 用大白话告诉它方向。

Q：怎么用技能（Skills）。

WorkBuddy 有完整 Skills 市场：「推荐」是官方精选技能，Skillub 里是大家做的各种 Skill；套件是把一组相关技能打包（相当于 Claude Code、Codex 里的插件）。自建技能：点右上角「添加技能」→ 选「创建技能」→ 用大白话告诉它想实现什么功能。

Q：怎么用连接器（MCP）。

**一句话解释：**把 WorkBuddy 与你日常在用的外部服务打通。最大优势是与腾讯整个生态无缝打通——QQ 邮箱（可直接发送、搜索、整理邮件）、腾讯会议、腾讯文档，还有通达信 MCP；也支持自定义连接器。QQ 邮箱示例：点 QQ 邮箱 MCP → 扫码 → 手机端确认授权即完成。

Q：自动化怎么写。官方示例：

**场景 1 每日早报：**"设置一个每天早上 8:30 的自动化任务：发送一份每日新闻资讯早报到我的邮箱。"

**场景 2 周报自动生成：**"每周五 17:00 自动运行：汇总本周 D:/项目/ 下所有代码提交记录，按模块分类，统计每个模块的提交次数和主要改动内容，生成一份简洁的周报。

Q：怎么用手机遥控电脑发邮件。

## 第一步：微信搜索"腾讯WorkBuddy"小程序并登录（须与电脑端同一微信号），关注"腾讯CodeBuddy"服务号接收通知；第二步：回到 WorkBuddy 对话框输入绑定指令（如"这是邮箱号为 xxxx@qq.com，帮我绑定一下我的邮箱，用于通过 QQ 邮箱本身长期接收和发送邮件"）。授权完成后即可"遥控电脑发邮件"，无需代码和部署
