# 新手用Workbuddy这5招让你效率翻倍!
WorkBuddy · 新手入门。上篇学完了。这5招让你效率翻倍。

切换模式 · 调用专家 · 连接器 · 斜杠命令 · 自动化定时 新手升级必看，真正解锁 WorkBuddy 的全部潜力。

5 进阶技巧。3 工作模式。∞ 效率上限。 欢迎回来。

上一篇你学了 WorkBuddy 的「5步基础操作」——认识界面、说清楚需求、上传文件、等待执行、下载结果。

这篇是续集。同样是新手必学，但这里全是上一篇没讲到的知识。学完这5个技巧，你会发现自己用的 WorkBuddy 跟别人用的根本不是一个东西。

## 技巧一：学会切换3种工作模式。
WorkBuddy 有3种工作模式，很多人用了很久都不知道——选对模式，同样的任务效果差三倍。

![数据分析及可视化](https://mmbiz.qpic.cn/sz_mmbiz_png/ekEkBBHFYcdOJRyR9V3txhI3Yasg55zjXnIp9DveakRdOusbXOJPztWgBLicJUA5lq8Y0LwZic8gjPPn5ViaWdGiaeNAfB5SF42Rsz5ObOibX37U/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=0)

*数据分析及可视化*

Craft 模式 默认。你说，它就干。直接执行任务，读写文件、运行命令、生成结果，一气呵成不停歇。 适合：已经知道自己要什么，让它直接出活。 Plan 模式 谨慎推荐。

先规划、后执行。WorkBuddy 会把任务拆成步骤清单给你看，你确认之后再开始干活，中途不会乱动你的文件。

适合：复杂任务、涉及重要文件时，先看计划再放行。 Ask 模式 只读。只回答问题，绝不修改任何文件。WorkBuddy 进入「顾问模式」，只分析和建议，不动手操作。 适合：想先咨询方案，不希望 AI 直接动你的文件。️ 如何切换模式。

1.。找到输入框上方或对话界面里的模式选择区域。2.。点击 Craft / Plan / Ask 任意一个，即刻生效。3.。每次新建对话时，也可以在开头直接告诉它：「用 Plan 模式」。

新手建议：平时用默认的 Craft 就好。当你要处理重要文件、不确定结果时，切到 Plan 模式，先看计划再执行，避免"好心办坏事"。

## 技巧二：用「专家」解锁垂直领域能力。
WorkBuddy 内置了100多个行业专家——每个专家都有专属的知识体系和工作方式，同一个任务交给「通用AI」和交给「对口专家」，差距会让你惊讶。

![资料库·灵感｜内容创作专家](https://mmbiz.qpic.cn/mmbiz_png/ekEkBBHFYcdqzdpVmcNTpY29WJibfCB6MB09AyvZTkqJicLXZaYiaO521zdclJKpjYDh2IwCiceouwvwiaJmia9pibQdYH9hAdrvq0pMONBiaQibiagm4/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=1)

*资料库·灵感｜内容创作专家*

怎么找到并启动专家。3步操作，专家马上上线。点击左侧边栏的 「专家」 入口（或在界面顶部找到专家中心）。按类别浏览：营销、数据分析、编程、设计、法律、财务……或直接搜索关键词。点击专家卡片 → 「开始对话」，该专家的知识就自动加载进来了。

技巧：写小红书 → 找「内容营销专家」；做财务报表 → 找「财务分析师」；改简历 → 找「职业规划师」。对口专家的回答质量，远高于通用模式。

## ⚡ 技巧三：用「斜杠命令」一键触发专属功能。
在输入框里输入 /（斜杠），会弹出一个命令菜单——这是 WorkBuddy 的「快捷指令」，一个命令顶得上你写一大段描述。

常用斜杠命令速查。/commit。帮你生成规范的 Git 提交信息，开发必备。/review-pr。代码审查，快速定位问题和风险。/clear。清空当前对话上下文，开始干净的新任务。/help。显示所有可用命令的完整列表。/tasks。

查看当前后台运行的任务状态。你 。WorkBuddy 。

我来帮你生成 Git 提交信息 ✅ feat: 新增用户登录功能 - 实现邮箱/密码登录 - 添加 JWT Token 鉴权 - 登录失败错误提示优化。

小技巧：输入 / 后会自动弹出补全菜单，不用全部背下来——看到相关命令直接点就行。随着使用越来越多，你会发现斜杠命令能覆盖你80%的高频操作。

## 技巧四：接入「连接器」，让 AI 操控你的工具。
这是很多人没发现的隐藏能力：WorkBuddy 可以通过「连接器」直接连接到你的其他工具，帮你跨平台操作，真正实现「说一句话，全自动搞定」。

*WorkBuddy 编辑(E) 窗口(W) 帮助(H)｜内容创作专家*

支持连接哪些工具。覆盖办公、开发、内容、数据等全场景。 腾讯文档。 飞书。 GitHub。 金山文档。☁️ 百度网盘。 钉钉。 QQ邮箱。️ Notion。️ 如何开启连接器。点击界面右上角的「连接器」图标（插头形状）。在列表里找到你要连接的工具，点击「授权」或「连接」。

连接器 = 真正的效率倍增器。不用在不同工具之间来回切换复制粘贴，一句话让 WorkBuddy 帮你打通所有工具。

## ⏰ 技巧五：设置「自动化」，睡着了它也在干活。
WorkBuddy 最让人惊喜的功能之一——你可以设置定时任务，让它按照你定的时间自动执行，完全不需要你操心。

![+ 新建任务](https://mmbiz.qpic.cn/mmbiz_png/ekEkBBHFYcfYjEQHU7fvkEbAyzHPs9PLksHNVB8cicuLm6pqRFOrllMCZkIMkpicaqMfFXfh4lAu59mjBchPVpTwPBDZChDWRFuauQrZtRqkM/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=3)

*+ 新建任务*

自动化能做什么。重复性工作，全部交给它。每天早上 8 点 → 自动生成今日工作简报，发送到指定地方。每周一 → 自动拉取上周数据，生成周报图表。指定时间 → 一次性提醒，到点就执行某个任务。每月初 → 自动整理上月内容数据，输出分析报告。⚙️ 设置一个定时任务。

最简单的方式：直接在对话里说，WorkBuddy 会自动帮你配置好。帮我设置一个每天早上9点的自动化：总结昨天的工作内容，生成一份简短的日报。

好的。我已为你创建了一个每日自动化任务 ✅  执行时间：每天 09:00  任务内容：整理并生成前一天工作日报 从明天起就会自动运行，不需要你手动触发～。

⚠️ 设置前想清楚：自动化任务会按时自动执行，如果涉及发消息、写文件等操作，确保指令描述准确，避免自动干了你不想要的事。

新手实用场景：每天早上设置一个「提醒我今天要做什么」的定时任务，让 WorkBuddy 帮你启动一天的工作节奏——这比任何闹钟都管用。
