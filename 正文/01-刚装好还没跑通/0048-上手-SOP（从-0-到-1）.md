# 上手 SOP（从 0 到 1）
明确核心场景（约 1 小时）：回答三个问题——我每天重复做的工作是什么。我的知识资产散落在哪里。如果有助手，我希望它帮我做什么。

搭建 ima 知识库（约 2 小时）：下载 ima（应用宝或官网）→ 按场景建多个库 → 导入内容（微信一键导入 / PC 批量拖拽 / 链接导入）→ 用 AI 问答验证。

配置 WorkBuddy（约 30 分钟）：下载 WorkBuddy（官网 workbuddy.cn）→ 微信/企业微信扫码登录 → 授权需要操作的文件夹 → 安装常用 Skills。114。

设计联动工作流（约 1 小时）：画出"输入（ima）→ 处理（WorkBuddy）→ 输出（文件/发布）→ 归档（ima）"。

**迭代优化（持续）：**记录耗时和卡点 → 把重复步骤封装成 Skill → 新知识归档到 ima → 两周后回顾效率提升。

**两条心法：**知识库不用一开始就建得很全，用到什么建什么，慢慢来。15 配置完成后立即把最近正在处理的一份文档整理存进 ima，切忌雄心勃勃一次迁移所有历史资料，容易因挫折而放弃；建议从一个核心小型知识库开始，持续做"喂养-调用"闭环。

**边界提醒：**这套组合更适合已有散落资料需要系统化复用、工作依赖查旧资料重组产出的场景，不适合期待自动学习思维模式、无分类堆砌文件以及处理敏感数据的场景。 另外需注意，ima 网页版功能被阉割严重——可以基于已有知识库提问，但不能创建知识库，建库必须下载客户端。
