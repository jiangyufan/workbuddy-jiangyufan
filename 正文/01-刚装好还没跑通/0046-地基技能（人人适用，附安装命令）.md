# 地基技能（人人适用，附安装命令）
## 1. skill-vetter（安全审查）
**真实名称：skill-vetter（Skill Vetter）**。

**作用：安装其他技能前做安全审查，检查可疑依赖、硬编码密钥、奇怪脚本。**

**安装命令：clawhub install skill-vetter。**

**使用场景：装第三方 Skill 前先扫一遍。**

**实测/数据：全球下载量前列，18.2 万次。**

## 2. tavily-search（联网搜索）
**真实名称：tavily-search**。

**作用：让 AI 实时联网搜索，不再凭记忆"瞎说"。**

**安装命令：clawhub install tavily-search。**

**使用场景：写文章查数据、做竞品调研、确认时效性。**

## 3. agent-memory（永久记忆）
**真实名称：agent-memory**。

**作用：记住你的偏好、纠正过的错误、做事习惯；默认每次对话 AI 是"失忆"状态。**

**安装命令：clawhub install agent-memory。**

**实测效果：连续用两周，改稿时间从 30 分钟降到 5 分钟。**

## 4. agent-browser（浏览器自动化）
**真实名称：agent-browser（Agent Browser）**。

**作用：像真人一样打开网页、滚动、点按钮、截图、填表，对付动态加载网站。**

**安装命令：clawhub install agent-browser。**

**使用场景：抓取 36kr、少数派、机器之心等首页新闻整理成行业早报；表单填表、招聘简历批量检索。**

**实测/数据：全球下载量前列，21.9 万次；有实测称每日节省 37 分钟。**

## 5. self-improving-agent（自我进化）
**真实名称：self-improving-agent**。

**作用：任务完成后自动复盘哪里做得好、哪里要改进、你的修改习惯是什么。**

**安装命令：clawhub install self-improving-agent。**

**实测效果：连续写 5 篇文章，第一篇改 12 处，第五篇基本一次过；另有实测称减少 83% 修改时间。**

**数据：全球下载量第一，48.2 万次。**
