# 多 Agent 并行工作

> **说明：** 本篇是产品动态/短记录，原文本身只有简短说明和配图，不含完整操作步骤。它被收录是因为记录了当时的界面或功能变化，可作为版本对照；需要完整流程请到对应章节找长文。
**是什么：WorkBuddy 可将复杂任务智能分解，调度多个 Agent 窗口同时执行。**

**怎么操作：**

输入复杂任务指令 → AI 自动拆解为多个子任务，智能识别可并行子任务，自动分配最优 Agent 组合。

多个 Agent 在独立窗口中同步执行，结果实时汇总合并到主对话；支持 2–5 个 Agent 同时并行。

合并阶段由主 Agent 自动合并各模块成果，并智能检测、修复合并冲突。

**适合场景：**真实工作中"多线并进"的复杂局面，如多模块并行开发网页（Agent A 做 UI/样式、Agent B 做交互逻辑、Agent C 做数据接口），串行约 15 分钟的任务并行约 3 分钟完成，效率提升约 5 倍。产品官方也将其列为四大核心能力之首——"多任务并行处理与统一看板管理" 。
