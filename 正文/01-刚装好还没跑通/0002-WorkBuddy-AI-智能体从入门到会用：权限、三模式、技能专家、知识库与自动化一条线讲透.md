# WorkBuddy AI 智能体从入门到会用：权限、三模式、技能专家、知识库与自动化一条线讲透
腾讯出品的这个 AI 智能体适合绝大多数职场人。这篇把它拆清楚：怎么入门，如何会用，以及怎样用它真正提高效率。

它由腾讯云代码助手团队开发，底层支持多模型路由，能访问本地授权文件夹，支持多个 AI Agent 并行工作、同时处理多个子任务。

大多数人用 AI 智能体的方式还停留在用搜索引擎：提出问题，智能体回答，然后自己再去做。这是聊天机器人的逻辑。WorkBuddy 作为 AI 智能体（AI Agent），具备自己拆解任务、调用工具、操作本地文件、生成成果、保存到指定位置的能力，全程半自动化，对于循环任务甚至不需要你动手。

同一句「帮我整理这 50 份合同」，聊天机器人给你的是一份操作步骤——打开 Excel、手动复制、排序，结果还是你自己动手做；WorkBuddy 是自动打开文件、提取信息、生成 Excel 并保存到桌面，直接交付可验收成果。

适合它的人很明确：需要频繁处理文档、数据、报告的角色——产品经理、运营、分析师、行政、HR，以及任何一个想把重复劳动外包给 AI 的人。反过来说，只需要简单问答的场景，网页版或元宝这类 App 更合适；对数据安全有严苛要求、不允许数据出网的场合，也不适合。

## 登录与权限：起步就把范围收小
**登录支持两种方式：**微信扫码登录（推荐），或手机号加验证码。

登录成功后会要求对文件夹的访问进行授权。建议只授权常用的文件夹目录，以便对安全性做最小化的约束。完成授权后，将来有需要可以在「设置—文件夹权限」里修改授权范围。

**权限有两个模式：**「默认权限」和「允许完全访问」。刚开始使用建议留在默认权限，所有操作都在安全沙箱约束内进行，超出范围会请求你的允许；熟练之后，或者在完全理解工作场景之后，再切换为完全访问，以便保持工作流的流畅性。

## 三个必设项：让它越用越趁手
除了权限，另一个需要调整设置的地方（点头像进设置）是「自定义指令」「对话记忆」「技能自动更新」。这三项是好不好用、以及能不能随着使用迭代成更趁手工具的关键。

对话记忆打开，它能从长期的对话中学习你的习惯；技能自动更新保持 Skills 是最新版本；自定义指令则是给它定下行为总则和对你自己的「认知」。

自定义指令可以直接参考这套模板：先理解目标、输入输出、限制条件再动手；如果需求不明确就问清楚；用最少步骤解决当前问题，不加未要求的功能；如果存在更简单的方法就坚持己见；遇到困惑要停下来，指出不清楚的地方，不要默认假设；只改完成任务必要的内容；每次修改后说明改了什么、为什么、如何验证。

整个自定义指令按自己的具体需求增减，尽可能简洁、描述清楚。

## 界面导航：左侧栏每一项是什么
左侧栏的快速导航分几块。助理：可连接微信、QQ 等，把手机消息接进来；项目：新建项目、项目管理、多人协同合作；专家、技能、连接器：100+ 垂直领域专家角色选择、Skills 扩展包安装、第三方工具集成管理；自动化：管理定时任务和触发规则；更多：接入腾讯文档、IMA 知识库等。

对话区中部是三个场景入口：日常办公、代码开发、设计创意。三个能力侧重不同——日常办公覆盖文档处理、可视化数据分析、深度研究、幻灯片制作；代码开发覆盖轻量级脚本开发、网站开发、skills 开发；设计创意覆盖网站设计、原型设计、品牌创意设计。每个入口点进去都有预置提示词模板，把字段换成自己的需求改两下就能启用，对刚接触的新手很友好。

还有一处是「项目文件夹」。任务开始前先选一个本地目录，选定工作目录后对话的读写都将在这个文件夹中进行；不选会默认加载在系统目录，任务完成后可以归档到某个工作空间。归档之后，左侧任务列表、空间目录、本地对应位置都能找到。为了方便管理各文件，从一开始就把分类做好，是个不错的前期动作。

任务跑起来后，右侧栏会实时更新一个 todo 清单，显示当前走到哪一步、下一步做什么，进度一目了然。

## 三种工作模式：Craft、Plan、Ask
WorkBuddy 提供多个工作模式，按需求选，且不同模式对应的 token（积分）消耗量不同。

Craft 是默认模式，分步确认执行。适合明确知道要干什么、结果可预期的任务，也是日常最常用的。例如「把目录中的数据合并成一张表，输出为 Excel，加上数据透视图」。

Plan 模式先规划后批量执行。适合步骤复杂、涉及多跨度文件、容错成本高的任务，它会先输出一份执行计划给你看，确认方向正确后再执行。例如「把过去一年的交流记录、方案、笔记整理成案例库，按行业分类，每个案例提取背景、痛点、解决方案、结果数据」。

Ask 模式只查资料，类似搜索引擎，不涉及本地文件操作。适合调研、问问题、理清思路。例如「帮我梳理国内 AI 安全公司的大模型防火墙定价模式，列出各自的适用场景和核心逻辑」。

同等任务下的 token 消耗：Craft 介于其他两个之间，Ask 最少，Plan 消耗最大。一句话总结——容易实现的简单操作或重复操作选 Craft，复杂程度大且自己理不清的任务选 Plan，提问回答选 Ask。

## 怎么描述需求，决定输出质量
刚开始用时，怎么描述需求，直接决定输出和返回内容的质量。描述得越详细，质量越高，越接近想要的结果。

对比一下就明白。差的写法是：「帮我写一个关于本季度的人工智能安全工作的总结。」好的写法是：「读取附件的所有每日工作日志、会议记录、项目文档，按照完成事项、产生的成果、遗留待解决的问题写一篇围绕人工智能安全的季度工作总结报告，要求 1500 字，行文涉及的数据严谨计算不编造，用 Word 以 docx 格式输出。」

差别不在字数，在于数据从哪来、结构是什么、约束有哪些——这三件事说清了，它就不用猜。

## 技能市场：把通用能力换成专项能力
Agent 默认的能力有限，拥有的都是普适的通用能力和框架。要让它具有更强的能力，需要安装技能扩展。

**使用方式：**左侧栏点「专家、技能、连接器」，选择需要的专项能力安装；已经安装的技能，在对话框输入斜杠就能调用。

技能市场里已经有不少实用能力：腾讯地图助手（AI 旅行规划）、NeoData 金融搜索、腾讯自选股金融数据、MarkItDown（文档转 Markdown，支持 PDF/Word/PPT/图片 OCR/音频转写）、Excel 文件处理、Web Access（直连本地 Chrome 联网）、IMAP/SMTP 邮件、Word 文档生成、腾讯文档在线云文档平台。

如果技能市场找不到想要的，或者已有的不满意，可以自己做一个：在右上角「添加技能—创建技能」，描述清楚需求就能生成属于你自己的 Skills。

## 专家模式与专家团：人设＋方法论＋工具链
专家就等同于专项的子 Agent，专家团则是多子 Agent（Multi-Agent）协同工作——它们会根据规则调用对应的 skills 和 MCP，针对规划好的要求进行工作。

两者结构不同。专家是角色切换：用户指向一个专家（比如数据分析师），用分析师视角处理，然后交付结果，积分消耗是标准；专家团是协作执行：用户指向团长，团长拆解任务，分给分析师、设计师、文案并行处理，最后整合交付，积分消耗是 3-5 倍。

WorkBuddy 内置了多个垂直领域专家角色，支持按属性分类浏览：OPC 一人公司、生活服务、开发工具、教育学习、投资理财、效率工具、办公协同、商业运营、数据分析、知识与学习、产品设计、技术工程、腾讯专区、数据智能、营销增长。

专家不只是「换个名字、换个人格的噱头」，而是给子 Agent 预加载对应领域的专业提示词、领域知识和工具权限组合，是用【人设＋方法论＋工具链】让 WorkBuddy 以特定领域专家身份执行任务。

## 知识库集成：让它知道你的标准
WorkBuddy 目前支持的知识库有腾讯自家的 IMA、腾讯文档、云盘，以及企业级的乐享知识库。

知识库的作用相当于你的知识储备。遇到相关问题时，Agent 知道你的标准要求、答案是什么，并按照标准来输出和回答。

接入腾讯文档的方法（其他类同）：左侧栏进入知识库，选腾讯文档，授权腾讯文档账号，选择需要接入的文档或文件夹。完成后可在实际任务中直接引用。

## 接入微信、飞书、钉钉：24 小时随叫随到
之前「养龙虾」热过一阵，WorkBuddy 也紧跟更新了 IM 调用的功能，让它不再局限于开电脑时的生产力，而是化身成一个 24 小时随叫随到的助理。

**适用场景很具体：**在外面不方便开电脑查某个表格；需要立刻记录拜访客户的情况；需要立刻记下此刻的想法和看到的内容；应酬完了才想起来要写周报。这些情况下，一个消息就能让它帮你完成。

**有一个前提必须注意：**运行 WorkBuddy 的电脑需要开着，且不能处于休眠模式。

**接入方式：**微信走左侧功能区「助理—设置」，打开里面的两个远程开关，手机微信扫码进入授权登录；飞书和钉钉走「设置—账号绑定—飞书」，需要飞书、钉钉管理员权限创建机器人，获取 Webhook 地址填入 WorkBuddy 设置。

## 定时自动化：把重复动作交出去
作为工作助手，用自然语言描述时间规则就能创建想要的自动化任务。任何需要重复且频次高的动作，都能借此释放双手。

**它的链路是四段：**配置任务（名称加提示词、选模型和技能、设定时规则）→ 定时触发（每天某点、每周某天、或单次指定时间）→ 自动执行（Agent 自主运行，按 prompt 执行，无人值守）→ 交付（保存到目录、推送小程序、查看记录）。

创建也很简单：可以去左侧的「自动化」点添加，也可以在聊天窗口里按自己的需求描述，让 Agent 自动帮你生成并添加。两个例子：例一是「每周五下午 20 点，把本周完成的任务整理成不少于 300 字的周报，保存到桌面周报文件夹，按年月日命名，同时发到我的邮箱」；例二是「每天早上 9 点，抓取某网站新闻和财经资讯，生成一份 500 字金融信息摘要，保存到 Desktop/finance，以当天年月日命名，完成后发给某人」。

如果需求有变更，可以在「自动化」里查看所有已创建的定时任务，并对它们开启、暂停、删除、手动触发（立即执行，不用等执行时间）。

## 模型选择：不选最强，选最合适
为什么还要选模型？因为大模型就像不同的脑子和不同的智力，模型之间有参数大小和版本差异，这些差异就像各自擅长的方向不同。所以选择的标准不是「最新、参数最大」，而是「最合适」。

WorkBuddy 支持一键切换大模型，选对了效果更好且更省钱。在不了解各模型实际长项、也还没形成自己的理解之前，默认用 Auto 模式就能合理调用最符合的模型。

大致的能力分布（仅供参考）：GLM-5.2 好用、非常好用，也非常烧钱，擅长代码编写和审计；DeepSeek V4 Flash/Pro 样样通、均衡省心，适合日常办公；KIMI / GLM 支持超长上下文，处理长文档、大型文件更轻松。

如果不想用内置模型，也支持自带 API Key 接入，遵循 OpenAI 协议的接口在「设置—模型—添加模型」里添加自定义模型。

**关于成本：**过了推广阶段，送的积分不足以应付大量使用和长期调用，这时可以购买付费套餐，或者自己购买所需的大模型套餐后用 API 调用。建议先买体验版，对消耗量做一次评测估算，看清自己的使用情况再决定是否升级。

## 三个实战举例
例一，数据清洗与分析。需求是填报不规范的 Excel 需要清洗和分析，用 Plan 模式。指令要写清三件事：附件是多份原始填报数据，存在日期格式不统一、重复行、部分身份证为空的问题；请先清洗，日期统一为 yyyy/mm/dd，同表内重复行只保留一条，身份证空值用红色色块标注；再以年级为单位生成汇总表，统计每个年级总人数。

例二，邮件批量发送。需求是给 50 个客户发内容定制化的邮件。附件 client.xlsx 里有 50 个客户的公司名、上次购买产品、购买日期、邮箱地址，要求称呼用客户姓名、提及即将授权到期的产品，并按附件中模板.docx 的格式起草续费提醒邮件，完成后分别发送；所有邮件汇总成一个 Excel，每行一封，含发件人邮箱和邮件正文两列。

例三，PPT 一键生成。基于附件「工作报告.docx」做一份工作汇报 PPT，分几个大板块：准备工作情况、实施里程碑、交付内容汇总、遗留待解决问题、上次问题解决情况；风格简洁专业，蓝白简洁配色，不少于 10 页。

**这三个例子有个共同点：**都是把「要它做什么」写得像一份可验收的施工要求，而不是一句愿望。
