# 把 WorkBuddy 界面走一遍：左边五个入口、中间三个分类，还有那个没人逛的灵感页
## 先说清它跟以前的 AI 差在哪
WorkBuddy 是腾讯出的一款 Agent 产品。简单理解：以往我们用的 AI 都是对话式，它可以直接执行任务并交付结果。

举个例子最直观。「帮我生成 1 个个人简历的网页」——之前的 AI 会给你一堆代码，需要你自己去复制、去执行；它会直接把网页生成好给你。

差别不在聪明程度，在交付形态。前者交付的是一段文本，后者交付的是一个能打开的文件。这篇文章就把它的界面走一遍，省掉你翻官方文档的时间。

## 左侧导航：三件小事和五个大入口
先看左边。顶部有三个小图标：收起、搜索、筛选。任务多了以后这两项特别有用——搜索能快速找回某个任务，筛选能按状态和时间段把任务筛出来。

**筛选项分两组：**状态（全部状态 / 进行中 / 已完成 / 失败 / 待处理 / 规划中）和时间（全部时间 / 今天 / 最近 7 天 / 最近 30 天），底部还有「重置筛选条件」。

**往下是五个大入口：**新建任务、助理、项目、专家·技能·连接器、自动化，再往下一个「更多」。

「新建任务」就是新建一个独立的单任务，跟其它任务毫无关联。「助理」是它的远程控制功能——简单理解就是拿手机控制电脑：手机上发指令，电脑端直接干活。可接入的助理有微信、微信小程序、微信客服号、企业微信、QQ、元宝、飞书、钉钉，进去找到助理集成，点右边「配置」就行。

## 任务和空间是包含关系，不是并列关系
**左侧下方能看到两层：**任务和空间。这两层很多人一开始搞混。

**用一句话记住：**空间 ⊃ 项目 ⊃ 任务。一个空间可以装多个项目，一个项目里可以有很多任务。如果你每天干的是同一类活，把它们放进一个空间，比散在任务列表里好找得多。

「更多」里还有一个容易被忽略的入口：我的文件。那是空间任务执行后生成的文件，可以同步上传到云端网盘，用来跨端查看和同步。

## 专家、技能、连接器：三个词各管一件事
这三个词在同一个入口里，但分工清楚。

专家，是「谁来做」。右上角有搜索，可以直接找你需要的专家；也可以点「我的专家」自己创建一个。创建时它自己给了句式：「帮我创建一个 XXX 专家，擅长 XXXX。我的经验是：【补充你的行业背景、相关经验】」。

专家团是多个专家的组合。比如你要做软件开发，不需要单独添加工程师、产品经理、架构师好几个专家，直接添加一个「软件开发团队」专家团就可以——产品经理定需求、架构师设计拆任务、工程师实现代码、QA 验证质量，一条线跑完。

技能，是「能干什么活」。分析数据、绘画、做视频等等，都是技能。它做了很细的分类，同样可以搜索、可以上传自己的技能，也可以用 skill-creator 自己创建。里面的 SkillHub 就是技能商店，套件则是把多个技能封装到一起，思路跟专家团一样。

连接器，是「接到哪些外部服务」。通过配置连接器，它能直接访问和操作第三方服务——腾讯文档、ima 知识库、乐享知识库、腾讯会议、企业微信、飞书、钉钉、腾讯问卷、TAPD 这类。连接器跟助理一样需要授权，授权页会明确列出「读取文档与内容」「编辑与管理文件」两项权限范围。

## 自动化：把周期性重复动作交出去
自动化按设定时间自动执行周期性、重复性的任务。刚进去会看到一排模板：每日 AI 新闻推送、每日 5 个英语单词、每日儿童睡前故事、体检预约提醒、可爱萌宠手机壁纸、会议前提醒整理议题……也可以完全按自己需求新建一个。

配置时有几个点值得看一眼。一是「周期」，分按间隔和单次；二是「生效日期区间」，留空表示永久生效；三是「推送到 WorkBuddy 微信小程序」这个开关，打开之后手机上收结果更方便。

还有一项「连接器」勾选——勾上即授权该连接器在这个任务里免确认使用。想让它自动跑不卡在确认弹窗，就得在这里勾。

## 中间工作区：三个分类和输入框
**右边主区域顶上分三类：**日常办公、代码开发、设计创意，需要哪个选哪个。日常办公下面还有更细的：文档处理、数据分析及可视化、金融服务等。

然后是输入指令的区域。这里有个细节很多人没注意：点「+」号能添加文件，而它能加的地方不止本地——本地文件、我的云端网盘、腾讯文档、ima 知识库、乐享知识库，五个来源都在同一个菜单里。

同一个「+」菜单里还挂着模式、专家、技能、连接器四项，等于把「用什么方式干、谁来干、用哪个技能、连哪个服务」全放在了一个入口。

引用对话中的文件，就是引用之前在对话里生成过的文件。可以通过「+」号引用，也可以直接在指令区用 @ 引用。

## 默认权限分三种，别一直用最松的那个
输入框右下方那个「默认权限」，点开有三种：计划模式是先规划、确认之后再执行；仅问答是不执行、只回答问题和找思路；默认模式是直接执行。

**日常建议用默认模式：**它在工作空间内高效执行任务，遇到高风险操作时会先停下来向你确认。你可以把它理解成一层安全护栏——平时不挡路，真要越界或执行危险动作时才拦一下。

至于后面的专家、技能、连接器，前面说过，需要谁直接选就行；技能也可以直接在指令区输入 / 调用。

## 模型：简单任务用便宜的，新手用 Auto
不同模型能力有差异，但更实用的判断标准是消耗速度：数值越大 = 消耗的 Token 越多 = 越贵。

所以简单任务选消耗速度低的模型就够，复杂任务再选高的。新手直接选 Auto，让它自己匹配。

模型也可以自定义配置，不过那是后面的事，先把界面走顺再说。

## 工作空间：选哪个盘，文件就住哪个盘
工作空间就是它干活的地方。比如你在 F 盘建了一个 WorkBuddy 文件夹，工作空间选它，它就在那里工作，不会影响其他盘符和文件夹，同时生成的文件也保存在那个文件夹里。

**这里有个坑要说清楚：**「新建工作空间」和「打开本地文件夹」是两回事。新建的话，它默认会把文件夹建在 WorkBuddy 安装的那个磁盘里——如果软件装在 C 盘，工作空间也就默认在 C 盘，白白占系统盘空间。所以更推荐「打开本地文件夹」，自己指定一个位置。

实在不想选，还有「不使用工作空间」。但这就等于放弃隔离，一般不建议。

## 还有一处很值得逛：灵感
左侧「更多」里有个「灵感」页，副标题写的是「常见工作流沉淀成可复用的任务起点」。

里面是一堆别人做好的成品，按全部、精选、办公协同、投资理财、内容创作、数据分析、效率工具、开发工具、知识与学习、信息与资讯、商业运营、旅行出行分类。比如「团队 OKR 雷达图」「实时协作白板原型」「交互式年度数据报告」「大理古城民宿推荐」「今日 AI 日报一键生成」。

每个卡片都能看到它做什么、是什么形态（标着 HTML 的多），也可以一键生成同款。对新手来说，这是最快理解「它到底能做出什么东西」的地方——比读功能说明直观得多。
