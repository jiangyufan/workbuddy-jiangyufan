# 常见问题排查

> **说明：** 本篇是产品动态/短记录，原文本身只有简短说明和配图，不含完整操作步骤。它被收录是因为记录了当时的界面或功能变化，可作为版本对照；需要完整流程请到对应章节找长文。
"搜索显示 0 条"按此顺序排查：①确认文件已上传至 ima 知识库内部，而非仅在临时对话里；②等待解析完成（通常 1～3 分钟）；③核对 Client ID、API Key 及绑定的知识库名称是否绝对准确，特别注意首尾不要留空格、特殊字符（如 + / =）被正确粘贴；④在对话框发送"刷新 IMA 知识库缓存"。

提示"连接失败"或"未授权"：核对凭证完整性 → 确认生成凭证的 ima 账号在浏览器或客户端处于正常登录状态、未过期 → 在 WorkBuddy 里发送"查看 ima 配置"核对绑定信息。

**模式选择（影响安全性）：**Plan 模式用于重要文件修改、复杂数据计算等高风险操作，先规划再确认执行；Craft 模式用于常规文件归档、内容追加，直接执行效率最高；Ask 模式最保守，每次操作前都会询问，适合初期试用。
