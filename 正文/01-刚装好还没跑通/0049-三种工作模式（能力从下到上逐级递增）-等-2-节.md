# 三种工作模式（能力从下到上逐级递增） 等 2 节
模式 ｜ 说明 ｜ 适用场景。

问一问（Ask） ｜ 仅问答与信息查看，不修改文件 ｜ 了解内容、确认需求、纯聊天。

做一做（Craft） ｜ 直接执行任务并修改文件（默认模式） ｜ 文档生成、表格处理、文件整理。

想一想（Plan） ｜ 先生成执行计划，确认后再操作 ｜ 多步骤任务、需审阅改动范围。

特别注意：WorkBuddy 默认是 Craft 模式，随便发一条消息就直接开干并开始消耗积分；只想聊天先切 Ask，没想清楚怎么做就切 Plan。

**模型：**内置绝大多数国产大模型（腾讯混元、DeepSeek、GLM、Kimi 等），不同模型消耗积分不同；官方教程作者直接推荐 DeepSeek V4 Pro。接入外部模型可走「设置 → 模型页面 → 添加模型」，兼容 OpenAI 协议的 API 都能接。

**权限：**默认权限（遇到高风险操作先停下来问你）和完全访问权限两种。

**上传文件：**右侧加号可上传本地文件、腾讯文档以及知识库，与 ima 知识库全面打通。

**工作空间：**可理解成项目文件夹，WorkBuddy 基于该目录读取和处理文件；任务完成后也可再存进工作空间，保存后能开启多个 agent 同时协作。
