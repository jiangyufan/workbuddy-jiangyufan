# 零基础也能写代码：不会语法，用中文把活干完
## 「我不会写代码」这句话，拦住了多少人
每次在讲座上提到写代码三个字，台下至少有一半人开始低头看手机。不是不想学，是真的不敢碰。一提到代码，脑子里蹦出来的就是满屏的英文、乱七八糟的符号，还有程序员那种「这你都不懂」的眼神。算了吧，太难了。

但写代码这件事已经变了。在 WorkBuddy 面前，不会写代码不再是障碍——你只需要用中文说清楚你想干什么，它帮你把代码写好、跑通、改对。

先把编程这个概念还原一下。编程说穿了就是用计算机能理解的语言告诉它你要干什么。以前你得学 Python、JavaScript、HTML 这些外语，现在 WorkBuddy 做了翻译：你把中文给它，它翻译成代码给电脑。

这跟用翻译软件跟外国人聊天是一个道理。区别在于，普通翻译软件只管翻译，WorkBuddy 翻译完还能帮你跑一遍，跑不通它自己能改。

## 三种语言三个场景，你不用记
Python 管处理数据和自动化任务——批量改名、分析 Excel 这类。JavaScript 管网页交互和浏览器插件——给网页加个按钮这种。HTML 管网页结构和排版——生成一份电子报告。

你不用记这些。跟 WorkBuddy 对话的时候，它会自己选最合适的语言，你只需要说需求。这一点很重要：很多人卡在「我该学哪个语言」上三个月，其实这个问题在开始动手之前根本不需要回答。

## 上手第一件事：Hello World
编程圈有个传统，学任何语言第一个程序都是 Hello World——在屏幕上打印一句你好世界。我们也走一遍这个仪式。

打开 WorkBuddy，在对话框里输入：「帮我用 Python 写一个 Hello World 程序，并运行给我看。」几秒钟之内，它会自动创建一个 .py 文件，写上 print("Hello, World!")，然后自动运行，屏幕上出现 Hello, World!

恭喜你，你已经写了人生第一行代码。虽然不是亲手敲的，但这是你的想法、你的指令、你的成果。从今天起，你就是能用代码解决问题的人了。

**核心认知：**用 WorkBuddy 写代码，你扮演的是指挥官的角色。指挥官不需要会开坦克，他只需要知道什么时候该上坦克。

## 出错了怎么办：让 WorkBuddy 自己修
写代码最烦的就是报错。以前你在网上抄一段代码，贴进去跑，满屏红字看都看不懂，只能再上网搜怎么改。

WorkBuddy 的处理方式极其简单：你把报错信息原样贴给它，加一句「帮我看看哪里错了」。它会把错误原因用人话给你解释一遍，然后自动改好。

举个例子。你让它帮你写一个读取 Excel 的脚本，它写好了，但运行时发现你没安装对应的库，报错了。你不用去搜「怎么装 pandas」，直接说：「运行报错了，提示 ModuleNotFoundError，帮我装好依赖再重新跑。」它会自动检测缺少什么、安装好、再跑一遍，你就在旁边看着就行。

这还没完。写代码时遇到不懂的地方，直接问它「这段代码是什么意思」，它会像老师一样一行一行给你解释。

所以 WorkBuddy 的代码模式有三种用法：生成——你说需求，它写代码；调试——你贴报错，它改代码；解释——你不懂代码，它当翻译。三个用法覆盖了从零到跑通的全部环节。

## 实战：写一个文件批量重命名器
光说不练假把式。做一个真实有用的小工具：文件批量重命名器。

**场景是：**你有一个文件夹，里面几十张照片都叫 IMG_001.jpg、IMG_002.jpg，你想把它们改成北京旅游_001.jpg、北京旅游_002.jpg，一个个手动改要累死。

在 WorkBuddy 里输入：「帮我写一个 Python 脚本：把 D:\照片文件夹 里所有 jpg 文件按顺序重命名为北京旅游_001.jpg、北京旅游_002.jpg……请先列出会改的文件名让我确认，再执行。」

注意指令里最后那句「请先列出会改的文件名让我确认，再执行」。它会先生成一个预览列表，让你确认改之前和改之后的样子，你觉得没问题了才开始真正改名。安全、可控、快——这一步是必须加的，不然批量操作一旦出错很难回滚。

**你还可以换花样：**让它按修改日期排序后重新命名，或者只改某天之后拍的照片，或者把 PNG 也一起改。想怎么来就怎么说。

有没有发现？你根本没学 os.rename、for 循环、文件路径这些概念，但做到了一件纯靠手动做不到的事。这就是 AI 编程的真正意义。

## 你还能让 WorkBuddy 写什么
抛几个方向打开想象力。网页生成器——「帮我做一个课程表页面，带颜色区分不同科目，可以导出 PDF」，纯 HTML，打开就能用。

数据可视化——「把这份学生成绩 Excel 画成柱状图，对比各科平均分」，图表秒出。

自动化脚本——「每天下午 5 点，自动把今天新建的文件打包压缩，存到 D:\备份」，解放双手。

小游戏——「帮我写一个猜数字游戏，网页版，有提示太大太小的功能」，好玩还能秀。

**记住一个原则：**凡是重复性的、规则化的、大量处理的事，都可以让 WorkBuddy 写代码搞定。你不用关心代码怎么写，你只关心事情做没做好。

## 三点提醒，少走弯路
第一，指令越具体越好。「帮我写代码」不行，「帮我把这个 Excel 里的第 3 列转成大写」行。

第二，大胆试错。WorkBuddy 写的代码如果没达到预期，继续对话、继续调整，它不会烦你，改到满意为止。

第三，别急着学语法。很多人一听说自己能写代码了，赶紧去找 Python 教程。不用。先用 WorkBuddy 写出 100 个小工具，等你发现「我确实想深入理解了」，再来学语法也不迟。

**今天最核心的一句话：**你不是不会写代码，你只是需要一个能把中文翻译成代码的人。
