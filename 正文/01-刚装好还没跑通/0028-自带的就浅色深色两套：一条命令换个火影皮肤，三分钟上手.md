# 自带的就浅色深色两套：一条命令换个火影皮肤，三分钟上手
## 自带外观就两套，看久了连灵感都变灰
每天对着它干活，功能是真香，可界面只有浅色和深色两套，来来回回就这两个选项。看久了，连灵感都跟着变灰了。

**先说清一个前提：**它自带的「外观」设置确实只有浅色、深色两套，这不是设置没找到，是真的就这些。

所以下面这个方案来自社区，是一款开源工具，专门给 WorkBuddy 桌面端换肤，名字叫 workbuddy-skin-studio。

## 这个工具能干什么、有什么要提前知道的
**三个实在的好处：**一是同时支持 macOS 和 Windows；二是一键切换——应用皮肤后右上角会冒出一个菜单，所有已装主题即点即换；三是一张图就是一个主题，随便丢一张 PNG / JPG / WebP 进去，它自动取色生成皮肤（配色加背景底图）。

**得提前说清楚：**这是非腾讯官方产品。不过它只注入运行中的渲染进程，不改官方目录。这个区别很重要——不动安装文件，风险范围就控制在「运行时的显示」上。

系统内置 10 款主题：火影（鸣人 / 佐助）、恋与深空（晨曦 / 星辰）、鸣潮（共鸣 / 声骸）、原神（晨曦 / 星夜）、Miku 488137 / Miku Light。加上「自定义图片」和「原生界面」，一共十二个选项。

## 安装只有一步：把这句话发给它
不用去命令行、不用 clone 仓库、不用 npm install。安装就是把这句话发给 WorkBuddy：「安装 workbuddy-skin-studio」。

实测两分五十九秒装完。它会把工具装到一个持久目录（不在临时工作区，以后随时能用），然后自己跑一遍自检：语法检查通过、doctor 自检通过（能找到应用路径、CDP 端口 9223、renderer 锚点）、内置 10 个主题正确识别、零外部依赖纯 Node 脚本。

这一步它做得很干净——装完会主动告诉你装在哪、验证了什么。你不用自己去翻目录确认。

## 换肤那一步要小心：它会把当前会话一起关掉
装好之后它自己会说明一个关键限制：apply 会用调试端口重启 WorkBuddy（关掉当前窗口再重开）。

而如果你此刻正跑在 WorkBuddy 里让它干这件事——一旦执行，本次会话会被一起关掉。所以它不会擅自动手，会给你两个选择。

选择一，让它来：先保存好当前任务，然后跟它说「应用 XX 主题」（比如 genshin-night 深色原神、miku-light 浅色初音），它会跑 apply 并验证。

选择二，你自己跑，更稳，不依赖这边的会话。进到工具目录执行：node src/cli.mjs apply --theme naruto-hokage（或者直接双击 scripts/apply.command）。想要哪个主题，把主题 id 换掉就行。

跑起来之后终端会依次打印：退出 WorkBuddy → 以 CDP 调试模式重启 → 等待 CDP 就绪 → 应用皮肤。实测 CDP 大约 6 秒就绪，然后返回一个 JSON，里面 applied: 1、themeId、以及 menuThemes 列表（就是右上角菜单里会出现的全部主题）。

## 自定义图片：丢一张图，它自己取色
内置的不够个性，就在右上角菜单里点「+ 自定义图片」，支持上传本地图片，它会自动取色并压成 webp，即点即换。

支持 PNG / JPG / JPEG / WebP，拖进窗口或者粘贴路径都行。上传后它会在页面内用 canvas 自动取四个颜色——主色 accent、辅色 secondary、面板底色 surface、文字色 text，然后覆盖 WorkBuddy 的 --cb-* 变量，配置存在 localStorage 里。

**有个机制值得知道：**surface 的明度决定深浅模式。图片偏亮（亮度大于 140）就生成浅色主题，图片偏暗就生成深色主题。所以想要深色皮肤就挑暗调图，想要浅色就挑亮调图——这个规律比反复试快得多。

一张图同时充当两样东西：背景底图（hero）和配色来源。所以选的图本身要能当背景用。

## 两个避坑点
第一，别拿带界面的截图当图。用干净的壁纸或立绘；README 里明确建议不要用含 baked-in 界面的截图或预览图做背景——否则界面元素会糊在背景上，而且这个工具本来就会覆盖 --cb-* 变量，截图里自带的 UI 反而添乱。

第二，分辨率不用特别大。工具会自动压缩，太大的图进 webp 也会被压，主要影响的是加载快慢。

## 写在最后
能换就换，别将就。一个你每天要盯几个小时的界面，选个自己喜欢的主题，开工的心情确实不一样。

**再说一遍边界：**这是社区工具，非官方，只改运行时渲染，不动官方文件。真要谨慎，就先备份一下当前任务，选「你自己跑」那条路——不依赖会话，出问题也好收拾。
