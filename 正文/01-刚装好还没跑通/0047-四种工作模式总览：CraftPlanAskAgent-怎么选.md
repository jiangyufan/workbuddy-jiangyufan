# 四种工作模式总览：Craft/Plan/Ask/Agent 怎么选
WorkBuddy 把同一个智能体拆成四种工作模式：Craft、Plan、Ask、Agent，本质是四种"协作姿势"，构成一条从"最可控"到"最自主"的光谱。核心认知是：模式跟着"任务所处阶段"走，不跟着"任务类型"走。

## 1. Craft：明确单步任务的"直接执行者"
**是什么 / 何时用：**定位"明确单步任务，直接执行"，设计哲学是"快"。当你已经清楚要做什么、且任务简单明确、低风险时使用。

**适合场景：生成格式明确的文档、文件格式转换、按规则批量重命名。**

**提示词模板：**"把（对象）执行（动作），要求（约束一、约束二、约束三），结果保存为（产物，含格式和位置）。"

**关键要点：**任务必须足够明确、足够低风险，否则"快"会变成"乱"；要把"怎么做"写清楚，不要把决策权甩给它。

## 2. Plan：复杂多步任务的"规划先行者"
**是什么 / 何时用：**定位"复杂多步任务，先出计划确认后执行"，设计哲学是"稳"。面对多步骤、有依赖、影响面大的任务时使用。

**适合场景：整理包含上百文件、跨多子目录的项目文件夹并生成归档清单；复杂调研任务。**

**提示词模板：**"我需要在（背景）下完成（目标）。请先不要执行，把任务拆解为分步计划，包含（你希望的阶段），每步写明具体做什么、产出物是什么、验收标准是什么。我确认后再逐步执行。"

**操作要领：**计划出来后，你只需盯关键决策点（归类规则对不对、执行顺序合不合理、输出格式对不对），确认无误后剩下交给它，形成"人管判断、AI 管执行"的分工。

**是什么 / 何时用：定位"纯咨询学习，只回答不动文件"，设计哲学是"纯"。你只想获取信息、理解概念、请教思路时使用。**

**适合场景：问清任务思路、要点、注意事项和可能的坑，是其他模式的"前置环节"。**

**提示词模板：**"我在（背景）中遇到了（具体问题），想了解（核心疑问）。请用（期望的形式）回答，重点讲清（重点）。"

**关键要点：**Ask 只答不动——向它要"规划"时它会给你一份计划，但不会去执行；想要"规划+执行"应改用 Plan。

---

**是什么 / 何时用：定位"自主探索多步骤，AI 自己规划主动执行"，设计哲学是"放"。目标清晰但路径不明确时使用。**

**适合场景："调研行业头部玩家并整理成报告""找出两个目录里的重复文件并清理"。**

**提示词模板：**"请帮我完成（可验证的目标），产出（产物和位置）。你可以自主决定（可自主的范围），但必须遵守（边界一、边界二）。完成后先自查是否满足（验收标准），再交付。如果（失败条件），就停下来告诉我。"

**关键要点：**只定目标和边界，把路径留给它；不要用 Craft 的口气把步骤规定死。

复杂任务从模糊到完成的一般路径是 Ask → Plan → Craft → Agent 2：

**用 Ask 搞清楚：**问清涉及哪些方面、有无现成方法论、关键概念，产出"一份想清楚的行动思路"。

**用 Plan 拆结构：**把任务拆解成可确认的分步计划，你审阅、修订、确认，产出"一份你认可的分步计划"。

**用 Craft 跑执行：**计划里每个边界清晰、路径单一的步骤，一句指令高效完成。

**用 Agent 补探索：**执行中遇到信息缺口（数据缺失、来源找不到），交给 Agent 自主完成。

整演示（"为公司新产品做市场进入可行性分析报告"）：Ask 阶段问报告结构→Plan 阶段下需求规划数据搜集/分析/成文三阶段→Craft 阶段用一句话整理三家竞品对比表保存为 CSV→Agent 阶段自主查竞争对手最新融资额，查不到就标注未知、不臆造。

组合速查表：

**写报告类：**Ask 定框架 → Craft 直接成文；复杂则中间加 Plan 排结构

**数据处理类：Plan 排步骤 → Craft 分步执行；异常数据用 Ask 咨询或交 Agent 排查**。

**调研类：**Ask 定维度 → Plan 排计划 → Craft 出成果 → Agent 补缺口

**学习理解类：**全程 Ask，结尾用一次 Craft 保存成文档

**批量操作类：**Craft 单步搞定，加"先列对照再执行"的确认；多文件多规则时先 Plan 拆规则

**提示词避坑三条：**①别用 Craft 口气给 Agent 下指令（把步骤规定死）；②别用 Plan 口气给 Ask 提问（Ask 不会执行）；③别用 Agent 口气给 Craft 下指令（Craft 无自主探索能力）。

## 二、Excel 数据分析的完整流程
**核心理念一句话：分析的质量上限，取决于你输入信息的完整度。整条流水线分五阶段。**

## 第一步：任务起手式——先讲清数据长什么样
用四要素描述数据：

**数据来源与业务背景：说明这份表是干什么的（如"2024 年 1 月到 6 月的电商订单明细表，每行一个订单"）。**

**表结构与字段含义：**主动列出关键列名和含义，尤其是模糊的缩写列（如"列 D 是 GMV、列 E 是退款金额、列 F 是订单状态，取值为已支付/已取消/已退款"）。

**数据规模与特殊情况：说明行数量级、是否有空值、合并单元格、多个 sheet。**

**你希望回答的核心问题：**明确"我最终想回答什么"。

起手式模板（可直接套用）：

"请帮我分析桌面上的 sales_2024.xlsx。这是一份电商订单明细，每行一个订单，共约 8 万行。关键列：A 订单号、B 下单时间、C 商品类目、D 成交金额、E 退款金额、F 订单状态、G 渠道。数据里可能存在空值和重复订单号。我想回答三个问题：一是各品类的销售额与退款率排名，二是月度销售趋势，三是异常高退款订单的特征。请先读取数据并确认你对列的理解，再开始分析。"。

## 第二步：让 WorkBuddy 读懂数据——先对齐再动手
不要急着要结论，先加"对齐环节"，要求它输出三样东西：

识别到的数据结构（行数、列数、每列数据类型和示例值）。

发现的潜在问题（空值比例、疑似异常值、重复记录）。

理解的分析口径（如"退款率"打算按退款金额÷成交金额计算）。

**技巧：**遇到不确定列名（如拼音缩写"gmv、tuihuan、qudao"），先让它读前几行并"给出你对每列含义的推测，列出假设清单"，你圈出对错即完成字段口径统一。

## 第三步：设定分析维度——从"帮我看看"到"帮我回答什么"
用"指标 × 维度 × 口径"三件套：

**指标：**要算的数（销售额、退款率、客单价、复购率）

**维度：**从哪个角度看（按品类、月份、渠道、地区）

**口径：**计算规则（去不去重、含不含退款、时间窗口怎么切）

**对比示例：**低质量指令是"帮我分析销售情况"；高质量指令是"按品类统计 2024 年上半年的成交金额和退款率，按金额降序排列，退款率用退款金额除以成交金额，保留两位小数"。

顺序建议：一次只锁定一个主维度 + 一个交叉维度，先总后分、先粗后细（先按品类看总额和退款率，再挑退款率最高的三个品类按月拆分看趋势）。

透视表做法（把需求翻译成行、列、值）：

**"请对订单明细做透视：**以'商品类目'为行，以'月份'为列，汇总'成交金额'的合计值。输出一张矩阵表，行是类目、列是月份、值是成交金额，并额外输出每个类目的年度合计。"

汇总方式要写清"求和/求平均/计数"（金额通常求和、单价通常平均、订单数通常计数）。若不知从何分析，可让它"建议 5 个有价值的透视维度组合，每个组合说明行/列/值字段、汇总方式、能回答什么业务问题，先列建议我来选"——原则是先建议、后执行、再确认。

## 第四步：执行与中间产物管理
进阶三要点：

**分步产出：**每完成一个维度，把中间结果写成一个新 sheet 或新文件（如"品类汇总表""月度趋势表"），而不是只在对话里贴数字——结果可追溯、可复用、可二次加工。

**输出计算口径说明：**如"退款率=退款金额合计/成交金额合计，不含已取消订单"，避免会上争论"这个数怎么算出来的"。

**设置检查点：**每完成一步让它汇报"我做了 X，得到了 Y，下一步打算做 Z，是否继续？"——相当于手动模拟 Plan 模式，适合高风险分析。

## 第五步：结论与图表的输出与核对
**两个常见误区：**只要数字不要结论、只要图表不要解读。正确做法是产出"结论 + 证据 + 建议"三层：

**结论：**"某品类退款率高达 18%，显著高于整体 5% 的平均水平"

**证据：**具体数字和对比

建议："建议优先核查该品类的物流与品控环节"。

**提示词可直接要求：**"针对每个发现，给出结论、支撑数据、以及一条可执行的建议。"

**图表：**指定类型和用途，而非"随便配个图"，如"用折线图展示 6 个月的销售趋势，横轴为月份、纵轴为金额，并标注峰值月份"。

**最后一步永远是核对：**让 WorkBuddy 做交叉验证，如"抽查品类汇总表里的前三个数，回到原始明细表里重新加总核对是否一致"。

**补充：**财务等对准确度要求极高的数据，先做"科目字典对齐"——让它读取科目表与标准模板对齐，对名称不同但含义相同的科目建立映射表并等你确认后再替换，不要让 AI 自作主张合并科目。

## 三、内容创作的具体做法
推荐按"选题—生产—审核—分发—复盘"五环节闭环组装，复盘结果回流选题，形成循环。

## 1. 选题环节：用灵感库稳定供题
维护一个灵感库，定期用 WorkBuddy 做选题发散和收敛筛选，形成"选题池"；每次创作从选题池按优先级取题，而非临时现想。

**示例提示词：**"从我的选题池中，按受众价值、可行性、新鲜度排序，帮我选出本周最值得做的 3 个选题，并说明理由。"

## 2. 素材环节：批量采集与整理
**素材通常来自三类渠道：**本地文件（PDF 报告、网页、案例文档）、零散记录（聊天灵感、备忘录、截图）、网络资料。操作要点：

**清洗结构化：**"把下面这段从网页复制的文字清洗整理：去掉无关的导航和广告内容、删除重复段落、修正明显乱码、统一标点，整理成结构清晰的纯文本，并提炼 3 个核心要点放在开头。"

**打标签建索引：**"为下面每个素材文件生成 3 到 5 个标签，分别标注主题、类型、适用内容形态，输出为 Markdown 表格，列出文件名和对应标签。"再汇总成"素材索引表"

**定期去重：**"检查素材库，找出内容高度相似或完全重复的文件，列出重复项；同时指出发布时间超过两年、可能已过期的数据类素材。"建议每月维护一次

## 第一步：把流程写成可执行的 SOP 文档。一份内容创作 SOP 通常包含：角色设定、输入要求、分步指令、每步的输出格式、质量检查清单
"公众号文章创作 SOP"示例：

**角色：**你是一名资深内容创作者

**输入：**主题、目标读者、核心观点、参考素材

**步骤一：**分析主题，生成 5 个备选标题

**步骤二：**搭建文章大纲（引入—分论点—总结）

**步骤三：**按大纲撰写正文，每节 300 字左右

**步骤四：**通读修改，检查逻辑与错别字

**步骤五：**按排版规范整理格式

**输出：**完整文章 + 标题 + 摘要

把这份 SOP 存成本地文件，每次创作时交给 WorkBuddy 执行。

## 第三步：SOP 要覆盖质量检查。在 SOP 末尾加一步："产出完成后，按以下清单自查：标题是否吸引人、结构是否完整、卖点是否遗漏、是否有错别字、格式是否规范，逐项输出检查结果。"
**示例提示词：**"按照我的公众号文章创作 SOP 和风格手册，为本周选定的选题完成初稿、标题和排版，并按审核清单做一轮自查。"

## 附：营销文案批量生成五步法
建卖点库 → 单条打样 → 设定变量批量生成 → 沉淀模板 → 人工筛选把关。

**卖点库四字段：**核心卖点、目标人群、使用场景、禁忌/禁用词。示例（敏感肌护肤水）：核心卖点"无酒精、无香精、添加积雪草提取物"；目标人群"换季易泛红的敏感肌用户"；使用场景"晨间精简护肤、晒后湿敷"；禁忌词"禁用'根治''消炎''医用级'"。

先花十分钟整理卖点库再丢给 WorkBuddy，产出质量会明显上一个台阶。

## 附：风格统一做法
先拆解风格（语气、句式、用词、结构、节奏、特有表达习惯），用样板定风格基准，再"参照风格 + 新主题"批量创作。

**风格基准提示词：**"以下是我希望保持的内容风格样板，请仔细分析它的风格特征，之后我会让你参照这个风格创作新内容，请先输出你提炼出的风格要点，供我确认。"

**批量创作提示词：**"参照上面确认的风格要点，为以下 5 个主题各写一篇 300 字的内容，保持语气、句式、用词、节奏与样板一致，只替换主题内容，不改变风格。"

**漂移检测提示词：**"对照风格样板，检查下面这几篇新内容：哪些地方风格不一致（语气变了、句式变了、用词不符合习惯），逐篇指出问题并给出修改建议。"

## 附：跨平台内容转换
先建立信息完整、逻辑清晰的"母稿"作为唯一信息源，所有平台版本从它派生，保证口径统一（可先用 Plan 模式把素材整理成母稿）。公众号版做深度与结构（"扩"），平台转换本质是"重新组织信息结构 + 切换表达语气 + 适配平台格式"。

## 4. 审核与分发环节：用清单和批量守住出口
审核用"AI 初审 + 人工终审"的分层机制；分发用"物料清单 + 批量制作"把一次创作的价值在多渠道释放。

**示例提示词：**"对这篇定稿执行发布前审核（AI 初审），然后按分发物料 SOP 批量生成各渠道物料，最后生成一份发布清单，列明每个渠道要发布的内容和物料。"

短视频脚本类可批量建立排期："以下是本周 5 个选题，请为每个选题各写一条 60 秒口播脚本，统一采用'痛点式开场 + 痛点—方法—结果主体 + 收藏引导结尾'的结构，口语化表达。"。

## 5. 复盘环节：让数据反馈回流选题
看打开率、完读率、互动率、转化、用户反馈等指标。

**示例提示词：**"这是我本周几篇内容的数据表现和用户反馈，请帮我分析：哪些选题和标题表现好、哪些差，用户反馈集中在什么问题上，总结出 3 条可复用的经验和 2 个要避开的坑，并据此提出下周选题方向的建议。"

## 6. 闭环度量与精力管理
**度量指标要覆盖五环节：**选题命中率、单位产出时间与返工率、漏检率、分发完整率与物料复用率、经验转化率。示例提示词："根据我本周的内容创作记录……帮我计算各环节的关键指标……并指出表现最弱的一两个环节和可能的改进方向。"

**精力管理三原则：**①降低启动成本（靠模板、SOP、灵感库）；②张弛有度（高产期全力产出，低谷期放慢储备）；③把精力用在刀刃上（选题判断、创意、终审留给自己，重复机械环节交给 WorkBuddy）。
