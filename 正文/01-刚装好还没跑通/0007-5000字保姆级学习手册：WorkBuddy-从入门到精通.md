# 5000字保姆级学习手册：WorkBuddy 从入门到精通
说实话，我接触过很多 AI 工具，大部分都是这个模式：你打字，它回答，你再打字，它再回答。很聪明，但不干活。直到我遇到 WorkBuddy，才第一次感觉到——这个东西是真的在帮我干活。

WorkBuddy 是腾讯云 CodeBuddy 团队推出的 AI 原生桌面智能体工作台，基于开源框架 OpenClaw 构建。官方的说法是「全场景职场 AI 智能体桌面工作台」，用人话翻译就是：你把任务交给它，它会自己规划步骤、操作电脑、处理文件，最后把结果交给你。

它内置了 DeepSeek、腾讯混元、Kimi、MiniMax 等模型，可以按任务类型切换：DeepSeek 推理强适合分析类任务，混元中文理解好适合中文写作，Kimi 擅长超长文本，MiniMax 多模态能力较强。简单说，ChatGPT 是只动嘴的顾问，WorkBuddy 是真正的员工——它会动手。

## 01｜安装与登录：十分钟能走完
访问 copilot.tencent.com/work，根据你的电脑选择 Windows 或 Mac 版本下载。安装前建议先装 Node.js（LTS 版）和 Git，这两个是运行部分插件技能的必要环境；如果只是体验基础功能，可以先不装，后续需要时再补。

双击打开 WorkBuddy，首次使用需要登录，支持微信扫码（推荐，最方便）和账号密码两种方式，需先阅读并同意服务条款和隐私协议。

**登录后进入主界面：**左边是功能导航栏，右边是主操作区域，整体设计很干净。

## 02｜模块一、二：AI 对话与任务执行
AI 对话是最基础的功能。在主界面的输入框输入问题，回车发送，AI 就会回答。但它的对话不只是问答——自带三种工作模式，可以在输入框上方切换：Craft 执行模式，收到指令直接动手做，适合任务明确、想快速出结果；Plan 计划模式，先出方案、确认后再执行，适合复杂任务、怕 AI 理解跑偏；Ask 问答模式，只回答问题不动手，适合只是想咨询。

新手建议刚开始用 Craft 模式感受执行能力；碰到重要任务切换到 Plan 模式，先看方案再放行，出错率低很多。

任务执行才是真正让人上瘾的功能。你描述一个完整任务，它会自动拆解步骤、逐步执行、最后交付结果。关键在于「尽可能详细」——模糊描述是「帮我整理一下文件」，清晰描述是「把 Downloads 文件夹里所有 pdf 文件，移动到 D:/资料/PDFs 文件夹，按文件名里的日期重命名为 YYYY-MM-DD-原始文件名格式」。说得越清楚，它做得越准。

## 03｜模块三、四：插件与技能，两回事
这里要区分清楚一个概念——插件和技能是两回事。插件 = 扩展 AI 的操作能力，基于 MCP 协议运行，安装后会在后台静默待命，AI 会自动判断是否需要调用。装了微信公众号搜索插件，AI 就能搜公众号文章；装了腾讯地图插件，就能查路线；装了文件系统插件，就能操作本地文件夹。

**安装路径是：**点击左侧边栏「插件」图标 → 进入插件市场浏览分类 → 找到需要的插件点「安装」→ 安装完成后自动在后台生效，无需手动启用。使用时直接提需求，不用特意说「用某某插件」。

技能 = 给 AI 注入专业知识。插件扩展的是能力边界，技能扩展的是知识深度。技能像 import 引入专业书籍，插件像安装专用外接设备。WorkBuddy 自带上百个预设技能，开箱即用：summarize 快速总结网页 / PDF / 视频，humanizer 去除 AI 写作痕迹，obsidian 操作笔记库，feishu-doc 操作飞书文档，xiaohongshu 生成平台适配版本。

安装社区技能可以去 skillhub.tencent.com 或 clawhub.ai，复制安装指令后在「技能」面板选「安装技能」，粘贴指令等待完成。安全提醒很重要：装任何社区技能前，务必先用 skill-vetter 做安全审查。技能本质上是代码，来路不明的技能可能有风险，skill-vetter 会扫描异常网络访问、索要 API 密钥或密码、访问敏感目录这些红旗信号，遇到高风险提示坚决不装。

## 04｜模块五：专家——有名字的垂直领域顾问
如果说技能和插件都是「工具」，专家则更像「人」——每一位专家都有自己的名字、专业领域和工作风格。WorkBuddy 目前上线了 12 大领域、141 位专家，全部按企业真实职能分工设计，涵盖社交媒体、SEO、内容创作、增长、前后端开发、AI/ML、DevOps、架构、广告投放、品牌策略、UI/UX、大客户经营等。

比如小红书运营专家 Fay、知乎策略师 Gia、内容创作专家 Kai、社交媒体策略师 Ari。用法是：在任务页面顶部找到「专家」入口，按领域浏览，点「立即召唤」，然后在对话框里告诉他需求，越具体越好。

**推荐指令格式：**我的身份 + 我的目标 + 具体问题 + 希望的输出格式。比如「我是一个做 AI 工具科普的公众号博主，本周想写一篇对比文章。帮我分析目前 5 款主流 AI 写作工具的差异，生成一份对比表格，文字简洁，适合公众号排版」。专家模式的核心优势是：它不是通用 AI 在泛泛而谈。

## 05｜模块六、七：自动化与 Claw 远程控制
自动化是让 WorkBuddy 从「效率工具」升级为「自动化系统」的关键功能：给任务设一个定时器，让它自动执行。你可以设置定期任务，到点自动运行，结果完成后还能推送到企业微信。

**操作路径：**左侧导航找到「自动化」→ 点「新建自动化」→ 填写任务内容（和正常任务描述一样）→ 设置触发条件（定时触发选每天 / 每周 / 自定义时间，或单次触发设一个具体日期时间）→ 配置通知（可推送到企业微信）→ 保存生效。

**典型用法：**每天早上 9 点自动抓取行业热点整理成摘要推送企业微信，每天晚上 11 点自动备份今天新建的文件。设置好之后，这些事情就从待办列表里消失了——机器会帮你记。

Claw 远程控制是最「黑科技」的功能：用手机微信远程指挥办公室的电脑干活。你人在外面，电脑在办公室，发一条微信，电脑自动执行任务。接入方式在设置里找「Claw 接入」，支持微信客服号（个人用户）、企业微信 AIBot 和 QQ 机器人，按提示扫码授权即可。

## 06｜三者协同：插件是手，技能是脑，专家是人格
很多人安装了一堆东西，但不知道怎么组合。一个简单的理解框架：插件是手，技能是脑，专家是人格。插件给 AI 装上工具手，让它能操作外部系统；技能给 AI 注入专业知识，让它懂得怎么做得更好；专家给 AI 一个专业身份，让它以专家视角来回答你。

**一个最佳组合案例：**你是内容博主，想每周自动收集行业动态并发布。第一步插件打底，装微信公众号搜索插件和网页浏览插件，让 AI 能搜集内容；第二步技能提升，启用 summarize 和 humanizer；第三步专家加持，召唤内容创作专家 Kai，让他以专业内容人的视角把信息组织成高质量推文。

## 07｜五个进阶技巧，让结果更准
技巧一，任务描述要包含四个要素：身份（你是谁、做什么工作）、目标（最终要达到什么效果）、范围（涉及哪些文件 / 数据）、格式（希望输出什么样的结果）。描述越具体，结果越准，返工率越低。

技巧二，用 Plan 模式处理重要任务。涉及文件操作、重要数据的任务，先用 Plan 看方案，确认没问题再执行，这个习惯能避免很多麻烦。

技巧三，技能组合使用。不要单独用一个技能，试试串联：feishu-doc 读取飞书文档 → summarize 提取关键信息 → humanizer 优化表达 → xiaohongshu 生成平台适配版本。

技巧四，善用追问。做完第一步不满意，直接说「这个太长了，帮我压缩到 500 字」「换一种更轻松的表达方式」「把第二部分的逻辑重新梳理一下」。它支持多轮对话，互动越多结果越好。

技巧五，定期整理技能库。装了一堆技能但不用，会影响 AI 的判断效率，定期把用不上的技能禁用或卸载。

## 08｜常见问题
数据安全吗？文件会上传到腾讯服务器吗——所有任务在本地运行，数据不出本地机器，腾讯官方承诺不收集用户的文件数据。安装第三方技能时需要谨慎，记得先用 skill-vetter 审查。

WorkBuddy 和 OpenClaw 是什么关系——WorkBuddy 基于开源框架 OpenClaw 构建，完全兼容它的技能生态，之前用过 OpenClaw 的技能可以无缝迁移，无需配置。

电脑配置要求高吗——普通的 Windows / Mac 都能运行，建议内存 8GB 以上，处理复杂任务时响应更流畅。

远程控制功能安全吗——安全。任务在本地执行，微信只是触发器，不传输文件内容。但建议不要用主微信号，专门用一个微信小号或企业微信号接入，隔离风险。

技能安装失败了怎么办——先检查 Node.js 和 Git 是否安装并正确配置，再检查网络连接。如果持续失败，重启 WorkBuddy 再试。

## 最后
学了这么多 AI 工具，WorkBuddy 给我最大的感触是：它终于把 AI 的能力，从「回答问题」真正拓展到了「完成任务」。以前的 AI 是你的智囊，能给建议、能帮你想，但最后还是你自己动手。

WorkBuddy 不一样。你说，它做，它交付。这个转变，比任何一个单独的功能都重要。当然它现在还不完美，复杂任务偶尔会跑偏，有时候需要你追问纠正，但这个方向是对的。
