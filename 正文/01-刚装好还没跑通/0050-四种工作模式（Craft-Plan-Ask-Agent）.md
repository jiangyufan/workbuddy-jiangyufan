# 四种工作模式（Craft / Plan / Ask / Agent）
**是什么：**WorkBuddy 最独特的设计之一，是把同一个智能体拆成四种工作模式，本质是四种"协作姿势"，对应从"最可控"到"最自主"的光谱。

**怎么操作（选择逻辑）：**

**Craft：**明确单步任务，直接执行；给"可立即执行的完整指令"，适合格式转换、文件重命名、快速生成等低风险任务。

**Plan：**复杂多步任务，先出计划确认后执行；给"明确的目标和约束"，用户只需盯关键决策点把关。

**Ask：**纯咨询学习，只回答不动文件；给"清晰的问题和充分的背景"。

**Agent：**自主探索多步骤，AI 自己规划主动执行；给"清晰目标、验收标准和边界"。

**适合场景与组合套路：**

"Ask 探路，Plan 定案，Craft 执行"——适合调研报告、方案撰写类任务。

"Agent 探索，Plan 收口"——目标清晰但路径不明确时，如"找出目录里所有重复文件"。

"Craft 打底，Ask 补位"——日常大量明确低风险任务直接 Craft，拿不准时切 Ask。
