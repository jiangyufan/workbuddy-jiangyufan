# 数据分析 / 财务类
**真实名称：neodata-financial-search（NeoData 金融搜索）**。

**作用：自然语言查金融数据——A股、基金、宏观、财报、资金流向、股票行情。**

**场景：**股票行情、财报、基金净值。

**真实名称：finance-data-retrieval**。

**作用：209 个结构化 API 精确查金融数据。**

**场景：**历史数据、批量数据查询。

**真实名称：stock-analysis**。

**作用：股票技术分析与可视化。**

**真实名称：data-analysis（Data Analyst）**。

**作用：通用数据分析与图表生成。**

**场景：**从三个月销售数据找出增长最快产品类别、画折线图看每周订单趋势。

## 34. 市场调研（market-research）
**真实名称：market-research（市场调研）**。

**作用：TAM/SAM/SOM 市场分析、消费者洞察；行业调研助手，自动生成调研报告。**

**场景：**竞品分析、新市场研究。

## 35. 销售数据分析（Sales Analytics）
**真实名称：Sales Analytics**。

**作用：读取 CRM 或销售数据，分析成单/丢单原因、预测业绩趋势、识别重点客户、输出销售策略建议。**

**场景：**销售复盘、业绩预测、客户分析。

## 36. Westock 数据
**真实名称：Westock 数据**。

**作用：更细粒度的个股数据——K线、分时、技术指标。**
