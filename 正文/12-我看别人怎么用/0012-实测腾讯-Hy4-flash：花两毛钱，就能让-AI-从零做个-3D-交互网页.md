# 实测腾讯 Hy4 flash：花两毛钱，就能让 AI 从零做个 3D 交互网页
![](https://mmbiz.qpic.cn/sz_mmbiz_gif/dCG7OC48IfI0qUYy3UOCq4iaoPgcHd6b2g2ljcv0wP9FibEFoVsS2arRtd4TvLN1bn7M8wIWCwCEoECGXnazTyFHUDSuuO4ibqAiavlrZr4JfKM/640?wx_fmt=gif&amp;from=appmsg#imgIndex=0)

11 月初，腾讯 Hy4 发布，新模型在大模型竞技场上一跃升至开源第一。

排在 Hy4 前面的三个模型分别是 GPT-6 Sol（Max）、Claude Opus 5（Max）和 Fable 5（High），附近还有 GPT-6.1 Terra、GPT-5.6 Sol 等一众强劲的闭源模型。

![](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfLIoN92AnJT7PxjAibFndTdmYMhP3ibYGpo0588iaTqJuUGuG7RsiclzD0YHhO3z1ibELAmgI6hgtgniadkXhkU9DYMsrCAWTZOk6YNY/640?wx_fmt=png&amp;from=appmsg#imgIndex=1)

我们此前在 WorkBuddy 内体验过 Hy4 的 Agent 长程任务和日常办公能力。从逐帧分析视频、复刻游戏和网页，到文件整理、Office 文档处理，Hy4 都交出了不错的成果。

整体实测表现，也基本符合它在大模型竞技场上的成绩。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/dCG7OC48IfI7MaWpoga7iaiawQboODZU9CEhvjnhO7UIxzVJibNnE6lGWwJJbuyNDv2j4icesF0HWXLfWIY7UvBu27PKQiaMBcpBVCcWOOvv1FYU/640?wx_fmt=png&amp;from=appmsg#imgIndex=2)

但对于经常使用 WorkBuddy 的用户来说，模型能力只是选择标准之一。是否免费、需不需要排队、执行速度够不够快，同样会影响实际体验。

比如在工作日高峰期打开 WorkBuddy，倍率只有 0.11x 的 DeepSeek V4.1 Flash，繁忙程度却常常居高不下。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/dCG7OC48IfItB072riaibpT1cUuV8KL9HqwzTfavYBXu6Zt8kwOCZPI4EkObXtaxbNibUOmjTOqr8gu4zClfVU8EgTTsE7tLfibK9FMfwgSltto/640?wx_fmt=png&amp;from=appmsg#imgIndex=3)

早在 Hy4 发布时，腾讯就预告过一款主打效率的 Hy4 flash。

就在刚刚，Hy4 flash 正式发布。腾讯希望将 Hy4 已有的 Agent、长程任务和生产力能力，以更低的成本带到高频使用场景。

APPSO 提前拿到了 Hy4 flash 的测试资格。这次我们最关心的是，它能否在保证任务完成质量的同时，减少 Agent 执行过程中的时间和 Token 消耗。

![](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfIpZQib3s8Ucc7ITACy07gibpyYSjyG0q87rR0CwWZ2YN6X0NCVIHT7UWgXEZ8VN7n3SXNrYfJSP1o4FssbCGdGbF7O0KskJZVAw/640?wx_fmt=png&amp;from=appmsg#imgIndex=4)

相较于 Hy4，新的 Hy4 flash 对 Token 效率进行了大量优化，Hy4 flash 总参数量为 224B，激活参数 12B，支持多模态和 1M 上下文长度。模型输出更加精简，吞吐量和整体响应速度也有所提升。

更令人惊喜的是，Hy4 flash 在 WorkIndex 上单任务成本仅为 Hy4 preview 的 1/13、Hy4 的 1/20、DeepSeek-V4.1-Flash-1017（ max 档位，忙时价格）的 1/8。

![](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfKOC6JdGWqF31sPWxSholicsonfyJMMSy0PHYOANI8Kkz63icNuic6dTbS2l4Kph2dyPB76mwapqXdNO4dLJ2e9sGtgbu8s0c7Bu8/640?wx_fmt=png&amp;from=appmsg#imgIndex=5)

![](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfKRP2VSt4fQXziarIy4VU98BicWicoicCRPybRSia8FD4Ue0sZlKPfT3cckMxvdjzWYCNMia9lHlFcXSuQ6buOSrZCNO1uzGMmdmtUY8/640?wx_fmt=png&amp;from=appmsg#imgIndex=6)

更高的 Token 效率也让 Hy4 flash 的价格要比 Hy4 便宜不少，Hy4 flash 的输入价格为 0.5 元每百万 Token 输入，而输出则是每百万 Token 输出 2 元，几乎是 Hy4 价格的十分之一。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/dCG7OC48IfKn4DBibA42OoP3cs5PtROHYUL5dktLw8lI0CicvzZoibx82xymvtIhdFKv0WPBhVMY3VTpLT58lO1iakGGwsX5ZsEVvgfoVVv7mYU/640?wx_fmt=png&amp;from=appmsg#imgIndex=7)

## 比 DeepSeek 更快还便宜。
现在的 Agent 干活，动不动就是半个小时起步。

打开执行记录，看着它读取文件、拆解任务、编写代码、调用工具、检查结果……一整套流程下来，几十分钟过去，模型可能还在反复检查同一个文件，甚至把刚修好的问题又改了出来。

这些弯路不会出现在最终的成果截图里，却会实实在在地增加任务耗时和 Token 账单。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/dCG7OC48IfIKAubrLuJX4AHLpGwbQZueWAv181D1spgqj2XJ7bpOdxoqUYvVxZuKhm8onqGOB4icfCxmjaHT6H3PAsLzeibhQ5ZtLEriaT8BWY/640?wx_fmt=png&amp;from=appmsg#imgIndex=8)

所以，当 Agent 开始承担真实工作，我们也需要关心一个更实际的问题：完成同一件事，究竟需要多少时间和成本。

为了测试 Hy4 flash 的实际效率，我们在 WorkBuddy 中准备了相同的任务，分别交给 Hy4 flash 和 DeepSeek V4.1 Flash 1017。测试过程中，提示词、工具权限和其他设置保持一致，重点观察两款模型的执行过程、最终交付，以及背后的时间和 Token 消耗。

我们先用了一些在 WorkBuddy 内重复、琐碎，但又需要花时间的工作，这些工作虽然不需要模型从零开发一套复杂系统，但也很考验它对信息的理解、整理和工具调用能力。

例如进行一些深度研究的任务，看看是否能高效地获得信息可靠、条理清晰、便于进一步使用的结果。

不过两款模型在完成时间上的差距很大，DeepSeek 花了 1 小时 30 分钟，Hy4 flash 只用了半小时。

对于只想快速验证想法、搭建网页原型的用户，尤其需要是迭代速度较快的场景，Hy4 flash 更经得起高频使用，而且产出已经具备继续修改的基础，。

DeepSeek V4.1 Flash 在这一轮任务中消耗了约 30 万 Token，另有约 1600 万 Token 的缓存命中，API 费用约为 1.21 元。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/dCG7OC48IfIjZH3JFUUfdyUEGWHuogl1p72eaztuacPEEBJUMuhMvrsteCWx6IDkG7HDgNld7LDmiaNNZELCJ6oLNicnLEzW1EicKDCsL7YRUo/640?wx_fmt=png&amp;from=appmsg#imgIndex=14)

Hy4 flash 的对话数据则记录了约 14.9 万 Token 的消耗，以及约 400 万 Token 的缓存命中。按照 Hy4 flash 的 API 定价，完成这艘可交互 3D 历史帆船，预计需要支付 0.23 元。

![](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfKghwzjKX7jVHjeAEm7icpPJwZIHedibpRxEDibx7c8vtYT2915vpvzrTPxWjHBY5QbIaDHwKuI4NfIscS1HoAQtuicdT7LVe4OMzY/640?wx_fmt=png&amp;from=appmsg#imgIndex=15)

除了上述案例，我们还统计了两款模型在 10 个代码和办公任务中的表现。从最终成果来看，双方整体处于相近水平。但在首轮交付时间上，Hy4 flash 的优势更加明显。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/dCG7OC48IfKtFLdCMnJWbbjbrwMOzbibKpopWWKuGwicHHIWofEmgbvOwkBepOHRhEbfJpHdzASPc5UibLF3tZIppNF7bwYYnnp12g354oF5fc/640?wx_fmt=png&amp;from=appmsg#imgIndex=16)

经过这一轮测试，我们认为 Hy4 flash 和 DeepSeek V4.1 Flash 的任务完成能力大致处于同一水平。DeepSeek 有时会投入更多 Token，在部分场景中也确实做出了更丰富的细节。

而 Hy4 flash 的优势也很明显，在完成实际工作的过程中，模型可以花更少的开销，提供更快的响应。特别是有些工作需求明确、格式固定，模型只要准确理解并顺利执行，较低的等待时间这个时候就很有意义。

就像深度搜索、日常办公、文件整理等高频生产力任务，我们会更推荐使用 Hy4 flash。它能以更低的时间和 Token 成本，交出质量不错的结果。即使是网页原型、小游戏开发等创作任务，也可以先用 Hy4 flash 快速生成第一版，验证想法，再决定后续如何完善。

![](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfIjLj4ibuOUkvdh1BGYDGMSN3pd1zU8Lic1pu3kGMJhHCPm7dMxWjHTRXMnQfYBSrE8X1jjiaEZePmoRqhbPI6KCJ42hlFx3stq7o/640?wx_fmt=png&amp;from=appmsg#imgIndex=17)

而对于长程软件工程、复杂代码库修改等需要持续推理、反复验证的高难度任务，我们仍然更推荐此前发布的 Hy4。多投入一些时间和 Token，换取更强的复杂任务处理能力，往往是值得的。

这也让 Hy4 和 Hy4 flash 有了更明确的分工。日常高频任务可以放心交给 Hy4 flash，遇到更复杂的工作，再切换到 Hy4。我们可以根据实际需求，在任务质量、执行速度和使用成本之间做出选择。

## 更实用的编程和办公搭子。

例如在办公方面，我们测试了 PPT 制作、文件整理，以及多种文档格式之间的转换。
