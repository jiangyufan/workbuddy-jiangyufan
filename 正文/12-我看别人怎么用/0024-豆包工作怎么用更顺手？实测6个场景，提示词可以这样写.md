# 豆包工作怎么用更顺手？实测6个场景，提示词可以这样写
豆包工作怎么用才更顺手。@沃垠AI 的答案只有两句话：第一句，给 Agent 管饱。提供足够的上下文。第二句，给自己管好。Agent 越是能干，我们越需要提升自己管理 Agent 的能力。有没有一种简单快速的办法，能同时实现这两件事。下面这篇文章，跟随 @沃垠AI 的讲述，6 段实用提示词，直接复制，让豆包工作「长」进你的工作现场。

## 干货教程：6 个能力，全部附提示词。
✦ 能力1：一句话，还原一个项目。这是我最想让你先试的。过去的用法是：你先翻群聊、找纪要、导表格，整理成一段话，再喂给AI。现在是：你只说项目名。提示词（直接抄，括号内项目换成你自己的）：

帮我梳理[项目名]的最新进展。要求： 1、在我的权限范围内，查找相关群聊、会议纪要、云文档、任务和审批； 2、输出：当前进度、已达成的共识、还没解决的分歧、最紧急的三件事； 3、每条结论后面标注信息来源（哪个群 / 哪份文档 / 哪次会议）； 4、不要编造数据，查不到的地方直接写“未找到”。

第 3、4 条划一下重点：标注来源让你一眼验真，不许编造是 Agent 时代最需要的保险。

这个能力，你还能再往前一步。你可以直接问「9 月 3 日还能不能上线」，它会把进度、风险、审批卡在谁那里、批与不批分别什么影响，都讲清楚。

比如让它查询一位新人的入职情况并发起一个审批流程，它会按照真实的时间和流程准备材料、提醒相关人员、创建任务并跟进结果。

✦ 能力2：读完群聊，直接出图、出视频。多模态本身不新鲜，Seedance、Seedream的能力大家都知道。有意思的是它的输入端。

读取[群名]最近的讨论，以及云文档[品牌规范文档]。要求： 1、总结这次营销的最终结论，有分歧的地方标出来问我； 2、按品牌规范的配色和字体，为[产品名]生成3张电商主图； 3、生成一条15秒宣传视频，卖点必须来自群聊里确认过的内容，不要自己加卖点。

最后半句很重要。

在 Harness 框架下，豆包工作有更完整的记忆和更好的上下文，你只要在提示词里写明「不许编造」，它就会老实交代哪里查不到。

比如让它拉一个群聊内容来生成宣传商品图、生成视频，体验非常丝滑。

✦ 能力3：直接进飞书多维表格，拉一个数据看板。文档、表格、PPT 这类基础办公能力，现在各家都有，不值得单独讲。值得讲的是：数据源在飞书，看板能实时跟着变。

它交付的是一个能直接上线的网页，不是一张静态图。第 3 条是关键，表里的工单状态变了，看板跟着变，你不用每周手动导一次数据。

✦ 能力4：它能自己看屏幕点鼠标，还能用云电脑替你熬夜。这是豆包工作最有意思的地方。

基于模型的视觉理解能力，它能够像人一样操作浏览器和电脑，看懂屏幕、点按钮、填输入框。还支持操作 Windows 虚拟电脑，不干扰你本机工作，随时可以接管。

用云电脑帮我做这件事： 1、登录[某后台]，筛选近7天的退款订单； 2、逐条查看退款原因，下载相关凭证； 3、把订单号、金额、退款原因整理成Excel； 4、原因分类基于实际内容归纳，不要预设分类硬套，不要编造。完成后把Excel发给我。

你可能想问，云电脑和本地电脑该怎么选。

简单说，本地电脑用在需要你本机的专业软件或本地文件时；云电脑用在数据采集、批量处理、长时间盯盘、定时任务这类一跑几小时的重任务上，不占本机资源。

*我先在你的电脑上找到这个 PPT 文件。｜发消息或按住说话...*

✦ 能力5：自由修改，想改哪里就改哪里。这也是豆包工作很有意思的一个地方。以前跟 AI 改东西最痛苦的是：你让它改第 3 页，它把整篇重写了。

豆包工作的做法是：在右侧工作台打开产物（文档、表格、PPT、图片、网页、应用都行），鼠标框选你要改的那一块，再用自然语言说要求。

提示词（框选之后再说）：

只改我选中的这部分：把这张柱状图改成按周对比的折线图，配色换成品牌蓝，标题改为「客诉工单周趋势」，其他部分不要动。

网页和应用的局部修改支持也做得很好。“这个按钮改成蓝色”“这张卡片加一行同比”，说完就改，布局不会崩。

✦ 能力6：把你的经验，变成可复利的资产。前 5 个是「帮你做事」，这个是「越用越懂你们公司」。

豆包工作提供技能（Skill）、连接器和各类工作伙伴。一个跑顺了的流程，可以沉淀成自定义技能，在组织内共享复用。

比如把能力1的那套提示词存起来：把我刚才梳理项目进展的这套流程，保存为自定义技能，命名「项目周报」。

以后我只说「项目周报 + 项目名」，就按这套标准流程执行并输出。比如我自己的豆包工作，就已经积累了 10 多个 Skill 了。

产物落回飞书，经验沉淀成技能，下一个任务继续在同一套系统里发生。这个飞轮转起来，才是组织级的复利。✦ 新手避坑：这 3 句话，抄进你的提示词里。

1. 给数据划边界。 加一句「所有数据必须来自我提供的文件/飞书文档，不要编造，找不到就标注“未找到”」，准确率立竿见影。
2. 说清验收标准。 一次性说清楚交付物格式、字段、字数、风格，减少返工。
3. 标注来源。补充一句「每条结论标注信息来源」，AI交付的东西你必须能抽查，有来源才敢用。

再补一个习惯：复杂任务先让它输出执行计划，你确认后再跑，这是管理Agent 的基本功。

回到开头的那两句话。给Agent管饱，说的是上下文。豆包工作把这件事从「人工喂料」，变成了「Agent自己进现场」。

给自己管好，说的是我们。当Agent能自己找资料、自己动手、自己推进，我们的活就剩三件：定义目标、给对边界、验收结果。

一个生产力Agent的上限，一半在它自己，一半在你给它什么样的工作环境。现在，环境这一半有解了。剩下那一半，得我们自己补上。
