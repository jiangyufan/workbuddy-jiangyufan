# Workbuddy制作超好看PPT，原来就靠这个skill！
效率手记 2026.07.10。WorkBuddy 做 PPT · 靠不靠谱。迭代这么多版本，PPT 到底做得咋样。是不是靠 skill 在撑。今天把它拆开说清楚。DOODLE。结论：能做，而且不差——底牌是 skill，不是魔法键。PPT skill。

嗨，大家好，我是 iscuker。最近 WorkBuddy 迭代得挺猛，新版本一个接一个。有粉丝在后台问我：更新这么多，PPT 到底做得咋样。是那种「一句话就出大片」吗。还有人补了一句：它是不是靠 skill 在撑。今天就把这个问题拆开说清楚。

PART。先给结论。THE VERDICT。能做，而且做得不差。

但它不是靠一个「PPT 魔法键」一键生成。它的底牌，是 skill（技能）。你下指令，Agent 去调用对应的 skill，把活干出来。换句话说，PPT 好不好，一半看你用的 skill 对不对，一半看你跟它沟通清不清楚。

底牌是 skill，不是魔法键——你下指令，Agent 调用对应的 skill 把活干出来。所以有人惊艳、有人觉得一般，差的那截，往往是用错了路线。

它其实有两条路。TWO PATHS。

第一条，叫网页翻页式。背后的 skill 是 dashiai-ppt，把需求整理成计划，生成横向翻页的 HTML 演示，能离线打开、浏览器改字、导出 PPTX 或 PDF。这条路的特点是快、稳、视觉统一。

第二条，叫真·PPTX 文件。背后的 skill 就叫 pptx，处理真实的 .pptx——可从零新建、改模板、合并拆分、读内容。这条路的特点是可控、能二次编辑。

网页翻页式。dashiai-ppt，生成横向翻页 HTML，快、稳、视觉统一。vs。真·PPTX 文件。pptx，处理真实 .pptx，可控、能二次编辑。两条路不是二选一，是看你要什么。

路线 A：dashiai-ppt，快但模板化。PATH A · FAST。

先说它最舒服的地方。你跟它说「帮我做个产品介绍的 PPT」，它会先让你选风格。它内置了 12 套主题，叫 theme01 到 theme12。我随便列几个：

轻拟态风 : 适合产品介绍、企业汇报。深浅代码风 : 适合技术方案、开发者大会。色谱图表风 : 适合数据报告、市场分析。深蓝杂志风 : 适合品牌故事、人物访谈。高能增长风 : 适合增长复盘、商业计划。选完风格、确认要不要配图，它就开干。出来的东西，横向翻页、动画顺滑、配色统一，拿去内部汇报基本不露怯。

它的天花板，就是那 12 套模板的审美上限——本质是「锁模板填文案」，除非你明确要求改页面属性，否则它不会帮你做视觉精修。所以你想「我要个完全不一样的设计」，它不一定接得住。

路线 B：pptx skill，真文件更可控。PATH B · REAL。

如果你要的东西，是别人能在 PowerPoint 里打开、接着改的文件，那就走 pptx skill。它三种用法：

从零新建 : 底层用 pptxgenjs 搭建。改现成模板 : 把内容替换进去。合并 / 拆分 : 多份文件拼一份，或一份拆多份。这条路的自由度明显更高。s。

kill 里甚至有一整套设计讲究：配色别默认蓝、每页都要有视觉元素、字体要配对、标题下别加装饰线。而且它 QA 很严——先做内容核对，再用子代理做视觉检查，专门挑重叠、溢出、对比度低这些毛病。

代价就是，比第一条路慢，沟通也要更细。适合什么场景。对接客户、正式汇报、要别人二次编辑的，都走它。

真实案例：我用 pptx skill 做了一份杂志编辑风 PPT。A REAL CASE。光说对比还是虚。

我直接让 WorkBuddy 用 pptx skill 做了一份《WorkBuddy专家团_杂志编辑风》PPT，9 页，全程没动手调格式。

需求就一句话：「帮我做个专家团介绍 PPT，杂志编辑风。」它自己拆成了封面、背景、定位差异、规模数据、并行机制、对比、场景、上手步骤、封底。下面几页是实际导出的截图。

大数字、双栏对比、四宫格场景——这些它都自己排好了。我基本只做了两件事：把需求说清楚，看完让它微调了几处措辞。这就是 pptx skill 那条路的真实体感：你出方向，它出稿，来回几轮就成型。

那质量到底如何。THE QUALITY。快速出第一版、内部过会、把零散资料变成能看的幻灯片——dashiai-ppt 够用，甚至超出预期。

要交付、要精细、要别人接着改——pptx skill 更稳，天花板也更高。但别指望一句话就出「大师级设计」，复杂定制得一步步聊。
