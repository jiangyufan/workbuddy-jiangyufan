# 三要素/四要素任务模板：把"活"说全再派单

> **说明：** 本篇是产品动态/短记录，原文本身只有简短说明和配图，不含完整操作步骤。它被收录是因为记录了当时的界面或功能变化，可作为版本对照；需要完整流程请到对应章节找长文。
**解决什么问题：任务越模糊，Agent 自己补充的假设就越多，结果越难验收。**

**怎么做（两种版本，择一使用）：**

四要素版（材料在哪、以什么为准、什么格式、结果存哪）：

**要素：**要写清什么

**目标：**有动词、有对象、有产出物

**背景：**材料在哪、读者是谁、什么场合用、以什么为唯一依据

**范围：**只做什么、不做什么、不许联网查的别查、不许编的别编

**完成标准：**格式是什么、字段有几个、结果存在哪

五要素版（给 Agent 派任务时的公式）：目标（最后想得到什么）、范围（允许查看或修改哪里）、限制（绝对不能做什么）、步骤（是否先给计划、等待确认）、验收（完成后如何检查）。实操建议：涉及写文件、删内容、装软件前，"先等待我确认"。
