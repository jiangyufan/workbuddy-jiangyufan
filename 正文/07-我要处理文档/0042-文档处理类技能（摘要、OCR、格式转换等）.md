# 文档处理类技能（摘要、OCR、格式转换等）

> **说明：** 本篇是产品动态/短记录，原文本身只有简短说明和配图，不含完整操作步骤。它被收录是因为记录了当时的界面或功能变化，可作为版本对照；需要完整流程请到对应章节找长文。
**是什么：WorkBuddy 内置文档智能摘要、OCR 文字识别、手写识别、文档格式转换与跨格式内容迁移等文档处理能力。**

**怎么操作：**

**文档格式转换：**先想清楚要"格式"还是"内容结构"，善用 Markdown 作为中转；对于 PDF 先判断是文字型还是扫描型，扫描型需先 OCR 再处理。

**批量转换：**统一口径（同一套转换规则）、分批加日志、保留原文件、按比例抽检，且校验重点放在表格、数字等高风险区域。

**OCR/发票处理：**批量上传 PDF/PNG 发票 → AI 自动识别发票号、金额、日期、开票方 → 生成汇总表格并按"日期_发票号_金额"重命名归档，OCR+AI 双重校验确保准确性。

**适合场景：**客户 PDF 改 Word、Word 转 Markdown 进知识库、发票批量汇总、把散乱 TXT 重建成结构化文档。官方实测"45 张发票 5 分钟生成报销明细，节省 2 小时"。
