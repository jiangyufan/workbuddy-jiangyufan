# 15 分钟出 1 小时纪要：会议纪要不是文学创作，是可追溯的行动清单
## 会议纪要为什么这么耗人
一次会议一小时，整理纪要又要一小时。一天两三场会，光纪要就能把人耗到加班。

**这篇的目标很具体：**把会议录音、议程、待办一起丢给 WorkBuddy，让它输出带结论、行动计划、责任人和截止时间的正式纪要。整条路径只有三步——①把录音转写、议程、待办初稿放进工作空间；②给 WorkBuddy 一条结构化指令；③在结果区产物里下载 Markdown，人工审一遍再发出。

**适合谁：**每周要开 2 场以上评审会的人；纪要总漏掉行动项、责任人或 deadline 的人；想把手机待办变成可追踪正式纪要的工程师。

## 准备三份材料
一个已登录的 WorkBuddy 账号；一段会议录音转写文本（本课用 lesson14_素材包/会议录音转写.txt）；一份会议议程或主题（会议议程.md）；一份待办初稿或手写笔记（待办事项初稿.md）。如果你只有录音没有转写，本课用已转写好的文本演示。

## 操作路径，做到按钮级
第 1 步，打开 WorkBuddy，左侧任务列表顶部点击「新建任务」。第 2 步，点击输入框左下角「选择工作空间」，选中 lesson14。第 3 步，在对话框输入结构化提示词，要求输出会议信息、与会人员、问题背景、结论、行动计划表（含负责人/交付物/截止时间）、下次会议时间。第 4 步，点击「发送」，等它分析并生成纪要。

自然语言一句话版可以直接抄：lesson14_素材包里的会议录音转写、议程和待办初稿，输出一份完整会议纪要，包含与会人员、问题背景、结论、行动计划表和下次会议时间。

## 结构化提示词长什么样
**任务：**根据会议录音转写、议程和待办初稿，整理成一份正式会议纪要。输入三份材料路径（录音转写.txt、会议议程.md、待办事项初稿.md）。输出要求五项：一、会议基本信息（时间、地点、主题、参会人）；二、问题背景（客户目标、当前状态、关键数据）；三、主要结论（已确定的根因方向、客户回复节点）；四、行动计划表，五列——序号/任务/负责人/交付物/截止时间；五、沟通机制（客户日报、下次会议时间）。

再加四条约束，质量差别很大：不要遗漏任何带责任人和截止时间的行动项；缺少负责人或截止时间的用「待确认」标注并单独列出；行动计划按时间先后排序；输出为 Markdown 文件并保存到指定路径。

## 我第一次只说了「帮我整理成纪要」
结果它输出了一份像散文的东西，没有行动计划表，还搞混了两个负责人的任务。原因很明确：我没告诉它需要输出哪些字段。而会议纪要真正值钱的就是那三件事——谁、做什么、什么时候交。

把模糊指令改成结构化指令后，AI 会按固定格式输出，你审一遍就能直接发。差别不在模型，在你有没有把字段写死。

## 出来的纪要长这样
**一个真实例子：**某车门锁执行器 NVH 问题评审会纪要。会议时间、地点、参会人写在最前；问题背景里写明客户目标「解锁噪声 ≤45 dB(A)」，当前测试 48–51 dB(A)、低温段偏高 3–5 dB；主要结论给出根因方向「齿轮啮合冲击 + 电机断电脉冲」，待 DOE 和仿真验证。

接着是行动计划表，五列齐全：1. DOE 方案与样件协调 / 陈工 / 实验方案、样件到位 / 2026-07-09；2. 仿真建模对照 / 李工 / 冲击能量仿真结果 / 2026-07-12；3. 转速梯度测试 / 王工 / 3000–6000 rpm 数据 / 2026-07-10；4. 客户初步报告 / 张工 / 分析报告 / 2026-07-15；5. 每日进展日报 / 王工 / 日报邮件 / 每天 17:00。

**最后是下次会议：**2026-07-09 16:00，各方向汇报进展。右侧结果区「产物」标签里可以直接下载，也可以让 WorkBuddy 转成 Word 发给客户。

## 把它存成模板，下次只替换括号
**任务：**根据以下材料整理会议纪要。1. 会议录音转写：［文件路径］；2. 会议议程：［文件路径］；3. 待办初稿：［文件路径，可选］。输出：1. 会议基本信息 2. 问题背景/议题概述 3. 主要结论与决策 4. 行动计划表 5. 风险点与待确认事项 6. 下次会议时间。要求：行动计划按截止时间排序，输出为 Markdown 文件保存到［输出路径］。

存下来，下次开会只替换方括号里的内容就行。这一步省掉的不只是打字时间，还有每次重新想「该让它输出什么」的认知成本。

## 老兵提醒：纪要不是文学创作
会议纪要不是文学创作，是可追溯的行动清单。十几年项目做下来，会多并不可怕，可怕的是会后责任不清、deadline 模糊、客户追问时各说各话。

**我的习惯是五条：**会前给议程；会后立即转写；强制五列表格；人工审责任人；敏感信息先脱敏。这五条做全，AI 整理出的纪要基本可以直接发给客户。
