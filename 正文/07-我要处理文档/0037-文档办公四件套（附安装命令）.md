# 文档办公四件套（附安装命令）
## 13. pdf / nano-pdf（PDF 处理）
**真实名称：pdf（清单中也写作 nano-pdf）**。

**作用：合并、拆分、提取表格、加水印、OCR 扫描件、表单填写、加密解密。**

**安装命令：clawhub install pdf；或 clawhub install nano-pdf。**

**实测效果：50 页扫描版合同一句话转成可编辑 Word，手动 1 小时 → AI 2 分钟。**

## 14. docx（Word 文档）
**真实名称：docx**。

**作用：Word 文档创建、编辑、格式排版。**

**安装命令：clawhub install docx。**

## 15. xlsx（Excel 处理）
**真实名称：xlsx（清单中也作 Excel / Excel Master）**。

**作用：数据清洗、写公式、画图表、批量处理、自动对账。**

**安装命令：clawhub install xlsx。**

**实测效果：**500 行数据按城市分组求平均值并出柱状图，"一句话直接出结果"；另有对比称传统 15–30 分钟 → 30 秒。

## 16. pptx（PPT 生成）
**真实名称：pptx**。

**作用：一句话生成完整 PPT，含内容+排版。**

**安装命令：clawhub install pptx。**

**实测效果：15 页培训 PPT，发一段描述 12 分钟出完整初稿。**

## 17. local-whisper（本地语音转文字）
**真实名称：local-whisper**。

**作用：录音直接转文字，全部本地运行，不上传服务器。**

**安装命令：clawhub install local-whisper。**

**使用场景：把会议录音转文字，自动识别中文、按说话人分段、标注时间戳、提炼决议待办。**

## 18. baidu-drive（百度网盘管理）
**真实名称：baidu-drive**。

**作用：操作百度网盘——上传下载、搜索文件、转存分享。**

**安装命令：clawhub install baidu-drive。**

**说明：**第三方社区 Skill。

## 19. obsidian（Obsidian 笔记库）
**真实名称：obsidian**。

**作用：Obsidian 笔记库管理与自动化。**

**安装命令：clawhub install obsidian。**
