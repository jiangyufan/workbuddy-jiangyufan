# 针对岗位优化简历
**适用场景：投递特定岗位前，用简历对照 JD 做匹配度分析和改写。**

你是简历优化专家。请对照【目标岗位JD】分析并优化我的简历。

要求：

提取岗位的核心能力和关键词；

找出简历与岗位要求的匹配点和缺口；

优化项目经历和成果描述；

优先使用可验证的量化结果；

不虚构经历、技能或数据；

输出修改后的简历和修改说明。

目标岗位JD：

【粘贴JD】。

原简历：

【粘贴或上传简历】。

## 附：使用前必知的 4 条规则
这批模板原文明确给出四条通用规则：①把变量替换完整——看到【目标文件夹】【主题】【目标岗位】必须换成真实信息；②AI 没有的材料要主动提供——分析 Excel 就上传 Excel，整理纪要就提供转写稿；③高风险操作先要预览——涉及发送邮件、公开发布、删除或移动文件时，增加一句"先生成预览和执行清单，等我确认后再执行"；④自动化任务需对应权限——定时任务、邮箱、钉钉、社交平台和本地文件操作要提前连接服务并授权，权限不足时让它明确说缺什么，不要假装执行成功。

另外，一个合格的提示词至少包含六个要素：角色 + 输入材料 + 具体任务 + 输出格式 + 质量要求 + 执行边界，其规律可归纳为"对象说清楚，任务拆具体，结果能验收，风险有边界"。1 若想套用更简的通用版，可用角色 + 背景 + 任务 + 资料 + 标准 + 格式，原文提供了可直接复制的完整版本。

想少改几遍的进阶做法是在五要素（角色/任务/约束/格式/示例）基础上加"自我校验"，让复杂任务"先规划、再执行、最后自检"。
