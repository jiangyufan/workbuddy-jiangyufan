# 接入企业微信
**方式 A：**内部员工（腾讯企业适用，最简）

针对腾讯企业做过定制化，腾讯内部员工无需任何配置，仅需打开集成开关。操作步骤：

登录 WorkBuddy 管理后台 → 选择「平台接入」→「企业微信」。

勾选「内部员工接入」，系统自动生成授权链接。

点击「开启集成」，全员即可在企微使用。

**验证：**在企业微信中搜索 WorkBuddy，直接发消息即可对话

**配套能力：**企微工作台侧边栏直接打开 WorkBuddy，无需安装 App；继承企微组织架构与角色权限；支持 SSO 单点登录，无需二次验证。

**方式 B：**外部企业（创建智能机器人 + API 配置）

**适用于与外部企业或合作伙伴通过企微机器人协作。完整步骤：**

**第 1 步：**创建智能机器人

前往企业微信官网（work.weixin.qq.com），使用有企业管理员权限的账号登录；如尚无企业需先注册。

在应用管理中创建「智能机器人」，填写机器人名称与可见范围。

**第 2 步：**选择连接方式并生成密钥

在创建页面右下方切换到「API 模式创建」（API 模式暂不支持预览与调试）。

API 配置有「使用长连接」和「使用 URL 回调」两种模式；当前已支持 URL 回调方式，长连接方式敬请期待。

**选 URL 回调后：**URL 先留空待回填；Token 和 Encoding-AESKey 点击「随机获取」生成，这是企微与 WorkBuddy 通信的加解密密钥

**第 3 步：**在 WorkBuddy 换取 URL

打开 WorkBuddy 的 Claw 设置菜单，点击「企微 AIBot 集成」旁的「配置」。

在「注册企微 AIBot 通道」弹窗中填入第 2 步获取的 Token 和 Encoding-AESKey，点击「注册」。

点击注册后即获得一个 Webhook，复制这个 Webhook 1。

**第 4 步：**回填 URL 并保存

回到企业微信机器人创建页面，把刚才复制的 URL 填入「URL」字段并保存。

**第 5 步：**验证接入

添加完成后无需配对，直接在企业微信聊天窗中与机器人对话；如果机器人能以 AI 方式对话，说明接入成功。也可扫描企微后台机器人二维码，找到机器人发消息、添加到群聊试对话。

**外部企业模式附加能力：**企微群内直接 @机器人下达 AI 指令，机器人自动回复任务状态与进度报告，重要事件与提醒主动推送；适用于跨企业协作项目群、客户服务与支持群、合作伙伴联合办公群。
