# 平台接入总览：四种通道，两种模式

> **说明：** 本篇是产品动态/短记录，原文本身只有简短说明和配图，不含完整操作步骤。它被收录是因为记录了当时的界面或功能变化，可作为版本对照；需要完整流程请到对应章节找长文。
WorkBuddy 的远程协作能力由电脑端 Claw 设置 → 集成（BETA） 统一管理，可接入企业微信、QQ、飞书、钉钉四类通道。所有通道的配置逻辑一致：先在目标平台创建应用/机器人拿到凭证 → 回到 WorkBuddy 填入凭证 → 复制 Webhook → 回到平台填入回调 → 验证连通。

**一句话区分两种接入方式：**内部员工方式最简，管理员一键开启即可；外部企业方式功能更强，需创建智能机器人 + API 回调配置。
