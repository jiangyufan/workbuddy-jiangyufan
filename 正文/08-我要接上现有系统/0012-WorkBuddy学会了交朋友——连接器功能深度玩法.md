# WorkBuddy学会了交朋友——连接器功能深度玩法
有没有想过——WorkBuddy就像一个有了手脚的AI，但如果没有“朋友"，它依然是个孤岛。

过去三个月，我们聊了WorkBuddy的三种模式（Craft、Plan、Ask），聊了它怎么帮思政课老师写教案、整理文献、分析成绩。

但那些场景，都有一个共同点：WorkBuddy只在自己的世界里干活。写好的教案，要手动复制到腾讯文档。整理好的文献目录，要手动发送到QQ邮箱。学生发来的作业，要手动下载再上传到微云。这些“最后一步"的重复劳动，正在被一个叫“连接器"的功能悄悄消灭。

## 一、连接器是什么。——让AI走出孤岛。
简单来说，连接器就是WorkBuddy与其他办公软件之间的桥梁。以前，WorkBuddy只能：读取你电脑上的文件。在你的电脑上创建文件。与你对话。现在，有了连接器，WorkBuddy还能：✅ 直接读取你的腾讯文档。✅ 直接发送QQ邮件。✅ 直接管理微云文件。

✅ 直接同步TAPD任务。✅ 直接操作腾讯乐享知识库。一句话总结：WorkBuddy从"本地助手"升级成了"全网助手"。

## 二、思政课老师的真实场景——连接器如何改变工作流。
1. WorkBuddy生成教案（.docx文件）
2. 我手动打开腾讯文档网站
3. 点击"新建" → "上传文档"
4. 选择文件 → 等待上传
5. 重命名 → 移到对应文件夹

现在的做法：

我对WorkBuddy说：「帮我写一份关于'新质生产力'的教案，写完后直接上传到腾讯文档，放在'2026春季学期/教案库'文件夹里，文件名格式为'新质生产力_20260502'。」。

WorkBuddy自动完成：

1. 生成教案内容
2. 调用腾讯文档连接器
3. 自动上传并命名
4. 返回腾讯文档链接

省下的时间：手动操作约5分钟 → 自动完成约30秒。场景二：学生作业自动收集+批改+反馈。

1. 学生在QQ邮箱发作业给我
2. 我手动下载每个附件
3. 逐个打开批改
4. 手动写邮件回复

我对WorkBuddy说：「检查我的QQ邮箱，下载所有主题为‘形势与政策作业'的邮件附件，按学号重命名，批改后生成反馈邮件，自动回复给学生。」。

1. 调用QQ邮箱连接器，搜索指定主题邮件
2. 下载所有附件到本地
3. 逐个批改（基于我设定的评分标准）
4. 生成个性化反馈邮件
5. 调用QQ邮箱连接器，自动发送

省下的时间：手动操作约3小时 → 自动完成约15分钟。场景三：公众号文章自动同步到乐享知识库。

1. 写好公众号文章（Markdown格式）
2. 手动登录乐享后台
3. 复制粘贴内容
4. 调整格式
5. 发布

我对WorkBuddy说：「把这篇公众号文章同步到乐享知识库，放在‘思政课PPT系列'目录下，标签设为‘AI+教育'和‘WorkBuddy教程'，然后生成摘要。」。

1. 读取本地Markdown文件
2. 调用腾讯乐享连接器
3. 自动创建知识库文章
4. 添加标签和摘要

省下的时间：手动操作约10分钟 → 自动完成约1分钟。

## 三、连接器的“隐藏玩法"——不只是效率工具。
上面说的都是“省时间"，但连接器的价值远不止于此。玩法一：跨平台知识融合。我有三个知识来源：

1. 腾讯文档：日常教案、课件
2. 乐享知识库：公众号文章、教学心得
3. 微云：参考文献、政策文件

以前，这三座"知识孤岛"是分离的。现在，我可以这样：

「帮我把腾讯文档里所有关于'AI+教育'的教案，乐享里所有相关文章，微云里所有相关PDF，整合成一份《AI+思政课教学手册》，包含：理论框架、实操案例、参考文献。」。

WorkBuddy通过连接器，同时读取三个平台的内容，自动整合。这件事，以前要花一整天，现在一杯咖啡的时间。玩法二：自动化教研工作流。我可以设置一个自动化任务：每周五下午5点，自动执行：

1. 从QQ邮箱下载本周所有学生邮件
2. 从腾讯文档读取本周所有教案
3. 生成《本周教学总结》：学生反馈摘要、教案更新记录、下周建议
4. 发送到我的QQ邮箱，并上传到微云备份

这就是“连接器+自动化"的威力：让你的AI同事在半夜帮你干活，早上醒来直接收报告。

## 四、如何配置连接器。——5分钟快速上手。
说了这么多，怎么把这些功能用起来。

## 第一步：进入连接器管理页面。
在WorkBuddy左侧导航栏，点击“连接器"，你会看到：QQ邮箱（已支持）。腾讯乐享（已支持）。腾讯文档（已支持）。TAPD（已支持）。微云（已支持）。自定义连接器（高级玩法）。

## 第二步：授权连接。
以QQ邮箱为例：

1. 点击“QQ邮箱"卡片
2. 点击“授权连接"
3. 跳转到QQ邮箱授权页面
4. 登录并确认授权
5. 回到WorkBuddy，显示“已连接"

就这么简单，30秒搞定。

## 第三步：在自然语言指令中调用。
不需要记命令，直接用自然语言：❌ 错误示范：「用QQ邮箱连接器发送邮件」。

WorkBuddy会自动识别你的意图，调用对应的连接器。

## 五、连接器的"边界"——哪些事它还做不了。
坦诚地说，连接器功能还在早期阶段，有一些限制：限制一：权限边界。WorkBuddy通过连接器能做什么，取决于你给它的权限。比如，你授权了QQ邮箱，但只给了“读取"权限，那WorkBuddy就不能发送邮件。建议：初次使用时，先给“只读"权限，确认安全后再开放“写入"权限。

限制二：平台API限制。有些平台对API调用有频率限制。比如，腾讯文档免费版每小时最多创建10个文档，超过会报错。建议：批量操作时，让WorkBuddy分批次执行，避免触发限制。限制三：复杂逻辑的跟腱。

如果工作流特别复杂（比如：先判断邮件标题→再读取附件→再根据内容分类→再调用不同连接器），目前的连接器可能会“卡住"。

建议：复杂工作流拆分成多个简单步骤，用Plan模式先规划再执行。写在最后。

回首这三个月，我们从“WorkBuddy是什么"聊到“三种模式怎么用"，再到今天的“连接器深度玩法"。

WorkBuddy在一步步从“工具"变成"同事"，从“本地"走向“全网"，从“单打独斗"走向“生态协同"。
