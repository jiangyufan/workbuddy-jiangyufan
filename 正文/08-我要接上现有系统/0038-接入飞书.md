# 接入飞书
**流程要点：**创建企业自建应用 → 添加机器人能力 → 批量导入权限 → 获取并保存 App ID 与 App Secret → 在 WorkBuddy 配置凭证并获取 Webhook → 在飞书开放平台订阅事件与卡片回调 → 完成应用发布。

**第 1 步：**创建企业自建应用

登录飞书开放平台，创建企业自建应用。

在「凭证与基础信息」中获取 App ID 与 App Secret，并妥善保存（避免泄露）。

**第 2 步：**添加机器人能力

在应用能力中添加「机器人」。

**应用图标要求：**JPEG/PNG/SVG/BMP 格式，2MB 以内，大于 240*240px，无圆角

**第 3 步：**配置权限

批量导入所需权限。

**第 4 步：**在 WorkBuddy 粘贴凭证

点击右上角个人按钮 →「Claw 设置」。

选择「飞书集成」→ 点击「配置」。

在「注册飞书通道」弹窗填入「飞书 App ID」（如 cli_a92360a836b89bb4）和「飞书 App Secret」（两者必填），Encrypt Key 与 Verification Token 为可选项，点击「注册」。

这一步的作用是让 WorkBuddy Claw 具有在飞书内收发消息的能力。

**第 5 步：**订阅机器人长链接，接收事件和卡片回调

回到飞书开放平台，找到刚创建的应用，配置「事件与回调」。

进入「事件配置」→「订阅方式」→ 选择「将事件发送至开发者服务器」→ 粘贴刚才在 WorkBuddy 复制的 Webhook → 保存。

**添加事件：**勾选「接收消息」事件 im.message.receive_v1（用户发送新消息至机器人或群聊后推送事件）并确认添加

**第 6 步：**发布应用

设置可见范围，创建版本并发布；应用发布通常可免审自动通过。

注意：应用发布后当前配置方可生效。

**飞书深度集成能力：**飞书消息中直接发送 AI 指令、飞书文档与多维表格数据互通、飞书日历事件自动同步到任务、飞书审批流程触发 AI 自动化；机器人高级功能包括自定义指令菜单、卡片消息交互式任务操作、群机器人定时播报项目进度、飞书工作台侧边栏嵌入 WorkBuddy。

**补充：**WorkBuddy 同样支持钉钉，通过钉钉开发者后台创建企业内部应用，在 Claw 设置的「钉钉机器人集成」中注册钉钉机器人以接收和回复消息。
