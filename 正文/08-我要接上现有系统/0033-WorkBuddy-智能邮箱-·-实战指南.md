# WorkBuddy 智能邮箱 · 实战指南
日 常 办 公。收发邮件。说一句话就行。繁琐的读写操作交给 AI，你只负责下指令、做最终确认。写邮件并发送。AI 起草全文，你确认后发出。语气、要点由你定。帮我给客户发邮件，告知项目已验收，语气专业但不太正式"。检索与摘要。按时间、主题、发件人检索，直接生成重点清单，附件也能先读。

找上周项目进度的邮件，把待办列成清单"。附件智能处理。下载、按规则重命名、提取关键金额，不用逐个打开。把报价单附件下载到桌面，按 客户名-日期 重命名"。HTML 富文本邮件。把邮件做成精美网页，适合周报、产品发布、节日问候。自 动 化 流。

把邮箱。变成自动化入口。不只是帮你发邮件，更是自动化管道的入口和出口。发票自动归档。监听新邮件 → 下载附件/正文链接 → 提取金额单号 → 写入对账表。行业资讯每日简报。每天定时检索新闻，整理成简报发到你的个人邮箱。个人邮箱联动。在 163/QQ/Outlook 设转发规则，把要处理的邮件转给 Agent Mail。

休假自动回复。监听特定发件人，防死循环逻辑，同一人只回一次。协 作 拓 展。不止收发。还能协作与变现。让邮箱成为你和团队、客户、机会之间的智能中转站。周报自动发送。每周提炼工作记录，生成结构化周报定时发领导。客户邮件批量跟进。按需求起草个性化回复，逐个确认后发出，非模板套话。

会议纪要分发。整理成含议题、决议、待办（含责任人）的邮件+附件。求职投递自动化。按 JD 定制投递邮件，甚至以你口吻与 HR 邮件沟通约面试。安 全 机 制。放心交给 AI。的四个理由。物理隔离。AI 用独立地址，个人邮箱零接触，互不干扰。

两阶段确认。发邮件先让你过目，像给 AI 装了"手刹"。防 Prompt 注入。邮件正文里的恶意指令不会被执行，防被邮件操控。附件可控。单附件最大 20MB，单封最多 50 个附件。实 战 技 巧。5 个。避坑要点。1。先说场景，再说操作。

找上周王总发的预算邮件，下载附件并提取金额" 比 "搜索邮件" 更准。2。批量处理分批确认。删除不可逆，先列清单确认范围，再执行下载/删除。3。自动化先测试再常驻。监听脚本写好后，多发几封测试邮件验证再常驻运行。4。不实时就别用监听。大多数邮件用定时任务即可，更省资源。
