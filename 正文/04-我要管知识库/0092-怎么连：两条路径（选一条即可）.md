# 怎么连：两条路径（选一条即可）
**路径 A：**原生内置授权（推荐，约 30 秒～2 分钟）

2026 年 5 月 28 日起，WorkBuddy 将 ima 知识库原生内置到「资料库」入口，不再需要通过 Skill 间接调用。

打开 WorkBuddy 桌面端，左侧导航栏找到「资料库」（或「更多」→「ima 知识库」，也可在「专家·技能·连接器」→「连接器」里找「ima 知识库」）。

在资料库列表拉到底部，看到新增的「ima 知识库」选项，点「立即前往授权」。

进入 OAuth 授权页面，用你平时登录 ima 的同一个微信扫码确认（扫码微信必须与存资料的是同一个号），这一步只需一次。

**授权页面会列明三项权限：**在 WorkBuddy 中查看你的知识库列表、查看或搜索知识库资料、将知识库文件添加到任务或将文件保存到 ima 知识库。

授权完成后，ima 里所有知识库——个人建的、团队共享的、订阅的——全部出现在列表中，每个库旁标注内容数量。

**路径 B：**通过 ima 技能 + API 凭证（传统方式，约 5 分钟）

在 WorkBuddy 技能商店搜索「ima 笔记」或「ima 知识库」技能，点击安装。

用电脑浏览器打开 https://ima.qq.com/agent-interface，用微信扫码登录 ima 账号。108。

点击「获取 API Key」，页面弹出 Client ID（格式类似 ima_xxx）和 API Key。

⚠️ API Key 只显示这一次，弹出来立刻复制保存；如果之前获取过，需先点「删除」再重新获取。

回到 WorkBuddy 的 ima 技能设置页，在 Client ID 和 API Key 两个输入框填入并保存。108。

另一种更省事的做法：在 IMA 客户端点左上角头像 →「Claw 配置」→ 点「一键复制」部署提示词 → 粘贴到 WorkBuddy 对话框发送，它会自动安装 IMA Skill（约 5 分钟）；安装过程中回到「Claw 配置」页面找到 Client ID 和 API Key 发给它完成鉴权。

**验证是否连通：**在对话框输入「列出我已有的知识库都有哪些」或「帮我列出我 ima 知识库中的所有知识库名称」，能正确返回列表就说明连接成功。12 或发送「查看 ima 配置」核对已绑定的库名和密钥；发送「测试是否连上」能返回知识库列表即绑定成功。
