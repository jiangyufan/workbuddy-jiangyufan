# 腾讯ima × WorkBuddy 完整打通指南
上个月，一个做内容的朋友跟我说了一件事。

她每天早上花两个小时刷行业资讯，收藏了几百篇文章，但每次要写竞品分析的时候，还是要从头搜。那些收藏的东西，根本用不上。

这不是她一个人的问题。收藏夹永远打不开，是所有知识工作者的共同诅咒。

腾讯在 2026 年 3 月把两个工具打通了——IMA 知识库负责「记住」，WorkBuddy 负责「动手」。这篇是完整的实操手册，从安装到跑通第一个工作流，全程没有废话。

## 先搞清楚：这两是什么。
不用长篇大论，一句话定位：IMA 知识库。

带 AI 能力的笔记 + 知识库。你往里存资料，它帮你理解、分类、随时用自然语言查。支持微信文章一键导入、PDF、Word、会议录音转写，免费 30GB 云存储。

住在你电脑里的 AI 同事，社区叫它「龙虾」。你说一句话，它自己拆解任务、读文件、生成报告、发推送，全程本地运行不上云。于上个月正式上线，免部署开箱即用，新用户免费送 5000 Credits。

单独用 IMA：只能查，不能干活。单独用 WorkBuddy：每次从头说需求，它不记得你攒了什么。两个打通之后才是完整的：存 → 管 → 用 → 创，一条链跑。

## 第一步：装好两个工具。
1. 打开 codebuddy.cn/work/
2. 下载对应系统版本（Win / Mac，安装包约 150-180MB）
3. 打开软件，登录腾讯账号
4. 系统自动赠送 5000 Credits，直接可用

⚠️ WorkBuddy 目前是桌面端工具，需要电脑安装。Mac / Windows 均支持。手机可以通过微信远程遥控电脑端干活（下面会讲配置方法）。

## 第二步：把两个工具连起来。
使用上个月上线的 IMA Skills。连通之后，WorkBuddy 可以直接读写你的 IMA 知识库。配置分两种路径：

方法一：通过 WorkBuddy 技能商店（推荐）。

- 生成 IMA API Key 打开 ima.qq.com/agent-interface，登录后点击「生成 API Key」，复制保存 Client ID 和 API Key。
- 安装 IMA 笔记技能 打开 WorkBuddy，点击左侧「技能」窗口，搜索「ima 笔记」，点击安装。
- 填入凭证，保存 在技能设置页面，分别填入 Client ID 和 API Key，点击保存。完成后输入指令测试：「帮我列出我的 IMA 笔记」，能返回列表就说明连通成功。

方法二：通过 IMA 手机 App 配置（更快）。

打开手机 IMA App → 「我的」→「CLAW 配置」→ 复制凭证 → 粘贴到 WorkBuddy 对应设置项。整个流程约 2 分钟。

## 第三步：配置微信操作（可选）。
这是 WorkBuddy 全量开放的功能。配置之后，你在外面开会、通勤，掏出手机发一句语音，电脑上的 WorkBuddy 立刻开始干活，结果推送回微信。

微信 ClawBot 配置。

1. 电脑端升级 WorkBuddy 到 4.6.4 及以上版本
2. 打开「设置」→「Claw 设置」→「微信 ClawBot 集成」
3. 点击「配置」，生成二维码
4. 手机微信扫码绑定，完成 绑定后，手机微信会多一个联系人「ClawBot」 发语音或文字给它，电脑端立刻执行，结果推送回聊天窗口 支持发送图片、文件，全程本地运行，隐私安全

除了微信，WorkBuddy 还支持企业微信（稳定性最高，推荐团队用）、QQ、飞书、钉钉，7 个平台按需选一个配置即可。

## 3 个可以复制的场景。
场景一：每天早上 9 点，行业热点自动整理推送微信。打开 WorkBuddy，点击「自动化」→ 新建定时任务，填入：

每天早上9点，自动搜索今日[你的行业]领域最新动态， 从我的IMA知识库里调出近一个月相关背景资料做对比， 整理成500字摘要，发送到我的微信。

设置一次，每天自动执行。结果推 Markdown 格式到微信，上班路上直接看。场景二：在外面开会，手机发一句话，电脑自动出竞品报告。打开微信，给 ClawBot 发语音：

从我的IMA知识库里找出所有关于「XX竞品」的笔记， 结合今天的最新公开信息，整理一份竞品分析报告， 用PPT格式输出，保存到桌面，完成后告诉我。

WorkBuddy 会调取你之前存进 IMA 的所有相关资料，加上实时搜索，生成 PPT 后推送通知到微信。你回到电脑前，文件已经在桌面了。

场景三：每周五自动整理本周会议纪要，存入 IMA。

每周五下午5点，读取桌面「会议记录」文件夹里本周新增的文件， 提炼关键决策和待办事项，整理成统一格式的周报， 自动存入我的IMA知识库「2026-Q2-会议纪要」文件夹， 完成后发送摘要到企业微信。

这个场景把「干活」和「存档」一步合并——WorkBuddy 整理完直接写回 IMA，下次要查历史决策，IMA 里全有。

坑一：WorkBuddy 调 IMA 很慢。

原因是知识库太大、任务太复杂，或者赶上网络高峰（工作日上午 10-11 点、下午 2-4 点）。解决方法：把最常用的资料单独建一个小型知识库专用于高频查询；简单搜索直接用 IMA App，不经过 WorkBuddy。

坑二：Credits 消耗太快。

把 Credits 用在高价值任务（生成 PPT、数据爬取、复杂报告），简单查询直接用 IMA App。API 调用通过 WorkBuddy 访问 IMA 知识库有免费次数，普通用户基本用不完，不用担心。

坑三：指令说得太模糊，结果一塌糊涂。

不要说「帮我做个报告」，要说「读取 data/ 文件夹里的 Q1 销售数据，按区域汇总，生成柱状图和饼图，输出为 PPT 格式，保存到桌面」。指令越具体，结果越可用。

坑四：知识库乱，AI 调出来的也乱。

建议按「项目-时间-类型」三维结构组织 IMA，比如「2026-Q2-竞品分析」「2026-Q2-会议纪要」。WorkBuddy 查询时能精准定位，效果质变。

回到开头那个朋友。我把这套工作流发给她之后，她花了一下午把三个月的收藏文章整理进 IMA。第二天早上，她发消息说：「我刚在上班路上发了一条微信，回到工位竞品报告已经在桌面了。」。工具不是学会了才用，是用起来才会真的会用。两个都是免费公测，先装上，跑起来再说。
