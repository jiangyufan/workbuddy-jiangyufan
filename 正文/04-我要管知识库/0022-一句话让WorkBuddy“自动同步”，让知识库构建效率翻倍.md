你是否也有过这样的时刻：“上周看到一篇很有价值的公众号文章，随手转存到微信收藏夹”。“电脑桌面上散落着10多次项目研讨会的会议纪要”。“各种公益研报、政策要求PDF堆在本地文件夹里，要找的时候翻半天”。想写一份项目总结，却想不起哪份资料里有关键数据"……

如果你已经考虑使用或高频使用 ima 知识库，那么今天这篇文章值得收藏。

我们不需要手动拖拽上传，不需要打开浏览器插件。只要给 WorkBuddy一条简单的指令，就能把散落在各处的资料自动归入 IMA 知识库，甚至还能监管本地文件夹，有新文件自动同步。

## WorkBuddy × IMA：这是什么组合。
简单说：ima：你的知识库，负责存资料。WorkBuddy：你的 AI 助手，负责「发指令让资料自动进知识库」。两者的协作就像这样：你说："帮我把这个链接加到 ima 的「行业动态」知识库"。WorkBuddy：✅ 已添加。你说："帮我监管 D盘的“公益项目”文件夹，有新研报、会议纪要就自动同步到 ima "。

WorkBuddy：✅ 已启动。不用再三番四次打开 ima 客户端，也不用手动选择分类，一句自然语言就搞定。听起来是不是很方便。下面我们就一步步演示具体如何操作。

## 第一步：让 WorkBuddy 连上你的 IMA。
1. 获取 API 密钥

API ：不同软件系统间的“桥梁”，允许它们安全、高效地交换数据或功能。例如，微信登录其他App时，实际是调用了微信的API验证身份。

你会看到 API Key 和 Client ID 两个值，点击一键复制就能获取。

## 第三步：让知识库「活起来」——自然语言提问。
资料入库只是第一步，真正有价值的是「随时可问」。

1. 跨文件搜索整合

对它说：在我的IMA知识库里，搜索关于「老年友好社区」的相关内容。把找到的资料整理成一份摘要。WorkBuddy 会在多个知识库里搜索，从不同文档中提取关键信息，整理成一份综合摘要。

1. 基于知识库写材料

对它说：基于我「项目研究资料库」里的内容，帮我写一份关于社区数字化治理的3分钟演讲稿。WorkBuddy 会从知识库里提取相关资料，写成有数据、有案例的演讲稿。

1. 快速查找引用

对它说：我需要引用一份关于「社区领域公益组织数量」的数据。在我的知识库里找找，告诉我具体在哪份文件的哪一页。WorkBuddy 会定位到具体文件，甚至给出页码和原文段落。对比一下。

如果你每周需要频繁查找、下载、整理各类资料资料，现在，用workbuddy一句话就能批量上传、直接定位项目数据、多文件自动提取整合。整个流程顺畅许多，能显著减少重复操作的时间。

这套工作流适合哪些公益场景。
