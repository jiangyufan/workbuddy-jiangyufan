# 腾讯又放大招了！ima推出知识Agent，全场景感知功能太香了！
腾讯ima正式上线copilot功能，支持创建专属Agent，主打一个「越用越懂你」，对我们这些ima知识库的重度用户来说，真是太香了。

那么，这次更新的copilot功能厉害在哪里呢。如何实现「越用越懂你」。我们不说太复杂，就简单总结这三点。

## 一、长记性了。是自主进化的四层记忆系统：
是自主进化的四层记忆系统：

1. copilot设定层：就是我们创建的专属Agent的人设，可以设定它的说话、做事的风格。这不只是配置项，这是Agent开始搞清楚「自己是谁」的起点。
2. 用户档案：记录和更新用户的信息、喜好、习惯等。让Agent知道用户的信息越多，帮助得越到位。Agent是在认识一个人，而不是单纯的建一个档案。
3. 长期记忆：跨场景记住你重要的事。比如你最近在做什么项目或者学习什么知识。
4. 经验技巧：在任务中积累经验和技巧，能跟用户配合得越来越默契。

## 二、浮窗形式的全场景感知。
这个是让我最为惊喜的功能，可以感知你当下在ima里做什么。你只需点击「小窗打开」，它会以浮窗悬停在ima应用内，无论你是在ima里浏览网页、文件、知识库或笔记，它会全程伴随，自动感知当前内容。

重点是：不需要额外上传文件或者复制链接，直接问「帮我总结这个网页，生成笔记后加入我的知识库」，它就帮你读取操作完成。实测真是太好用了。
