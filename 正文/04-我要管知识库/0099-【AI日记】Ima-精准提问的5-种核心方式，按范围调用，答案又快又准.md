# 【AI日记】Ima 精准提问的5 种核心方式，按范围调用，答案又快又准
同样是用AI，为什么别人回答精准、高效、不跑偏，而你问半天，结果却对不上教学资料。秘密不在“问什么”，而在让AI明确：该读你哪些资料。今天一次性讲透： IMA 5 种按范围提问法，学会直接封神。1️⃣ 基于文件夹提问（最精准） 操作：进入知识库具体文件夹 → 在对话框直接提问 优势：答案只看这个文件夹，范围最小、针对性最强 适用：分析某年级、某单元、某次作业、某专题所有资料 ✅ 示例： 分析本文件夹内课题申请的相关内容，并提炼课题申请要点。2️⃣ 基于知识库提问（全面 / 精准） 操作: 方式A：首页对话框输入 @ → 选择 1 个或多个知识库 方式B：进入某知识库根目录直接提问 优势 @单个库：针对性强 @多个库：视角更广，适合综合总结、调研 适用：调用整学科知识库、个人库 + 专业库联合分析 3️⃣ 基于标签提问（跨文件夹调用） 操作：在对话框输入 # → 指定标签 优势：跨文件夹、按逻辑聚合资料，解决“散在哪都能一起用” 适用：一键调取所有 #AI融合 #小学英语 等同类内容。

吐个槽，Ima这么强大，为啥不能实现自动打标签呢，其实手动打️标签也挺麻烦哈。4️⃣ 基于特定文档提问（最聚焦） 操作：打开单篇 PDF/Word → 右侧「问问 IMA」提问 优势：只精读这一篇，深度解读、不跑偏 适用：读长论文、析教案、解术语、评学生单份作品。

ps:这功能只支持pc端，问问ima，老方便了。5️⃣ 直接对话（不调用知识库） 操作：首页不 @ 任何库，直接提问 说明：用大模型通用知识 / 联网搜索，不读你的个人资料 适用：查常识、要资讯、创意写作、头脑风暴  一句话速记（建议收藏） 要最精准 → 进文件夹问 要最聚焦 → 就单文档问 要跨文件 → 用#标签问 要整库/多库 → 用@知识库问 要通用问答 → 直接聊  用好这 5 种提问方式， AI 才能真正成为你的第二大脑， 资料不乱跑、回答不跑偏，教学效率直接翻倍。
