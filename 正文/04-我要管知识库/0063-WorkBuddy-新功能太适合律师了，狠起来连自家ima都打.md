# WorkBuddy 新功能太适合律师了，狠起来连自家ima都打
WorkBuddy 这次的新功能，我觉得特别适合律师。甚至有点狠——连自家的ima都干。

WorkBuddy 正式加入了资料库功能，简单理解，你可以把它看成一个内置的知识库。但这次真正让我觉得有意思的，不只是“能存资料”，而是它把知识库 + HTML 人机协作 + 一键发布网站串到了一起。

这三个能力，律师都很有用。01 WorkBuddy 也有自己的“知识库”了。第一个，就是WorkBuddy 资料库。

*专家·技能·连接器｜应用·灵感*

你可以创建不同的空间，把自己的文件、文档、资料上传进去，也可以直接把 WorkBuddy 执行任务后的结果存进资料库。

比如律师完全可以按照自己的业务做：

婚姻家事资料库、建设工程资料库、企业法律顾问资料库，或者直接给某个重点客户单独建一个资料空间。当任务需要某个资料库时，可以直接把它添加到任务里。

以后让 WorkBuddy 干活的时候，就不用每次重新找文件、重新上传。

*日常办公 代码开发 设计创意｜数据分析及可视化*

目前免费的资料库容量是5G，日常存一些法律资料、项目文件，我觉得已经够不少律师用了。02 HTML 终于可以直接改了。第二个功能，我反而觉得对律师特别实用：HTML 网页支持人机协作修改了。我经常在课程上跟大家讲，HTML 是 AI 时代非常值得律师掌握的一种“可视化输出形式”。

不是让你学写代码，而是因为它确实适合做很多东西：案件汇报、法律服务方案、客户报告、个人介绍、法律体检报告……相比普通 Word 文档，做出来通常更加直观，也更有展示感和美观。但以前有一个问题：AI 生成 HTML 很容易，改起来很麻烦。

律师又不懂 HTML 语法，可能只是想改两个字、删一段话、调整一个标题，都得重新跟 AI 对话，严重一点甚至重新生成一版。

现在 WorkBuddy 直接把这个问题补上了。你可以像改普通文档一样，自己直接改文字；也可以选中某一块，告诉 AI：

以后 HTML 做出来哪里不满意，不用推倒重来，直接改。这个体验提升其实非常明显。03 做完网页，终于可以直接发给客户了。第三个，是我等了比较久的能力：WorkBuddy 里做出来的网页，可以一键发布成网站了。这个对律师的使用场景一下就打开了。

比如你用 WorkBuddy 做了一个个人介绍网站，发布以后直接把链接发给客户。

做了一份案件可视化汇报，也可以直接变成一个网页链接。做了一份法律服务产品介绍、企业法律体检报告、普法专题页面，也不用再截图或者导 PDF，直接转发。以前 AI 帮你“做网页”，很多时候只解决了制作这一半。现在 WorkBuddy 开始把“做出来”到“发出去”这一步也打通了。

当然，目前还不支持绑定自己的域名，这一点我还是比较期待后续补上的。

如果以后能直接绑定律师自己的域名，那个人官网、业务介绍页、法律服务产品页这些东西，基本真的可以在 WorkBuddy 里面一条龙搞定了。

所以这次更新看下来，我觉得 WorkBuddy 的方向已经越来越明显了：它不只是想帮律师“问问题、写东西”。而是在慢慢变成一个地方——你的资料放在这里，AI 在这里干活，结果在这里修改，最后还能直接发布出去。这个闭环，对律师来说，确实有点香。
