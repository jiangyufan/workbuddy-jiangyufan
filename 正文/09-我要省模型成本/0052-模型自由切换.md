# 模型自由切换

> **说明：** 本篇是产品动态/短记录，原文本身只有简短说明和配图，不含完整操作步骤。它被收录是因为记录了当时的界面或功能变化，可作为版本对照；需要完整流程请到对应章节找长文。
**是什么：**WorkBuddy 内置多种业界主流模型（国内版支持 Hunyuan 混元、DeepSeek、GLM、Kimi、MiniMax），可按任务需求灵活切换。

**怎么操作：**

在对话中随时点击模型选择器切换当前模型，无需重新创建会话，上下文保留。

可手动切换，系统也会根据任务类型自动推荐最优模型；不同 Agent 可分别使用不同模型。

快捷键 Ctrl+M 可切换模型。

**适合场景：**不同任务对模型能力要求不同——创意写作选文学能力强的模型（如 Kimi 创意写作一流、长文档解析优），代码开发选推理能力强的模型，多语言任务选跨语言表现优的模型。官方强调混元、DeepSeek、Kimi 分别侧重中文本土化、逻辑推理与代码、长上下文处理，系统按任务类型智能调度。
