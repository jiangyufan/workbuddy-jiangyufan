# DeepSeekV3.1到底更新了什么？五个维度用大白话告诉你。
## 1.更新内容
经过思维链压缩训练，V3.1 在思考模式下，相比 DeepSeek-R1-0528，能在更短时间内给出答案，且输出 token 数减少了 20%-50%，同时保持了与前代相当的性能表现。

2.更新后区别。

·这意味着在相同的任务下，V3.1-Think 能够以更快的速度生成答案，并且消耗更少的计算资源，在计算资源优化上具有明显优势。

3.应用场景细分。·【在线教育】：在智能辅导场景中，学生提问后，模型可以更快给出解答，减少学生等待时间，提高学习效率。·【智能客服】：企业客服系统中，模型能够快速响应客户问题，同时降低企业的计算成本。

## 二、上下文窗口扩展：从 64k 到 128k
V3.1 将上下文窗口从原有的 64k 扩展至 128k，这使得模型能够处理更长篇幅的文档和代码。·扩展上下文窗口后，模型可以处理结构更复杂、内容更丰富的文本。·在处理长篇文档时，它能够通览全文，精准提炼核心观点、梳理论证逻辑，甚至完成文献综述；

·面对大段复杂代码，也能理解整体架构，快速定位错误、提出优化建议。

**·【学术研究】：**学者处理长篇学术论文时，模型可以对论文进行全面分析，辅助学者进行文献综述、观点提炼等工作。

**·【软件开发】：**程序员在开发大型项目，面对大量代码时，模型可以理解代码整体架构，帮助程序员快速定位代码错误，提出优化建议。

通过 Post-Training 优化，新模型在工具使用与智能体任务中的表现有较大提升。DeepSeek-V3.1 可以支持多种 Code Agent 框架，开发者能够自己搭建智能体。

·在编程智能体任务方面，如代码修复（SWE）测试中，相比之前的 DeepSeek 系列模型，V3.1 所需轮数更少，表现更优。

·在搜索智能体能力上，在需要多步推理的复杂搜索测试（browsecomp）中，V3.1 得分大幅领先 R1-0528。

**·【自动化办公流程】：**智能体可以自动处理文档、安排会议、协同各部门工作，提高办公效率。·【工业生产协同】：在工业生产中，智能体能够操控不同设备完成复杂生产流程，提升生产效率与协同性。

V3.1 在多语言处理能力上进行了全面优化，目前能处理超过 100 种语言，尤其对亚洲语言和资源较少语种的运用进行了优化。

这使得模型在全球范围内的适用性大大增强，能够更好地满足不同语言背景用户的需求。

**·【跨国企业办公】：**企业内部不同语言背景的员工沟通协作时，模型可以帮助翻译文档、辅助交流，打破语言障碍。

**·【跨境电商】：**商家与全球客户交流时，模型能够理解并回复不同语言的客户咨询，提升客户服务质量。

DeepSeek-V3.1 最大的亮点之一是采用了混合推理架构，即一个模型同时支持思考模式与非思考模式。在官方 App 和网页端，用户可通过点击 “深度思考” 按钮，轻松在两种模式间自由切换；在 API 调用时，开发者也可通过选择 “deepseek-chat”（非思考模式）或 “deepseek-reasoner”（思考模式）来满足不同场景需求。

·思考模式下，模型会展示完整的推理过程，适用于复杂问题求解、逻辑推导等任务，相比旧版本，它能更迅速地给出答案，大幅提升思考效率。

·例如在解决复杂数学问题或逻辑推理题时，思考模式可以逐步分析问题，给出详细的解题步骤。

·而非思考模式则直接给出简洁的答案，适合常规的信息检索、简单对话等一般性任务，保障流畅交互体验，比如日常闲聊、简单信息查询等场景。

**·【科研场景】：**研究人员在推导复杂理论、分析实验数据时，使用思考模式，模型可以详细分析数据，给出推导过程和结论，辅助科研工作。

**·【日常办公场景】：**员工查询会议安排、文件资料等简单信息时，非思考模式能快速给出答案，提高办公效率。总结：2025 年出的开源大模型 DeepSeek-V3.1，技术和产业意义都挺重。​

技术上，它不用拆成两个模型，一个就能同时搞定对话和复杂推理，还能灵活切换模式，成本降了，也给行业提供了新思路，另外处理长文本、用高端技术训练的能力也很顶尖。​。

应用上，它离智能助手更近了，写代码、搜网页、用工具更厉害，能初步完成 “感知 - 思考 - 用工具 - 反馈” 的流程，已有开发者用来做编程助手、整理信息。​。
