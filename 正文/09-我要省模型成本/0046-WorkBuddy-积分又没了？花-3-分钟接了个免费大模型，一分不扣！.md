# WorkBuddy 积分又没了？花 3 分钟接了个免费大模型，一分不扣！
![积分再也不用担心花完了！](https://mmbiz.qpic.cn/mmbiz_jpg/hHdicyWfdctmtCJYhe5s3tiavIllMoPBotRyyMoqGP9lydZzZ5zDZiaVrFYdnbicrnu48CiatTl0D5nAZiab1qHHa1Ag00Bow6y6MEFUoL1swJ13Y/640?wx_fmt=jpeg&amp;from=appmsg&amp;watermark=1#imgIndex=0)

*积分再也不用担心花完了！*

嗨，大家好，我是iscuker。

用过 WorkBuddy 的都懂那种感觉：深夜灵感来了，报告写到一半，「积分不足」四个字弹出来，真的很糟心。

至于签到领积分。升级套餐。怎么算都不划算。

想起来WorkBuddy 一直留着自定义模型的口子。内置模型走积分，自定义模型走你自己的 API，积分消耗直接归零。

昨天试了一下，接的是 OpenRouter 上一个叫 Ox Alpha 的模型。这模型有点意思，还在“隐身期”，但能力是真有：免费、上下文 100 万 token、会思考、能看图、还能调工具。重点是——不花钱。

整个过程三步，比泡面还快。

## 第一步：去 OpenRouter 拿钥匙。

![](https://mmbiz.qpic.cn/mmbiz_png/hHdicyWfdctmHsgDajW4ABSN3XAGgOZoTXcs3knIwug6ZJxTfIJW5Aj2lxEjQo3TurFYtISVrfWTg3ZEOxhasgtGicxVMpVuB2piba5VUUWiaHE/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=1)

浏览器打开 openrouter.ai/keys，Google 或 GitHub 一键登录，点 Create Key，起个名字，复制那串 sk-or-v1- 开头的字符串。

两个坑提前说：Key 只显示一次，关掉页面就再也找不回，当场存好；免费模型不需要绑卡充值，一路下一步就行。

## 第二步：回 WorkBuddy 配置模型。

![自定义模型｜本地配置文件](https://mmbiz.qpic.cn/mmbiz_png/hHdicyWfdctkm2dgYpvsCvW5o0jIkraQibofic7OlnkA7IXzpAibAvXMYCZtfuFKNdyY93kTuRxr3hye8suGL5K6dYxbNt8Mw98hzSia3MRSpsUE/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=2)

*自定义模型｜本地配置文件*

能力开关全打开：工具调用、图片输入、推理模式都勾上——这模型是真支持，不开白不开。上下文长度直接拉满 1000000。

- 重启，开聊

![微任务赢积分好｜数据分析及可视化](https://mmbiz.qpic.cn/sz_mmbiz_png/hHdicyWfdctmeMcfTKQLkDyzJU9EMeIYIYvsCCGeWpl1QHhEkfag20zW005nibWkQ1X3GDiaVYQHKx9tK6n1WGibenpynJZS1zQIDuavRCJI1uM/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=3)

*微任务赢积分好｜数据分析及可视化*

保存，完全退出再重新打开WorkBuddy（它是启动时读配置的，不重启看不见）。回到对话界面，模型下拉里找到 Ox Alpha，选中，随手发条消息。等回复出来，再瞄一眼账单：Cost $0.00。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/hHdicyWfdctm2F8oHUJTEqXHxqVef0x57qMHEw3eun2Dxxn87zRdl9o8WjHU6kNswp1APOg7yTjjh230JbXGgA3ibCKibJPxcsgZcqwdPKticibM/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=4)

好用是真好用。100 万上下文什么概念。整份长报告扔进去，它不带喘的。免费额度对个人玩家也相当宽裕。但也不是没毛病：性子慢，第一次回复得等个七八秒，急性子慎选；偶尔工具调用还会抽一下风。

所以我现在是混着用：轻量问答走混元 HY3，重活、长文档丢给 Ox Alpha，各干各的，互不耽误，积分还省下来了。

三个注意点，记好：免费档每天有请求次数上限，批量跑任务留点余量；Key 泄露了就去 keys 页面删了重建，一分钟的事；以后想换模型，只改「模型名称」那一格就行，其他不动。

## 最后说两句。
折腾完这一圈，最打动我的其实不是省了多少钱。而是它提醒了我：AI 时代真正的底气，从来不是你用上了多强的模型，而是你随时能换掉它。供应商会涨价，套餐会改版，模型会过气。但只要接口是通的，Key 在你自己手里，主动权就一直在你手里。工具如此，人也一样。

愿我们都做那个握着钥匙的人。我是 iscuker，8 年地产人、5 只猫的铲屎官，也在学着不那么用力地生活。顺势顺祈，岁月茸茸。
