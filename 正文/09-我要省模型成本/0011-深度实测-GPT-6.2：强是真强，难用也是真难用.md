# 深度实测 GPT-6.2：强是真强，难用也是真难用
![](https://mmbiz.qpic.cn/mmbiz_gif/dCG7OC48IfJVEylFtLHiagt65VNBm59eyibNlzF5GpkR1sFIGiaJcH2eh3or6O0mbVnAGZmD2KVjGoMoREPhNDVVKMjzKBNzeOMwTtf2J9LejY/640?wx_fmt=gif&amp;from=appmsg#imgIndex=0)

就在今天，OpenAI 正式发布了新一代旗舰模型 GPT-6.2 Astra，以及主打性价比的 GPT-6.2 Sol。

从官方公布的成绩来看，GPT-6.2 Astra 在专业 Agent 任务上反超 Claude Fable 5.2，完成同等任务的综合成本却只有后者的 5%，堪称一次漂亮的反击。

![](https://mmbiz.qpic.cn/mmbiz_jpg/dCG7OC48IfIGxYSa46iayqUeuBSdJmL4tvvJwWgtgawsdjp8vT3Lp9UsplcLJGjwB3mweByG0xmfFWjRYEa3d8byaOC1JETjicrWkiaQIsRwz4/640?wx_fmt=jpeg&amp;from=appmsg#imgIndex=1)

上下滑动查看更多内容。然而，模型上线不到 12 小时，X 上就出现了大量差评。

知名开发者 Theo 直言，这是「OpenAI 史上最糟糕的模型」；AI 创业者 Matt Shumer 更是评价其「基本无法使用」。

![OpenAI 刚刚发布了 Astra 6.2 和 Sol 6.2!｜完整的体验评测即将在 @every 上发布！](https://mmbiz.qpic.cn/sz_mmbiz_jpg/dCG7OC48IfJbCAHrw5pGhMfL0rtL6rT0rp9Kqoib1wMAQhHYU3YfH6Ylb94I14y7cdYicmJE8UMWJ82UIYxia3SlcgtHCky79u4mpzVAKFVf1g/640?wx_fmt=jpeg&amp;from=appmsg#imgIndex=2)

*OpenAI 刚刚发布了 Astra 6.2 和 Sol 6.2!｜完整的体验评测即将在 @every 上发布！*

争议主要集中在几个方面：回答过度简洁，写作水平倒退，长程 Agent 任务容易提前停止，甚至遇到问题也不主动向用户报告。

![Get started 开始使用｜Key concepts 天键概念](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfKXp8Bq5griaqLulJl7ibXT5f7yDwuRJxXl0VxcE0BTOpqETjuRf8na5zr2fAfdUbFU5CtBZ9OSB2TpBeePU9IKLc5fp5XEoD20g/640?wx_fmt=png&amp;from=appmsg#imgIndex=3)

*Get started 开始使用｜Key concepts 天键概念*

但有意思的是，即便是批评最激烈的用户，也承认 GPT-6.2 Astra 在 3D 建模、空间推理和成本效率上的巨大优势，部分能力甚至领先于目前所有竞品。

![我一直在提前测试 Astra 6.2，我觉得它得到的评价不公平。](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfL0ZVibdbHacqxJOgRE014m6vJEmA0SRKuMT38s8Bldvy2DibgAluek4nHJGRRQoPH2OAj3NkiawAo22JyCKhFX7m9LKQPTlTs2Fg/640?wx_fmt=png&amp;from=appmsg#imgIndex=4)

*我一直在提前测试 Astra 6.2，我觉得它得到的评价不公平。*

一边是创纪录的性能和极低的成本，一边是社交媒体上几乎一边倒的差评。GPT-6.2 Astra 到底是一个被低估的天才，还是一个聪明却不好用的模型。

带着这些争议，我们让它完成了一系列真实任务，看看它究竟表现如何。

## 毋庸置疑的 3D 能力。
和 Fable 5.2 一样，我们从零开始用一句提示词，GPT-6.2 Astra 就给我们做出了这个游戏。

「你知道吗，你也应该给我做一个FPS。请务必做到极其精细的质量，视觉效果要看起来能跟AAA大作媲美。范围做小一点（比如一个小关卡），但除此之外要有令人惊艳的照片级真实画面。」。

即便我们使用的是 Ultra 的推理程度，GPT-6.2 也只花了 17 分钟的时间完成这个游戏项目。

经典的鹈鹕项目，GPT-6.2 Astra 绘制的 3D 鹈鹕骑自行车，感觉也已经来到了下一个阶段，从一开始的 2D SVG，到后来的 3D 动画，再到现在的超写实真实鹈鹕。

我们也参考 Fable 5.2 的经典案例，让 GPT-6.2 Astra 做了一个 Pop-up Atlas，一本可以走进去的 3D 立体书。

玩家可以控制一个提着灯的纸片旅人，沿着溪流、红桥和山村散步。镜头跟着它走，前方的树和房屋从书页上立起来，走远后，身后的景物又慢慢折平。

成这个项目的交付文档里，GPT-6.2 写着「性能方面，测试环境只能使用 SwiftShader 软件渲染」、「Blender 建模脚本已附上，本次 glTF 由同一套模型定义经 CPU 导出」、「在线预览发布时遇到 DNS 故障」……

如果一个用户只是想要测试一些提示词的玩法，想要自己做一个简单的 Demo 小项目，根本不懂什么是 SwiftShader、也不知道 gITF 和 DNS 分别是什么，确实会对模型最后附上的这段文字感到疑惑。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/dCG7OC48IfLNvqUL26IAxH5r3T7jib0c8y0rab9sKHicI6hQF3EEdVEsjjpwDZROZXSoQMXntdcZojia3H8icJiaBG94QteKLZWdKJSnUibMWdu2c/640?wx_fmt=png&amp;from=appmsg#imgIndex=5)

更多的项目测试还有要求 GPT-6.2 Astra 构建一款第三人称开放世界犯罪游戏，背景设定在阳光明媚的1980年代迈阿密风格城市。

GPT-6.2 不仅给了我们一个可玩的游戏，还把整个游戏的测试过程做成了一份报告，里面涵盖了对抗、开跑车、刹车以及在沙滩散步等等场景。

![](https://mmbiz.qpic.cn/mmbiz_jpg/dCG7OC48IfL53sQuRRaiaZjUic8XoqRbU6Fcl6DffkewxXL3ZyHXKJvFAOeonichmDPSQKcrd7vWwzdD53jfeOwWHCBJy8tKv2LFWSjxboAUAs/640?wx_fmt=jpeg&amp;from=appmsg#imgIndex=6)

最让我感觉 GPT-6.2 Astra 超强 3D 能力，还是这个「孔雀开屏」的项目。

我们的提示词只是「画出一只极其逼真的孔雀开屏可交互 3D 动画」，模型就生成了可直接打开的互动 3D 场景，可以拖动视角，也可以手动控制孔雀从收羽到完全开屏，近看每根尾羽上的眼斑。

## 在线的审美，和确实该加强的写作。
现在的前沿模型几乎都已经摆脱了过去那种做什么都是一股 AI 味的状态，无论是做网页，还是生成报告，整体的样式都更高级，更具设计感。

我们直接跟 GPT-6.2 Astra 说「创建你能想象到的最美丽、最惊艳的单个 HTML 文件。」。

![□ 生成深海图鉴](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfLJsnibWtkEYGf7bnPqBF4UaeklnN3kibKJA3txj6c77X4XXFx55f9jWLjiaybahm30E816wZs5YOTeH9n8ibyrEqAgiatQzoBGJicoE/640?wx_fmt=png&amp;from=appmsg#imgIndex=7)

*□ 生成深海图鉴*

GPT-6.2 Astra 给我们的是一本想象中的深海图谱，收录于单个离线 HTML 文件中。玫瑰金水母在幽暗水域中脉动，条纹鹦鹉螺拖着象牙色触须，玻璃栉水母捕捉着光线。

我们还能将 2.5× 放大镜在标本上移动，以查看更精细的细节；或打开野外笔记本，查看石墨插图，同时可选的水下声景会随每幅图版而变化。

而各种文字的报告网页，GPT-6.2 Astra 也没有采用那些固定的风格，而是带了一些设计感。

图｜提示词：帮我深度研究一下黄仁勋最近的动态，从他宣布自己出轨，到今天英伟达的电话财报，把这些时间线都捋一下，用好看、生动形象，更具可读性，交互性强的网页报告呈现。

我们接着让它把这份报告制作为一份 PPT，GPT-6.2 Astra 生成的 PPT 文档也比之前缺少模板，样式单一的排版更加有审美了。

*从“锦鲤”重回工位到Reddit的“AI离职潮”:2026年，我们正在重新理解工作的意义｜一、被祛魅的“1亿红利”：当自由变成一张限期兑付的日程表*

而 GPT-6.2 Astra 给的文章呢，似乎很难看到它是怎么把这两件事联系起来的，它说「这些个人经历还回答不了有多少人因 AI 辞职，却足以解释那个程序员为什么想把画画留给自己。」。

读下来也觉得 GPT-6.2 写的文章很多类似废话的表达，像是「这一站带不回能剪进 vlog 的素材，她就没去。」还有大量的短句，割裂了文章的阅读体验，让人不明所以。

*AI 干活快了，为什么有人反而辞了职？｜比起那份网传价值一亿元的奖单，我更惦记她没去成的一个地方。*

又或是让它们写一篇高考作文，同样是泛泛而谈地 AI 解决所有问题，我们的认知障碍怎么突破之类的局限。Gemini 写的作文标题是「垂手可得的答案，与无可替代的追问」，遣词造句确实有很高考作文的感觉。

我们要面对的，不再是「如何做到」的技术困局，而是「为何而做」的价值迷思，以及「何以为人」的精神保卫战。

![垂手可得的答案，与无可替代的追问](https://mmbiz.qpic.cn/mmbiz_png/dCG7OC48IfJVTMGsNkiboZzdIHtuSgbZ6DIaFqPoFrKxkDcB8xKOiaibiafB07ySIlGOhYYGKlgxM0fnH0libF5AUcKKeGTBFH8qpBwNg8phApQE/640?wx_fmt=png&amp;from=appmsg#imgIndex=13)

*垂手可得的答案，与无可替代的追问*

而 GPT-6.2 Astra 的版本写的作文标题是「那一级台阶」，文章确实另辟蹊径，避开了 Gemini 那种大多数人都会写的角度，它说「AI 能算出最短路径的米数，却看不见物理与人心之间的那道落差。」。

但似乎又觉得很多观点的表达过于隐晦，文体也四不像，既不是议论文，也不是记叙文。而且这篇文章从第一段开始，就把重心完全滑向了「无障碍设施」和「关爱残障群体」。

全篇大段笔墨在讲轮椅导航、修学校台阶，AI 反而成了一个可有可无的背景板，会让人觉得 GPT-6.2 Astra 是背了一篇关爱弱势群体的文章，硬往 AI 题目上套。

如果是我，我想我也不会选择用 GPT-6.2 Astra 来完成写作方面的任务，因为写的东西确实一言难尽。

## 越聪明的，一定越好用吗。
仔细阅读社交媒体上对 GPT-6.2 「讨伐」最深刻的文章，会觉得模型和用户之间已经出现了某种错位，大家并不是觉得 GPT-6.2 「蠢」。

这篇文章对于 GPT-6.2 一顿炮轰之余，同样发现了不少优点：出色的审阅者，能发现其他模型漏掉的问题。

偶尔能提出真正出色的新颖解决方案。它帮我做出了一个新的反向代理，每月能省下 2.5 万美元，Opus 没那个胆量去探索足够多的选项。

在 3D 和游戏方面是世界级的。代码质量有了实质性提升。写的子 Agent 提示词相当不错。
