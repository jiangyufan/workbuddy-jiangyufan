# 把积分花在刀刃上：套餐、模式、模型倍率、自定义模型四个旋钮调对
## 先说结论：同样的预算，调对四个旋钮能做三倍的事
用了半年 WorkBuddy（自动化任务、写报告、处理本地文件、做开发），把最常见的场景、对应的操作模式和模型选择整理出来，把踩过的坑和实测结论一次说清楚。

工具本身不贵，贵的是用不对工具浪费的时间和积分。真正决定积分消耗的，是四个决策点：选哪个套餐、用哪种工作模式、按场景选什么倍率的模型、要不要外接自定义模型。这四个调对了，同样的预算能多做三倍的事。

## 第一个旋钮：四档套餐怎么选
先看收费体系。体验版免费但只有 500 积分，跑两趟就没了，日常用不够；标准版连续包月 70 元，每月实得 4000 积分；高级版 140 元、9000 分；旗舰版 700 元、5 万分。

实测结论：只要不是每天都在跑大型软件开发任务，标准版应付 8 小时日常办公的高频场景完全够用。写周报、整理文件、生成 PPT、做数据分析，这些消耗没有想象中大。高级版只有在集中做 Vibe Coding、一个月烧掉大量 Token 时才需要；旗舰版除非全天当生产工具跑项目，否则纯浪费。

还有一个容易忽略的细节：年付和连续包月折扣一样，都是 7 折——年付 840 元和连续包月 70 元乘 12 是同一个价。既然价格一样就不该选年付：AI 工具迭代太快，今年好用的明年不一定还是它，月付灵活，用着不爽随时能换，没必要把自己绑死一年。

## 第二个旋钮：三种工作模式，选对了省积分，选错了白烧钱
WorkBuddy 有 Craft、Ask、Plan 三种模式。很多人不分任务复杂度，一律用默认的，结果积分烧得飞快，或者任务做一半发现方向错了又得重来。先把三者的适用边界摆清楚。

Craft（做）：任务定义清晰、不需要决策、纯执行时用。比如文件格式转换、批量生成、跑脚本、写完直接用。日常工作的 80% 场景用 Craft 就够了，发任务前把需求说清楚，执行完直接验收，不用全程盯着。示例场景：每月登录邮箱把各类电子发票下载好、分门别类存放、自动统计同类金额总和——这种就直接用 Craft，不用多想。

Ask（只问不做）：只需要分析和建议、不改任何东西时用。比如代码审查、方案评估、拿不准某个方向对不对先听它的意见。把代码或方案贴给它，它帮着找问题、给建议，但不会改动任何文件。

Plan（先想后做）：有战略判断、方案选型、多路径不确定时用。比如架构设计、产品规划。它会先拆解任务、出方案，给了 A/B 甚至 C 方案供选择，确认后再切到 Craft 开干——这就避免了没想清楚直接开干导致的重复建设和返工。方向错了，后面重写的积分比规划十次都多。

一句话口诀：动脑的事先 Plan 或 Ask，动手的事直接 Craft。目的越明确，提前选对模式响应越快。

## 第三个旋钮：按场景选模型倍率，别让 Auto 替你花钱
模型选择框里每个模型后面都标着一个数字，比如 0.04x、0.95x。这个 x 不是积分数量，是倍率系数：同样一件事，用不同模型跑，消耗的积分差很多倍。倍率越低越便宜，倍率越高通常能力更强但积分烧得更快。系统会根据任务复杂度算预估积分，模型越轻量消耗越少。

腾讯把自家混元的倍率设到 0.04 这个极低值，近乎白送；DeepSeek-V4-Flash 也便宜。把日常 8 个场景按复杂度排序、给出实测的模型选择建议：

L1 公众号文章润色并发布草稿——纯语言任务、无需深度推理，用 Hy3 Preview（0.04x）；L2 新闻爬取整合日报——需执行代码但推理深度不高，用 DeepSeek-V4-Flash 或 Auto；L3 产品 UI 图生成——依赖多模态生图，用 Minmax2.7 或配 ImageGen（0.95x，烧得快但频率不高）；L4 PPT 生成——长上下文加结构化输出，用 Kimi-K2.6 或 DeepSeek-V4-Flash。

L5 前端页面设计、L6 后端代码加数据库——推理要求中等偏上、需架构设计和多文件协同，用 DeepSeek-V4-Pro 或 Kimi-K2.6；L7 需求报告生成蓝图方案——深度推理、核心判断不能出错，上 GLM-5.1；L8 产品规划加测试用例设计——最依赖推理能力和领域经验，同样用 GLM-5.1（0.95x），这种任务不是每天都有，真到用的时候钱别省。

Auto 模式是否省钱要看情况：它按语义复杂度自动分配模型，甚至多模型接力。好处是不用费脑选，缺点是涉及高价分析模型反复接力时，往往比手动指定烧得更多。任务简单又明确时，手动指定低倍率模型更划算。

## 第四个旋钮：有厂商 Token 套餐就配自定义模型
还有一种更省积分的方式——外接自定义模型。这类任务的计费发生在厂商那边，WorkBuddy 只是中转调用，不消耗它自己的积分。

比如本身订阅了 MiniMax 的 TokenPlan Max 套餐，支持 MiniMax 全系模型，就可以通过"配置自定义模型"把外部 TokenPlan 加进来。要注意 WorkBuddy 内置下拉菜单里只有 M2.5 及更早版本，M2.7、M3 是后出的、菜单里选不到，但改配置文件就能加进去。

配置文件在用户目录下的 .workbuddy/models.json，需要加一段模型配置，包含模型 ID、名称、服务商、API Key 和 Base URL，注意 JSON 格式要正确。改完后完全退出 WorkBuddy 再重新打开，重启后左下角的模型选择里就会出现新加的模型。

## 一张表收尾：四个旋钮的建议配置
套餐选标准版连续包月，70 块够用，重度用户再考虑升级，且别选年付——工具迭代快、月付灵活不绑定；模式选择上，纯执行用 Craft、有判断用 Plan、只问用 Ask；模型按场景选，简单任务用低倍率、推理任务再上高倍率；有厂商套餐就配上自定义模型，WorkBuddy 积分能省则省。

说到底，省钱的本质不是少用工具，而是把每个决策点想清楚——让便宜的模型去做简单的事，让贵的能力只在你真正需要判断的时候出场。
