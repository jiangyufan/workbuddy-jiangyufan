# 用 WorkBuddy 搭建自动抓热点系统，选题再也不用瞎刷
很多人做公众号、短视频，卡在第一步：不知道写什么。不是不会写，是选题慢。等你刷完一圈抖音、小红书、知乎，热点已经过期了。

*WorkBuddy科技创新*

我后来干脆不刷了，直接用 WorkBuddy 搭了一套「自动抓热点系统」——每天自动帮我找选题、做整理、甚至连标题方向都给出来。

我们原来是打开抖音，小红书，知乎，公众号等去找对标账号，对标的最热的话题，看一圈后来选定自己的题材。来回切 5 个 App，30 分钟过去了，还没确定写啥。

我们现在借助WORKBUDDY，帮我们自动整理好热点清单，然后我们在里面选一个就好。这就变成了从找内容，变成了挑内容。大大节省了我们找热点的时间。

WORKBUDDY 可以帮我们实现：自动全网爬热点 → 自动筛选爆款潜力 → 自动汇总标题 / 话题 → 定时更新、一键导出。其系统核心逻辑是：数据源。：微博热搜、抖音热榜、知乎热榜、小红书热榜、百度热搜。抓取层。：WorkBuddy 网页抓取 / API 调用，定时自动爬。

筛选层。：按热度、增速、话题体量、时效性自动过滤低质量热点。整理层。：自动生成热点标题、分类（娱乐 / 社会 / 科技 / 生活）。输出层。：自动存表格、推送通知、可直接拿去写公众号文案。

在数据源上面，我们找这些大的网站，按照抓取内容的排名、话题标题、热度值、上涨速度、上榜时间，去抓取内容。

可以每 1 小时 / 每 2 小时自动跑一次，也可以设置自媒体黄金时段比如早 8、午 12、晚 7 定点抓取.。

接着你可以继续加 WorkBuddyAI 处理节点，给指令直接复制：剔除明星无营养八卦、重复话题、过时旧闻。优先选增速快、讨论量飙升、适合公众号发文的话题。自动分类：社会、科技、生活、情感、行业、娱乐。每条热点标注：适合做图文 / 适合做短视频 / 适合追热点标题。

你也可以自己编写，增加指令的内容。接着让Workbuddy 自动整理，然后帮我们存入表格，再输出就好了。
