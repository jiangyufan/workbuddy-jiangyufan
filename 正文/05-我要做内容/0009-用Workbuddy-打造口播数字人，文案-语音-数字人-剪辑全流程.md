# 用Workbuddy 打造口播数字人，文案-语音-数字人-剪辑全流程
很多人想要做自媒体，但是不想自己出镜，感觉有镜头焦虑，甚至也不愿意去用自己的声音录制文案。这个很正常，因为并不是很多人一开始都是自媒体圣体。

而是可以基于自己的一张照片直接生成的数字人，并且支持在 Workbuddy 或者豆包工作里面调用生成。再结合文案、语音剪辑，能实现视频制作全流程。

## 01｜整理流程。
先来大致看一下整个流程，其实就是从文案的创作到语音的克隆，然后调用 API生成数字人视频，最终再调用剪辑 skill 进行视频的剪辑。

整个流程都是基于 AI 工具直接完成，不需要你再去打开第三方软件，手动去做某一个环节的任务。只需要提供主题或者提供一段参考的文案想法，就能实现视频的生成制作。

## 02｜文案制作。
首先第 1 步就是要搞定文案的内容。其实很多人对于文案板块并不是很在意，但是恰好在做短视频时，文案内容是最重要的，。

很多人会考虑数字人的视频效果会不会引起平台的限流等问题。其实这些问题很正常，但是说一句很现实的话：如果你用真人制作的短视频流量一般，那你用数字人制作的视频流量也是一般。

但如果你用真人制作的短视频流量不错，那你用数字人制作的流量也就不会太差。这其中的原因并不是因为粉丝量的问题，而是因为你用真人制作短视频有流量，说明你具备一定的网感，你会抓热点，也会整合内容。

有了这样的能力，其实做数字人视频也是不错的。这里我跑通了整个流程，一共是有两套 skill：一套 skill 是针对小白用户，去做自己的定位选题框架的；另一套是基于经常做自媒体，有自己的产品也有自己的同行竞争的人群。

但是安装的时候，一定要注意同行“分析文案 skill”的分析。

它原来接的是 Gemini 的模型分析，但是 Gemini 模型分析的 API 并不是那么好获取的。我们可以抹除这一块的内容，直接让 AI 工具本身的内置模型给我们分析也是 OK 的。

运行后的效果以小白 skill 的为例：

这个 skill 会在第一步先给你做一个定位梳理，从你的兴趣、资源和变现目标三个方向入手，先将你的定位梳理清楚。

然后再生成对应的脚本。同时，他也非常熟悉互联网短视频的风格，比如黄金 3 秒、节奏模板等等。确保你的短视频文案具备一些反常识/共鸣等能力。

## 03｜语音克隆。
既然舰长说了我们要全流程，那语音这个板块也需要重点去突破。

不然的话，当我们生成好文案之后，还需要自己去录音，将文案读一遍。这种行为虽然不是特别麻烦，但也不算是一个自动化的流程。

所幸现在的模型发展还是不错的，那我们就可以选择最经典的 MiniMax 模型，给我们做一个语音的复刻。

并且我们要把语音克隆的这个流程优化成一个 skill，方便我们后续接入到全流程里面。

请帮我创建一个 skill，这个 skill 就是专门调用 minimax 的 API 给用户生成自己的声音音频出来 1.你需要教用户怎么获取 minimax 的 api_key，需要提醒用户实名认证和最低充值。2.要引导用户提供一段录音文件 3.根据录音文件和minimax 的 api_key去复刻音色，获取到这个音色 iD；同时提供一段 20 字左右试听文案 4.将获取的音色 iD 保留到环境变量里面， 5.上面流程是初始化流程，只缺少 音色 id 的时候才会执行，下面就是常规的生成语音。根据 用户提供文案，或者流程执行过程中提供文案，生成对应音频即可。

因为想要进行语音复刻，我们就需要在 MiniMax 网站上进行个人实名认证，克隆一个音色的花费大概在 9.9 元，生成的语音价格就会比较便宜，差不多一万个字两块。

当然，音色只在你第一次克隆的时候才会收取费用，后面都是不收取的。（提前说明）。

克隆的时候呢，只需要你先自己录制一份 30 秒左右的音频也就是录音，文案可以随便设定，差不多 30 秒读完就可以。然后再自己拟定一个音色 ID，比如我是舰长，我就叫“jianzhang0920”。

因为我这里的环境有一个 MiniMax API，所以如果你们的环境里面没有 MiniMax API，还需要再提供一下这个平台的 API key。

## 04｜数字人视频API。
关于数字人，需要跟大家提前说明：图片生成数字人的价格是 0.06 元/秒。

但是一直都没有找到优质的 API 接口，或者换更通俗的话就是便宜且稳定的接口。

市面上，要不然就是一些开发者做成了小程序、应用，让你到网站上面去用，价格也基本不菲。要么就是一些免费的公用类型的数字人，这种数字人肯定对我们的自媒体视频没有任何帮助。

也是直到今年这个几个月，尤其是上半年开始，这个图片数字人的技术出来了，成本就下来了，不像是之前需要我们自己录自己的形象，在那边读 123、123。平台和制作 skill 的方法。

注册完账号之后，会立马跳出 API 的内容。这个 API 你一定要保存好，最好是放在自己的备忘录里面。

因为后面不管是调用 API，还是登录咱们的这种网站账号，都要基于这个 API 才行。

进入网站后，直接去下载对应的 API 文档。（右上角第二个按钮，显示“API 调用文档”）打开后下载这个调用文档。这个文档是给 AI 看的。

下一步，结合文案和提示词再发给你的 AI 工具，它会自动帮你制作成一个 Skill。这个 Skill 就可以通过 API 调用的方式帮你生成数字人视频。

生成的结构其实就是结合你提供给他的图片加上音频，就能制作数字人视频。

【下载的调用文档需要上传给 Ai 工具】 这是一个平台生成数字人口播视频的接口调用文档。我现在需要基于这个文档，帮我做一个 Skill。这个 Skill 只需要具备一个功能：结合我提供的音频和自己的照片或图片，生成数字人的口播视频。只需要做这么多，语音合成、TTS 等其他东西都不需要管。你这个 skill 呢，只需要做好请求和查询任务等等。

制作好后就可以使用 AI 工具生成数字人了。输入的内容为：注册账号时得到的 API 密钥，。加上你的照片，。再加上录音或者你自己克隆的音频。

三件东西准备好，就能给你生成一份数字人。最开始测试，建议大家先生成一个 20 秒到 30 秒左右的视频，先看一看效果，再去做几分钟的视频。
