# WorkBuddy 资料库：一句话给团队搭一个带后台的工作台
它不只是存文档的网盘。用一句话就能建在线文档、做数据看板、生成可发布的网页、还能直接改 HTML。这篇把新上线的资料库摸透。

## 01｜资料库到底是什么
资料库是 WorkBuddy 原生的内容管理、分享协作与轻发布模块。它不在你电脑里——它是一块云端空间，你用一句话下达指令，WorkBuddy 会自动帮你把内容落进去、管起来、分享出去。

它覆盖在线文档（doc）、网页链接（lnk）、结构化数据表（database）、数据 / 汇报页面（page）、网盘文件（drive）与空间管理（manage）。简单说，资料库里有六种东西：

在线文档可以写、读、改、审阅协作，类似在线版 Word；网页 / 数据页面能生成 HTML 页面，可发布成公开链接；结构化数据表能创建带字段的表，增删改查记录，对标多维表。

网页剪藏是把一个网址收藏进来，还能读取正文内容；网盘文件用来上传下载文件本体，拿下载链接；空间管理则建目录、建团队空间、管协作权限、全库搜索。

这些品类底层是打通的。文档里可以插入数据表，网页可以绑定数据表实现「带后台」，这让资料库不只是个存储工具——它是一个能跑起来的轻量应用平台。

## 02｜直接改 HTML：改网页不用碰代码
这是很多人会好奇的能力：WorkBuddy 可以帮你生成一个网页，之后还能直接在对话里让你改这个网页，不用打开编辑器、不用碰代码。

**它的做法是：**用户要求修改一个已经导入 / 发布在 WorkBuddy Page 平台上的页面，并给出节点链接时，它基于后端事务协议，只上传被修改的产物文件。

你只需要把页面的链接发给 WorkBuddy，然后用大白话说你要改什么。比如「把这个页面的标题改成『2026 Q3 季度复盘』，背景换成深蓝色，底部加一段致谢」，或者「这个页面第三块图换成本地这张，字号整体调大一点」。

WorkBuddy 会拉取你已托管页面的最新版本，定位你要改的地方，只上传发生变化的文件，然后提交一个新版本。改完直接更新，不需要重新生成整页。

关键点是增量更新，不是从头来。编辑走的是「事务」机制——只改你动过的部分，没动的不重传，省时间也省流量。

## 03｜改完怎么发布给别人看
页面默认只有你自己能看。想公开分享，一句话就能发布：只要说「把这个页面发布出来」，WorkBuddy 会执行 publish page 拿到一个公开访问链接，发给别人即可。

不想公开了，同样一句话「取消发布」即可下线，链接立刻失效。

## 04｜带后台的个人工作台：一句话搭一个可增删改的看板
这是资料库最超出预期的能力之一。不只是做个静态网页，而是做一个带数据后台的动态页面——你后续能随时加条目、改数据、换图，页面自动跟着变。

它适用的场景是需要持续管理数据：看板 / dashboard、运营页、名单 / 清单 / 台账、卡片墙、有筛选排序，或后续要增删改内容、换图、加条目。产出形态是 HTML + 配套 database，字段可增删改并与页面双向同步。

它和普通网页的区别在哪？普通静态网页内容写死在 HTML 里，改内容要重新生成页面，适合一次性汇报、总结、展示，换一张图得改代码。带后台的动态网页内容存在数据表里，页面运行时读取，改数据就自动更新，适合需要持续维护的清单、看板、运营页；换图只要在对话里说「把第 N 张换成这张」，后台记录变了，页面就变。

怎么做出来？先描述你的需求，跟 WorkBuddy 说你要做什么。比如「做一个团队任务看板，字段有任务名、负责人、状态、截止日期、优先级」。

它会自动建表 + 生成页面：WorkBuddy 先创建一张结构化数据表（database），定义好字段，然后生成 HTML 页面并绑定这张表。页面上有数据时自动渲染，能筛选、能排序。后续还能持续增删改。
