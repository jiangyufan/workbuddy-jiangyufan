# WorkBuddy使用指南，49个可直接照抄的实用场景
我是可可，广东潮汕人，2个孩子的妈妈，新教育践行者，AI一人公司实战圈共创主理人，专注于研究AI+一人公司提效与变现。

*WorkBuddy 使用指南*

如果你现在用AI，还停留在写邮件、做PPT、整理文档，那真的只用到了很小一部分。

WorkBuddy可以陪你模拟沟通、看冰箱照片安排菜谱、把流水账周报整理成汇报，还能从100条用户差评里找出产品需要改进的地方。

我把这些用法整理成了49个实用场景，每一个都配了可以直接复制的提示词。打开WorkBuddy，粘贴进去，再把方括号里的内容换成自己的资料，就可以开始测试。

其中一部分场景搭配WorkBuddy的Skill使用，我在对应场景下面写了可以搭配的Skill，以及它能继续帮你完成什么。

怎么在WorkBuddy里调用Skill。

点击左侧的“专家·技能·连接器”，搜索并安装需要的Skill。回到对话框，直接告诉WorkBuddy调用哪个Skill、完成什么任务，它就会自动调用。

问答AI也能输入提示词，为什么还要用WorkBuddy。

普通问答AI更像是回答问题，而WorkBuddy还会拆解任务、调用Skill、读取和修改文件，把任务继续做。

这49个场景分为4类，包括13个办公效率场景、12个内容创作场景、12个商务经营场景，以及12个生活与学习场景。大家可以直接找到自己感兴趣的部分，不用从头看到尾。

涉及发送邮件、修改文件、操作外部系统的任务，建议先让WorkBuddy展示计划或预览，确认以后再执行。可以交给AI操作，但关键步骤还是要自己把关。

## 一、办公效率，你的隐形同事（13 个场景）。
除了写邮件，模拟沟通、对比合同、整理竞品资料这些工作，也可以让它先做一轮。01 会议录音 → 结构化纪要 + 待办 + 负责人。

你是一个专业的会议纪要助手。请根据我提供的会议录音转写文本，生成以下内容： 1. 会议摘要（3 句话说清楚会议核心结论） 2. 关键讨论点（按议题分组，每点不超过 2 句话） 3. 行动项清单（格式：任务描述 | 负责人 | 截止时间 | 优先级） 4. 遗留问题（未达成共识、需要后续跟进的事项） 要求：去掉所有寒暄和重复内容，只保留信息密度高的部分。输出为 Markdown 表格。

可以搭配的Skill：lark-vc（飞书视频会议）——直接从飞书历史会议拉取纪要/逐字稿，不用手动录音转写。lark-task（飞书任务）——提取出的行动项一键创建为飞书任务，自动分配给负责人。02 流水账周报 → 有数据有洞察的高管版汇报。

你是一位资深职场沟通教练。请把我下面这段工作流水账，改写成一份面向直属上级的周报。要求： 1. 开头一句话总结本周核心成果 2. 按项目分组，每个项目用"进展-数据-下一步"三段式 3. 把模糊的描述变成具体的数据或可量化结果（如"优化了流程"→"将审批环节从 5 步压缩到 3 步"） 4. 结尾附下周 3 个重点计划 5. 全文不超过 400 字，语气专业但不啰嗦 我的流水账： [粘贴你的本周工作记录]。

可以搭配的Skill：tencent-docs（腾讯文档）——改写完直接生成一份排版好的在线文档，一键转发给领导。

03 合同对比：3 份合同上传，条款差异标红 + 风险提示。

你是一个法务审核助手。我会上传 3 份合同文件，请帮我： 1. 提取每份合同的关键条款（付款条件、违约责任、知识产权归属、保密条款、终止条件） 2. 做成对比表格，标出三份合同的差异 3. 对每处差异给出风险等级（高/中/低）和修改建议 4. 特别注意：有没有对我不利的隐藏条款 输出格式：先表格对比，再风险提示清单。

可以搭配的Skill：tencent-docs（腾讯文档）——对比表格直接生成在线文档，方便法务团队协同批注。

04 竞品速查：输入竞品网址，自动生成对比矩阵。

你是一个市场分析师。请访问以下 3 个竞品官网，帮我生成一份竞品对比报告： 竞品 1：[网址] 竞品 2：[网址] 竞品 3：[网址] 对比维度： - 核心产品/服务 - 定价模式（免费/付费/分层） - 目标客户群体 - 核心卖点 - 明显短板 - 社交媒体活跃度 输出：对比表格 + 一段"我们的差异化机会在哪里"的分析（200 字以内）。

可以搭配的Skill：web-access（联网搜索）——让 AI 真正打开竞品官网抓取最新信息，而不是靠训练数据里的旧内容猜。

05 邮件情绪翻译器：把"我快气死了"翻译成 3 版得体商务邮件。

你是一个高情商商务沟通专家。我把我想表达的真实情绪写在下面，请帮我翻译成 3 个版本的邮件： 版本 1：正式得体版（适合发给上级或客户） 版本 2：温和坚定版（适合跨部门协作） 版本 3：简洁直接版（适合日常沟通） 每个版本要求： - 保留我的核心诉求 - 去掉情绪化表达 - 加上具体的解决建议 - 每版不超过 150 字 我想说的话： [粘贴你的真实想法，比如"合作方第三次延期了，我真的很火大，但又不能撕破脸"]。

可以搭配的Skill：agent-mail（智能体邮箱，已连接）——选好版本后直接发送，不用复制到邮箱客户端手动粘贴。

06 模拟谈判教练：AI 扮演难缠客户/老板，陪练沟通话术。

你是一个沟通培训教练。现在请你扮演以下角色，和我进行模拟对话： 角色设定：[比如"我的直属上级，性格强势，注重数据，不喜欢听借口"] 场景设定：[比如"我要申请将项目截止日期延后一周"] 规则： 1. 你每次只回复一段话，模拟对方的真实反应（包括质疑、施压、沉默） 2. 每轮对话后，在括号里给我一个"沟通评分"（1-10 分）和一句改进建议 3. 对话进行 5 轮后，给出总体评价和 3 条话术优化建议 现在请先以角色身份开场。

07 会议前功课包：输入主题 + 参会者，生成必问问题 + 背景摘要。

你是一个会议准备助手。我明天要参加一个会议，信息如下： 会议主题：[比如"Q3 营销预算评审"] 参会者：[比如"CMO、财务总监、增长负责人"] 会议目的：[比如"争取我的项目预算不被砍"] 请帮我生成： 1. 背景摘要：这个会议通常关注什么、各方可能立场是什么 2. 3 个必问问题（能展示我的专业度或争取主动权的） 3. 3 个可能被问到的问题 + 我的应答要点 4. 1 个"杀手锏"数据或论点（能一锤定音的那种）。

lark-calendar（飞书日历）——直接读取日历里的会议详情、参会者名单，不用手动输入。lark-contact（飞书通讯录）——查参会者的部门、职位、最近动态，功课做得更深。08 Excel 数据讲故事：把表格变成 3 段高管能秒懂的叙事。

你是一个数据叙事专家。我会上传一份 Excel 数据文件，请帮我： 1. 用 3 段话把核心数据讲成一个"故事"（问题→发现→建议） 2. 每段不超过 100 字，用高管能秒懂的语言 3. 标出 3 个"如果被追问，我该怎么回答"的数据点 4. 生成一句适合放在 PPT 标题的金句 要求：不要堆数字，要讲"所以呢"。

可以搭配的Skill：lark-sheets（飞书电子表格）——直接读取飞书表格里的数据，不用下载 Excel 再上传。

09 项目复盘：用 GROW 模型自动复盘本周工作。

你是一个复盘教练。请用 GROW 模型帮我复盘本周工作。我的本周情况： [简述你做了什么、遇到了什么问题、结果如何] 请按以下结构输出： 1. Goal（目标）：本周原本想达成什么 2. Reality（现状）：实际发生了什么，差距在哪 3. Options（选项）：下周有哪些可选的改进方向（至少 3 个） 4. Will（行动）：从选项中选出 1-2 个，拆成具体可执行的下一步 语气：像一个严厉但关心的导师，不要说空话。

可以搭配的Skill：lark-task（飞书任务）——自动拉取本周已完成/未完成的任务列表，复盘基于真实数据而不是回忆。

10 简历 ATS 通关：粘贴 JD + 简历，标出缺失关键词。

你是一个简历优化专家，精通 ATS（简历筛选系统）规则。我会提供：1) 目标岗位的 JD 2) 我的简历 请帮我： 1. 提取 JD 中的关键词清单（硬技能、软技能、工具、证书） 2. 逐项标注我的简历中"已覆盖/缺失/表述模糊" 3. 针对缺失和模糊项，给出具体的修改建议（包括改前/改后对比） 4. 给出简历的整体匹配度评分（百分比） 注意：不要编造经历，只优化表达方式。

可以搭配的Skill：tencent-docs（腾讯文档）——优化后的简历直接生成在线文档，导出 PDF 投递更方便。

11 年终述职 PPT：输入全年项目，生成大纲 + 演讲稿。

你是一个职场述职顾问。我提供了今年参与的主要项目信息，请帮我生成一份年终述职 PPT 的大纲和配套演讲稿。我的项目信息： [粘贴你的项目列表和关键数据] PPT 要求： 1. 封面：1 句话总结全年最大亮点 2. 8-10 页结构：成果概览 → 重点项目（3 个）→ 成长反思 → 明年规划 3. 每页标注：标题 + 核心要点（3 条）+ 配图建议 4. 最后附一份 3 分钟的演讲逐字稿 风格：数据说话，不煽情，但要有记忆点。

可以搭配的Skill：tencent-pptx（PPT 生成）——不只是给大纲，直接生成一份可以打开编辑的 .pptx 文件。

12 知识库搭建：散落文档 → 结构化 wiki。

你是一个知识管理专家。我会提供一批散落的工作文档（会议纪要、流程文档、经验笔记等），请帮我： 1. 梳理出一个合理的知识库目录结构（不超过 3 层） 2. 把每个文档归入对应分类 3. 标出哪些文档有重复内容可以合并 4. 标出哪些领域还缺少文档，建议补充什么 5. 生成一份"知识库使用指南"（200 字内，方便新人上手） 输出：目录结构树 + 文档归档表 + 待补充清单。

可以搭配的Skill：lark-wiki（飞书知识库）——梳理完直接在飞书创建知识空间和文档节点，团队立刻能用。

13 工作汇报可视化：数据 → 甘特图/流程图/思维导图。

你是一个数据可视化助手。请根据我提供的项目数据，生成 3 种可视化输出： 1. 项目甘特图（用 Mermaid 语法，显示各阶段时间线） 2. 工作流程图（用 Mermaid 语法，显示当前工作流中的瓶颈） 3. 思维导图大纲（用 Markdown 层级格式，展示项目全貌） 我的项目数据： [粘贴项目阶段、时间节点、负责人等信息] 要求：图表要能直接复制到文档里使用，标注清楚每个节点的状态。

可以搭配的Skill：lark-whiteboard（飞书画板）——生成的图表直接放到飞书画板上，团队可以在线协同标注。

## 二、 内容创作，你的内容流水线（12 个场景）。
内容创作不只有写文章。前面的选题规划、后面的多平台改写、内容日历和知识卡片，也都可以放进同一套流程里。

14 小红书爆款选题工厂：输入赛道，生成 30 个选题 + 标题模板。

你是一个小红书运营专家。我的账号赛道是：[比如"职场妈妈的时间管理"] 请帮我生成： 1. 30 个爆款选题（按"痛点型/反差型/干货型/故事型"分类） 2. 每个选题配一个标题模板（带 emoji，15 字以内，有钩子） 3. 每个选题标注：目标关键词、推荐封面风格、预估互动类型（收藏/评论/转发） 要求：选题要基于真实搜索需求，不要标题党。参考小红书当前流量逻辑，优先"收藏价值高"的内容。

可以搭配的Skill：web-access（联网搜索）——先搜一遍小红书当前热搜词和爆款笔记，选题基于真实流量数据而不是凭空想。

15 一稿多发：公众号长文 → 抖音脚本 + 小红书图文 + 视频号文案。

你是一个跨平台内容改编专家。我写了一篇公众号文章，请帮我改编成 3 个平台的内容： 原文： [粘贴你的文章] 输出要求： 1. 抖音短视频脚本（30-60 秒，开头 3 秒必须有钩子，中间 1 个核心观点，结尾引导互动） 2. 小红书图文（5 张图的文案 + 封面标题，每张图 50 字以内） 3. 视频号文案（200 字以内，适合转发朋友圈的调性） 注意：不是缩写，是根据各平台的用户习惯重新组织内容。

16 播客脚本生成：输入主题，生成完整对谈脚本。

你是一个播客制作人。我要录一期关于 [主题] 的播客，请帮我生成一份对谈脚本。要求： 1. 双人对谈格式（主持人 + 嘉宾） 2. 总时长约 30 分钟，分 4 个话题板块 3. 每个板块标注：预计时长、核心话题、主持人的 3-4 个引导问题 4. 在话题切换处加入过渡话术（自然衔接，不生硬） 5. 开头 1 分钟钩子 + 结尾 1 分钟总结 风格：轻松但有信息密度，像两个朋友在聊天。

17 直播话术设计：输入产品信息，生成 3 小时直播话术。

18 个人品牌定位：输入技能 + 经历，找到差异化定位。
