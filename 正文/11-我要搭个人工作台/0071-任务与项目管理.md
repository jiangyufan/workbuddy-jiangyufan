# 任务与项目管理
**是什么：覆盖待办创建、子任务拆解、任务依赖、标签分类、时间追踪、重复任务检测等一整套工作流管理能力。**

**怎么操作：**

**创建待办：**点击"新建待办"，或在 AI 对话框输入"帮我创建一个任务"；填写标题、描述、所属项目，设定截止日期与优先级（高/中/低），系统自动排入日历并生成提醒。文档版流程为：新建待办 → 输入标题描述 → 设置截止与优先级 → 添加标签分类 → 保存查看列表。

**子任务拆解：**输入"帮我拆解这个任务"，AI 自动生成子任务列表与时间安排；每个子任务有独立截止日期和状态。文档流程为：添加子任务 → 设置详情 → 分配 → 追踪进度 → 完成状态联动。

**任务依赖：**在任务详情点击"添加依赖"选择前置任务；前置未完成时后续任务自动锁定为"等待中"，前置完成后自动解锁并提醒。

**标签系统：**支持自定义颜色、父子层级标签（如"开发→前端→React"）、点击标签快速筛选。

**时间追踪：**在任务详情点击"开始计时"即可追踪，可暂停/结束，时间自动关联任务与项目。

**适合场景：项目型工作从想法到结构化任务的转化、需要精细进度追踪的多环节任务、跨项目分类检索。**
