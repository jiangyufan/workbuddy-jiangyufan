# 学术科研怎么用豆包工作？从文献到绘图，7个实战场景，提示词复制即用
![](https://mmbiz.qpic.cn/mmbiz_gif/kegUvHaA0d7wXO1yJ7zrcrokHf58p3fFR4lmy5o6RqJk3NWbzXk35TC1CJ0ePvRVppTZZDW4GFNibjROiasmwjb3XPIicIB5l9J6LDFNOefxyg/640?wx_fmt=gif&amp;from=appmsg#imgIndex=0)

@萌猪过河 是一名理工科研究生。豆包工作发布后，他常开玩笑说，自己的科研能力得到了“史诗级加强”。

“跟以前那种我问一句、它答一句的 AI 不一样，我电脑上的 Origin、浏览器、文件夹它都能自己打开操作，只用把需求说清楚，剩下的活不用自己动手干。再加上它能装 Skill，相当于可以按自己的研究方向给它配置专业工具，极大提高了科研效率。”。

从科研绘图、仿真建模、文献检索、论文精读、写作润色、投稿前自审，到每周固定的组会汇报，这些繁琐的工作，如今都能在豆包工作里完成。7 个实战场景，提示词直接复制就能用。

豆包工作仅作为科研辅助工具，不能替代研究者的独立思考与学术判断；请严格遵循学术规范，并对研究过程与成果负责。

## 01Origin 自动绘图✦。

![](https://mmbiz.qpic.cn/mmbiz_png/kegUvHaA0d57RDZDczbD8Unm52tNC6Maslj1yuYK7BsCJSkTQBxhcwhJeJAbFVypnicob6kSSibuGycLBdr5AlI6rgbX447bsQicuLZYPVaoLY/640?wx_fmt=png&amp;from=appmsg#imgIndex=2)

科研绘图环节，@萌猪过河 选择使用开源 Skilleditaplot，让豆包工作直接操控本地 Origin 作图，生成可以手动编辑的 Origin 工程文件。

本节所用 Skill 为三方开源项目，其功能、维护状态与兼容性由原作者负责。给豆包工作发送以下提示词，它就能自动完成 Skill 安装：提示词。帮我去 GitHub 上安装 hang-jin/editaplot 这个 skill。安装完成后，在“技能”中选中刚刚装好的 Editaplot Skill。

按照我上传的图片和数据，在这个技能中选择最适合的绘图模板，然后打开 Origin 进行绘图。全程只打开一个 Origin 窗口，不允许打开多个程序，保证 Origin 始终处于前台运行，让我能够看到完整的绘图过程。

随后等待豆包工作完成调用即可。首次读取 Skill 耗时较长，完成初始化后出图速度会明显提升。

## 02仿真建模，接入科研软件✦。
除了 Origin，@萌猪过河 还用同样的思路，让豆包工作接入了三款仿真软件——COMSOL、MATLAB、ANSYS。

1. COMSOL 多物理场仿真

通过自制的 SkillComsol-Automatic，@萌猪过河 直接用自然语言让豆包工作跑仿真。

使用 comsol-automatic-wwj。一定不要使用屏幕识别，只使用 MCP。先检查连接，然后运行 heat_sink_3d 三维散热器案例，报告能量平衡与网格检查。最后告诉我本次模型名称，让我在 COMSOL 中点击“文件 → COMSOL Multiphysics Server → 从服务器导入 App”，查看模型树、温度云图和升温曲线。

1. MATLAB / Simulink 自动建模

MATLAB Automatic 则能让豆包工作自动完成数值建模和 Simulink 仿真，发送以下提示词，完成安装与连接器配置。

帮我安装 GitHub 上的 fatdog-pro/MATLAB-Automatic-wwj skill，并按仓库里的豆包 MCP 接入指南配置 MATLAB 连接器。

1. ANSYS Fluent/Mechanical 仿真

ANSYS automatic目前支持 Fluent 和 Mechanical，第一次使用建议让豆包从 Release 完整包开始安装。

去 GitHub 仓库 fatdog-pro/ANSYS-automatic-wwj 的 Releases，下载最新已发布版本 Assets 中的 ansys-automatic-wwj.zip 完整包，不要下载 Source code。解压后保留 scripts、references 和 assets，读取 SKILL.md，检查本机 Ansys 与执行环境，再按已验证路线运行。

## 03文献调研✦。

## 04论文精读✦。
使用豆包工作提前内置好的 Skilldoubao-paper-close-reading，就能迅速还原论文的完整逻辑链，帮你标出薄弱环节，区分作者结论、作者推测与模型自身推断，并列出复现该方法时的注意事项。

帮我精读这篇论文。我关心三件事：一是方法的核心思想是什么、为什么这么设计；二是实验结果是不是真的支持它的结论、有没有没跑赢基线的地方；三是如果我要复现，坑在哪。最后整理成组会上能直接讲的笔记。

如果需要对比多篇论文，可以直接追加一句：围绕（某某问题），帮我对比这几篇的处理方式有什么差别。

## 05论文写作✦。
进入写作环节，豆包工作内置的doubao-academic-polish技能提供三种不同模式：写正文：基于想法或材料起草内容；

我会在下面提供实验数据和研究思路。请据此起草论文的「引言」和「方法」两部分，中文，目标为国内核心期刊。要求： 1. 引言按「研究背景与意义 → 国内外研究现状 → 现有方法的不足 → 本文工作与创新点」展开； 2. 方法部分写清研究对象、实验或仿真设置、关键参数与评价指标； 3. 只能使用我提供的数据和结论；信息不足处用【待补充：xx】标出，禁止编造数值、文献和引用； 4. 术语全文统一，使用学术书面语； 5. 先输出正文，文末另列「建议补充的图表与参考文献方向」。以下是我的材料：

搭提纲：只给结构方案，不改正文一个字；

请以审稿人视角检查这篇稿子的结构，只给调整方案，不要改正文： 1. 逐节概述现有内容，标出逻辑断层、内容重复和详略失衡的位置； 2. 给出建议的章节顺序，并说明每节应承担的论证功能； 3. 指出需要合并、删减或前置的内容及理由； 4. 最后输出一份按优先级排序的修改清单。稿子如下：

## 06投稿前审查✦。
投稿之前，可以使用豆包工作内置技能 doubao-academic-evaluator，让豆包以审稿人的视角挑一遍问题。该技能负责挑错、下结论、指方向，但不会代笔重写或代画图表。

我准备把这篇稿子投（某某期刊），你以审稿人的视角帮我审一遍，哪些是会被拒的硬伤，哪些只是小毛病，按严重程度排个序，每条告诉我在原文哪个位置、建议怎么改。先别动手改，我要自己来。

除了审查已成稿的论文，它也能评估一个尚未动手的研究想法值不值得投入数月时间，对刚开题的同学尤其有用。

我有一个研究想法，准备投入几个月做下去，你从审稿人和导师的角度帮我判断值不值得做：一是新颖性，它和已有工作的差别在哪、是否只是换了个应用场景；二是可行性，现有条件、数据和方法能不能支撑；三是潜在硬伤，哪些环节可能导致结论不成立。没有实验数据就不要给具体提升数字，只判断方向和机制是否讲得通，最后按「可以做 / 谨慎做 / 不建议做」给出结论和理由。我的想法是：

## 07组会汇报✦。
每周都要开的组会汇报，同样可以交给豆包工作。先让它批量处理这周的实验原始数据，无需安装任何 Skill：
