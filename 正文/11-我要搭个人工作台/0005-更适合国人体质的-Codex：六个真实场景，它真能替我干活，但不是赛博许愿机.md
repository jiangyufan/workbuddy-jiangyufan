# 更适合国人体质的 Codex：六个真实场景，它真能替我干活，但不是赛博许愿机
## 它和聊天机器人不是一回事
如果说过去的 AI 聊天机器人更像坐在聊天框里的顾问——负责回答问题、总结资料、改改文案，那 Agent 做的事往前一步：在回答之外，它还会按你的目标拆任务、调工具、自己往前推进。

而以 Codex 为首的本地 Agent，把这套能力扩到了你的电脑上。它不只看你发给它的文字，还能在你授权的范围里读文件、改文件、跑脚本、生成网页，甚至调用本地应用和外部服务。

但它在国内日常场景里也确实有点水土不服。网络环境、账号、权限、本地路径，这些细节只要卡住一次，普通用户的耐心基本就被消耗光了。

这也是我深度体验完腾讯 WorkBuddy 之后，愿意把它叫作「更适合中国宝宝体质的 Codex」的原因。下面六个场景都是我真实跑过的。

## 先认识界面：三个区，加一个工作空间
WorkBuddy 脱胎于同为腾讯旗下、面向程序员的 CodeBuddy。底层保留了 Agent 拆解任务、调用工具的硬核能力，但替普通人卸下了所有需要折腾环境的技术包袱。

下载很简单，打开 codebuddy.cn/work 装好就能直接用。界面和普通 AI 聊天机器人很像，功能区域主要分三块：左侧栏负责新建任务、查看历史对话和任务记录、管理工作空间；中间对话区描述需求、查看 Agent 的拆解过程和执行结果；底部是输入与操作区，输入任务、切换模型、调用技能、连接应用、附文件或选择工作文件夹都在这里。

模型可以切，Hy3、GLM、DeepSeek 都在列表里，也可以配置自定义模型。最近腾讯发布新的混元 Hy3 模型，WorkBuddy 内也有限时免费使用，赶上这段免费期的人，多半都把专家团可劲儿试了一遍。

这里有个容易被忽略但很关键的动作：先划一个工作空间（也就是指定一个文件夹）。它决定了 Agent 能看哪里、能在哪里动手，也决定了你后面敢不敢让它跑带「删除」的任务。

## 场景一：在微信里，让电脑上的它替你找文件、发邮件
这是我觉得最不像 AI 产品的一次体验。电脑开着，人不在旁边，微信里一句话就能使唤它。

我让它找电脑里的入职文件并打包发邮箱：「帮我找下电脑里的入职文件，打包压缩发给我」。它先自己找了一遍——外置硬盘里有个「20260701 打印入职文件」文件夹，翻出 6 个文件共 10.5 MB，直接打包成 10.2 MB 的压缩包。

然后它把发件人、收件人、主题、附件四项列出来，末尾一句「确认吗？」。确认后它回：「发出去了，去 foxmail 查收吧，6 份文件都在 zip 里。」

这事以前需要远程桌面、网盘同步，或者拜托同事帮你开电脑找文件。现在只要电脑在线，微信里一句话就搞定。它甚至顺手提了一句 agently-cli 有新版本，问要不要一起更新。

## 场景二：本地文件大扫除，它懂得先问你一句
很多创作者和摄影爱好者的电脑里，都有一片不愿轻易打开的素材废墟。我的就是：横跨一年半，命名规则前后不一致，有的夹日期、有的夹产品名、有的还带着奇怪的分隔符。找一张图基本靠记忆力和运气。

这次我先在 WorkBuddy 里划出一个隔离隐私的工作空间，然后给它一串复杂条件：把 with Liz 的单独拎出来放一个文件夹，产品的放另一个；同一产品有多个文件夹的合并成一个；归档的 RAW 只保留与成片同名的，其他删除；分隔符「_」全部去掉；文件夹命名统一为 yyyymmdd。

注意这条指令里带了「删除」。它没有像个莽夫一样直接 rm -rf，而是主动触发了二次确认机制，并在对话框顶部透明地展示了预估账单——预计消耗 5.37~53.6 积分。确认无误后，喝口水的功夫，一团乱麻的目录就被收进了几个清晰的分类里。

整套流程跑下来实际消耗在 95 积分左右。对比每天签到能领的 100-150 积分免费额度，应付这类轻度本地整理基本够用。这也是我一直强调「先让它报价」的原因：你花多少钱，是可以提前知道的。

## 场景三：从一堆材料到一张清单，再变成一份初稿
对内容工作者来说，把海量资讯理出头绪往往是一天里最耗时的环节。为了把这活儿外包出去，我让它在指定的本地文件夹里，从零搭一个完全自动化的「科技早报初筛工作流」。

我给它的指令里塞了十四项限制，核心是三件事：只准用当前文件夹、不准复用本机其他目录里任何现成的 workflow 或历史稿、只做选题初筛不写最终稿。它没有甩几个标题敷衍了事，而是真在本地跑通了读取信源、基础去重、剔除旧闻的脚本，然后在腾讯文档里生成了一份分类清晰的初筛清单。

原始条目 60 条，筛出候选 18 条，按「必看/可选/不建议写」三类整理，每条 50 字内说明为什么值得写，并标出来源、链接、发布时间和可能风险。

顺着这份清单让它继续写初稿，它分出了「大公司」「观点」「新产品」「新消费」「好看的」几个栏目，还在文末严谨地附了一份事实核查清单，把特斯拉专访、苹果 AI 调查这些信息列为待核项。零散素材就这么变成了一份可用度很高的提纲。

## 同一个逻辑，处理会议转写和产品评测
面对满是口语重复、来回插话的会议转写文本，它能精准剥离无用信息，提炼出包含「信息缺口」和「下一步执行建议」的选题卡。我给的格式要求是：标题、核心概念、原始讨论摘要、钩子、信息缺口、下一步执行建议，并保留主编的核心判断、去掉口语重复和转写错误。

它从一段早会转写里提炼出 7 张选题卡，把「苹果急着切到 M7」的两条原因讲得很清楚：一是增强消费级产品的端侧算力，二是让产品能力延伸到数据中心业务。同时如实标出信息缺口——M7 具体规格与制程尚未确认，苹果数据中心业务的公开信息极少。

处理长篇产品评测资料时，它会先识别产品定位，再把官方卖点和真实体验问题分开，标出需要后续实测验证的点，最后给出适合展开的叙事方向。红魔游戏平板那一份，它给出了核心判断、3 个体验点、14 项待验证参数、9 条可能的 Debuff，还有 7 个生活化的比喻——比如「海景房平板」「口袋里的 PS5」「会呼吸的平板」。

这类任务的价值不在「替你写完」，而在把人从面对空白文档发呆的焦虑里解救出来。你拿到的是判断框架，不是一堆参数。

## 不用写代码，也能把自己的经验做成工具
前面这些任务，本质还是让它替你执行一串操作。更有意思的地方是，它能把一套重复出现的判断规则，做成一个可复用的小工具。

我第一个试的是「高考作文批改助手」。作为英专生，我身边有不少同学后来做了英语老师，批改作文是他们躲不开的一环：要看内容、结构、语言、语法，还要给学生写能看懂的提分建议。

于是我把新高考 I 卷的作文评分标准图片喂给它，用大白话讲清楚要求：先理解评分逻辑，再做一个带 HTML 界面的批改助手，能批量读取作文，输出分数、优缺点和提分策略。它这次把任务拆成四块——读取评分标准提取档次规则、设计批量读取逻辑、为每篇生成分数与建议、用 HTML 做出卡片式页面方便老师复核打印。

页面排版规整，点开细看，分数、优缺点、提分策略都有，每张卡片下面还留了一个「老师确认」按钮。老师要做的，就从「从头批到尾」变成「复核、调整、打印」。

顺着这个思路，我又做了一个「名人访谈亮点挖掘」工具，要求拒绝流水账摘要，只提炼金句、新信息、值得展开的选题和有意思的观点。把扎克伯格约 60 分钟的播客转写丢进去，它准确抓到了他承认 Llama 4 开发未达预期、并重组超级智能实验室的具体信息；处理 Sam Altman 的万字访谈时，抓到了他谈 Codex「YOLO 模式」、合成数据、Agent 访问电脑权限这些细节。

更实用的是卡片底部的「后续补充信息」——它根据上下文给出可供交叉验证和延伸探讨的切入点。老师的经验变成了批改卡片，编辑的经验变成了访谈亮点卡片。

## 一个附加能力：它还能帮你下单
WorkBuddy 还有一个微信生态里的小彩蛋。接入微信支付刚发布的「AI 专属卡」后，我试着把团队下午茶交给它：下午 3 点送达，10 人份，人均 30 元。

它按预算、距离和评分找出蛋挞、披萨等一串可对比的选项。确认后，它会把订单推进到支付前一步——最后付款依然要人来决定。这条边界划得很清楚，也是我愿意用它碰钱的原因。

不过这个功能目前的使用场景还比较单一，我更愿意把它看作附加能力。对大多数打工人来说，它最稳定的价值还是本地执行和信息整理。

## 它不是赛博许愿机
这些天用下来，最大的感觉是：电脑里像是多了一位刚入职、勤快又不知疲倦的实习生，而我是它的 Mentor。只要把工作空间划好、把目标讲清楚，它就能自己拆任务、找路径、跑流程，中间过程也看得一清二楚。

但它也没强到「赛博许愿机」的程度。你不能把一句「帮我搞定」扔过去，然后等着它自动交出一个完美结果。文件在哪里、目标是什么、哪些目录不能碰、最后要长成什么样，依然需要你先讲清楚；任务推进到关键节点时，也需要你确认方向、修正偏差、检查结果。

话说回来，这已经足够让人上头了。你明知道它还会犯错、最后还得自己兜底，但看着它真的开始读文件、改代码、生成页面、整理材料，还是会忍不住冒出一个危险的念头——这活儿我是不是也能接了？

当然，真要做复杂项目，无论是模型能力还是用户体验，Codex 和 Claude Code 依然是更好的选择。但如果只是执行日常的简单任务，WorkBuddy 已经能给大多数人一个可用且低成本的选择。

## 它叫 Buddy，不叫神灯
这个关系恰恰呼应了它的名字。它不是阿拉丁神灯，也不想替代你、接管你的全部工作，而是在你的电脑里，和你一起把问题拆开、确认、推进，做一个愿意打下手、能陪你一起干活的搭子。

如果你准备开始，我给三个建议：第一，永远先划工作空间，这是权限的边界；第二，把「不许碰哪些目录」写进指令，比事后补救便宜；第三，看到它报价就顺手确认一下，你花多少积分心里要有数。

它负责把乱糟糟的材料整理到一个可以开始判断的状态，最后的判断还是人来做。我觉得这才是本地 Agent 该有的样子。
