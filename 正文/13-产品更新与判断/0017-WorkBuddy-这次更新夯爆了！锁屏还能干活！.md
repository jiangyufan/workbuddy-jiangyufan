# WorkBuddy 这次更新夯爆了！锁屏还能干活！

*关了屏幕它还在*

嗨，大家好，我是 iscuker。AI工具在本地电脑跑任务有个前提——电脑不能睡。一睡眠，相当于工位关灯走人，活儿就停在那儿了。最近workbuddy的更新，有一个超有用的功能——「允许锁屏运行」，新增三种模式。而workbuddy的更新一共 8 条改动。

我挑三条跟主题相关的说，剩下的顺带交代。

## 01 锁屏也能干活了。

*订阅和用量｜记忆与进化*

设置里现在能找到「允许锁屏运行」，三个档位随你挑：

![允许锁屏运行｜选择锁屏后的运行方式，保障远程控制与后台 Agent 任务持续执行](https://mmbiz.qpic.cn/sz_mmbiz_png/hHdicyWfdctn7klPT52hic9NNVn6jAnvibGSZgibG7toGE89Jco2k7SOEQ9ibdCAUI1j94wEhicIffsBMDyBicFKBddV7Ud6LbwTpYXBRhIPHJHyow/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=2)

*允许锁屏运行｜选择锁屏后的运行方式，保障远程控制与后台 Agent 任务持续执行*

关闭 —— 跟以前一样，合盖就停。熄屏后继续运行 —— 屏幕灭了，活儿照样跑。保持屏幕常亮 —— 适合需要盯着界面的场景。我以前的土办法是什么。把电脑的休眠时间改成"永不"，然后在旁边贴张便签提醒自己用完记得改回来。但是，有时候确实不是很方便。

准确来说，那不叫让电脑干活，那叫给电脑上了个夜班，还得我自己排班表。

现在我会这么分：跑那种一两个小时的整理活，选第二档，屏幕灭了我就去忙别的；需要盯着界面看过程的，选第三档；处理敏感文件的时候，老老实实选第一档。

三档一选，这事就过去了。

## 02 「自动化」改名了。

![专家·技能·连接器](https://mmbiz.qpic.cn/mmbiz_png/hHdicyWfdctl6ibicC2oljKjp39DcBZVR3U3aRER6pGXJ0kicuiachN4yib031cAnSY92glyhGYFgOKG8SfPrMcmDCbESVsicNiaNyPt3oKVrWnOpYM/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=3)

*专家·技能·连接器*

第二条改动看着更小：客户端把「自动化」统一改成了「定时任务」。其实，产品里改名这事，从来不是改个字那么简单。它意味着承认：之前那个词，用户得在脑子里翻译一遍。

「自动化」是个技术词，说的是机制；「定时任务」是个动作词，说的是你要干嘛。你不会说"我去设个自动化"，你会说"我设个定时任务"。

我以前带项目的时候吃过这个亏。给流程起名，起的是"内部协同机制"，结果半年没人用；后来改成"每周五交表"，当天就跑起来了。

实话说，那不叫改名，那叫把功能从技术语言翻译回人话。名字对了，功能才找得到。

## 03 档位会自己记住。

![档位会自己记住了｜上下文窗口档位分别记忆——新建会话、重启之后，沿用你上次的选择。](https://mmbiz.qpic.cn/mmbiz_png/hHdicyWfdctl50D6zENAkicYDLqzN9BaDhu44ZSEjLpGUnfbAWMb7Fs31Jr0HlI4fVbJ9pfLGKciby5usPrun2uqj6qUcQuK1I5We8Ipv9dPZg/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=4)

*档位会自己记住了｜上下文窗口档位分别记忆——新建会话、重启之后，沿用你上次的选择。*

第三条也小，但每天省事：模型的上下文窗口档位，现在可以分别记忆了，新建会话或者重启之后，沿用你上次的选择。

以前每次开新会话都得重新拨一遍那几个档。一次五秒，一天十次。准确来说，那不叫设置，那叫给同一个答案交了十遍作业。

## 04 顺带说说修掉的那些。

![](https://mmbiz.qpic.cn/mmbiz_png/hHdicyWfdctkCUWsSE3FXKkJV35BeNj8p1Djtknziah2fWC4Tq9HX7FibJ9G4GsRgQHO5fzBK6Zb8uSJf9EwzMpEJI2eCWM3ichVEFGDD6ACj38/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1#imgIndex=5)

另外的5 条是修 bug，都挺实在：登录过期了界面还显示已登录、发消息却报服务异常。本地任务第一次提问偶尔卡在「正在连接 MCP 服务…」。超长会话点「查看更多」加载不出更早提问。没选工作空间时侧栏会闪出日期文件夹。移动端产物里混进过程文件。

这5条修复bug，个人觉得都是让活儿别停在半路。最后的最后。八条里真新增的就三条，剩下五条在补窟窿。我挺喜欢这次的更新。它没造什么新词，也没喊什么新范式，就是把"人得守着电脑"这件事，一点一点往外拆。守着屏幕、守着术语、守着同一个设置，一样一样都不用人守了。

家里五只猫，没有一只是靠盯着我干活长大的。它们只在我坐下来之后才过来，趴在我腿上，等我把该做的事做。所谓好用的工具，不是让你更能干，是让你敢离开。我是 iscuker，8 年地产人、5 只猫的铲屎官，也在学着不那么用力地生活。顺势顺祈，岁月茸茸。
