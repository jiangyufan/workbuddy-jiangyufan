# 豆包工作更新！支持多Agent并行工作，Mac电脑也能操作
大家好，为大家介绍豆包工作的两项全新能力：多 Agent 并行和Mac 系统下的操作电脑。

多 Agent 并行功能，能让豆包工作召唤不同的子 Agent，在一个任务下分别执行不同的模块，既成倍节省时间，又能同时交付多个产物。

Mac 系统的操作电脑功能，可让豆包工作实现本地 GUI 操作，在没有 MCP、API、插件和 CLI 的情况下也能看懂界面并完成相应操作。

下面一起来看看两个全新的功能，更新豆包工作电脑版即可体验。

![几个子Agent帮你分头交作业](https://mmbiz.qpic.cn/mmbiz_png/kegUvHaA0d4EvjHkcFWbickUJGdVAtFJYvkw7Kzzsxeicq7g6uMPy1UNDWRMWmr1PVgOcm7sFnxQjtUWXWgnKbKEvD7jt9xk4qLbPvccSsXRI/640?wx_fmt=png&amp;from=appmsg#imgIndex=0)

*几个子Agent帮你分头交作业*

对于批量处理、分模块生成、多维度调研、多渠道检索等类型的任务，单 Agent 的效率和效果往往不尽人意。

而在多 Agent 并行的机制中，负责组织的主 Agent 会先行拆解，将比较垂直、专业的任务交由不同的子 Agent 分别处理，既快又好。

现在，在本地电脑环境下，你只需要将需求描述清楚，豆包工作会自动启动"多 Agent 并行"模式。你也可以在提示词里添加"使用多 Agent 并行处理任务"来手动触发。

## 举个例子：批量简历筛选。
在复杂长程任务的执行过程中，组织者 Agent 会自动分析，将拆解开的需求派发给多个子 Agent 同时处理。

![A1金钱工程师-直播简历评分与汇总｜文件夹中共有70份PDF简历。我先快速查看预览图和简历格式，确认可读性，再评估任务规模。](https://mmbiz.qpic.cn/sz_mmbiz_gif/kegUvHaA0d7jwCCkFpt64lHLNVo1sKznKhxFAGcVaOWHEyCwjxGE8SLEaeB3semfVSmViabC7vJe8ZCQafKAZib2ciaQRgsicMN6o8BPkOTcJFU/640?wx_fmt=gif&amp;from=appmsg#imgIndex=2)

*A1金钱工程师-直播简历评分与汇总｜文件夹中共有70份PDF简历。我先快速查看预览图和简历格式，确认可读性，再评估任务规模。*

比如在上述 70 份简历的筛选任务中，四个子 Agent 各自负责 17-18 份简历，显著缩短任务完成时间。等到所有子 Agent 完成各自的简历分析后，组织者 Agent 会输出最终回复。

## 还能同时交付不同产物。
如果你需要交付不同类型产物，多个子 Agent 还可以承担差异化分工。

比如在下方的任务中，多个子 Agent 可以分别交付Word、PPT、HTML三种形式的产物，在一个复杂任务里实现差异化分工，各自交付不同的"作业"。

*操作电脑功能｜支持 Mac 系统了*

豆包工作在 Windows 系统中基于 GUI"操作本地电脑"的能力已经发布一段时间了。现在，Mac 用户同样可以让豆包工作通过 GUI 操作电脑了。

在 MCP、API、CLI 之外，GUI 提供了一种更加通用、覆盖更多长尾场景的能力。

新建工作任务。在技能栏选择“操作电脑”。豆包工作自动查看电脑屏幕并点击操作相关的应用。

![今天有什么工作要处理？｜处理日常工作](https://mmbiz.qpic.cn/sz_mmbiz_gif/kegUvHaA0d6BT6BcCyzuicVFDUndSc6OTXbk3JibsoialCqibmnYCkX5hdPOcdJNNIzKVFPp1H41qKxwv4r3DfWnQ20g3c1uIiaJk2qb8cUlUkns/640?wx_fmt=gif&amp;from=appmsg#imgIndex=5)

使用该功能后，被操作的应用会以小窗悬浮在屏幕右下角，实时显示应用画面和蓝色虚拟光标。

![](https://mmbiz.qpic.cn/mmbiz_gif/kegUvHaA0d4UiappxcOFxDCS9ozXAicgowematRLOKoLBPeNab914icKLEW46dIsmvqEp2sEwibrFiazTvX8uW09T9gnh4G8YTVsZeNMFMgy3iaHQ/640?wx_fmt=gif&amp;from=appmsg#imgIndex=6)
