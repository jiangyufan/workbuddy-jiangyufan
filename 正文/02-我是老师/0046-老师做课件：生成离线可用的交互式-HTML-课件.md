# 老师做课件：生成离线可用的交互式 HTML 课件
**适用：把抽象过程做成能拖、能点、能即时反馈的网页课件，比 PPT 更能抓住注意力。**

**可复制提示词（课堂测验类，方括号换成自己的课题）：**

角色设定：你是一位擅长制作交互式网页的前端开发专家，同时熟悉中小学教学场景。你能把教学内容转化为高颜值、强交互的HTML网页课件。任务：请为以下课题生成一个交互式课堂测验网页。课题信息：- 学科：[填写学科] - 年级：[填写年级] - 课题：[填写课题名称] - 题目数量：[X]道。题目要求：1. 题型：[选择题/判断题/填空题/混合] 2. 难度：[基础/中等/较难/梯度分布] 3. 覆盖范围：[列出需要考察的知识点]。功能要求：1. 每道题有A、B、C、D四个选项（选择题）或填写框（填空题）2. 点击选项后高亮显示选中状态 3. 点击"提交答案"按钮后：显示正确答案（绿色高亮）、显示用户选择（错误的红色标记）、显示详细解析 4. 底部显示总分统计：答对X题/共X题，正确率XX% 5. 全部答完后显示"再做一次"按钮。样式要求：1. 整体风格：简洁清新，适合教学场景 2. 配色：主色调[蓝色/绿色/紫色/橙色]，背景浅色 3. 字体：中文用微软雅黑，英文用系统默认 4. 间距：题目之间适当留白 5. 响应式：支持手机和电脑查看。输出要求：1. 生成一个完整的HTML文件，所有代码（HTML+CSS+JavaScript）都在一个文件内 2. 不依赖外部资源（图片、字体、CDN）3. 代码有注释 4. 直接保存为 [课题名称]_测验.html。

**操作步骤：**① 打开 WorkBuddy，选择 Craft 模式（可直接生成文件）；② 输入指令；③ 等待 AI 自动编写 HTML，包含题目、选项、提交按钮、答案判断、分数统计；④ 生成后在浏览器预览，不满意直接告诉 AI 修改；⑤ 确认后导出 HTML 文件，发到班级群或嵌入学习平台。

同一篇还给出知识配对类、互动演示类两套提示词，复制后替换方括号内容即可。使用建议：先做一个知识点的测验课件在一个班试用；AI 生成的题目发学生前自己先做一遍；保存好源文件，下次换题只改内容。

**延伸：**还可用 WorkBuddy 资料库能力生成"教师办公工作台"单文件网页（课程表、调课记录、公开课/培训、班级进度、每周复盘、教学日历等模块），提示词可直接复制使用。
