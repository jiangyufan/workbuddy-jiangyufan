# 交互式 HTML 课件（课前配对 / 课中演示 / 课后测验）
**适用场景：**把抽象概念做成能拖、能点、能即时反馈的网页课件，比 PPT 更能抓住注意力；课前预习用知识配对、课堂讲授用互动演示、课后复习用测验闯关。

可直接复制原文（课堂测验类）：

角色设定：你是一位擅长制作交互式网页的前端开发专家，同时熟悉中小学教学场景。你能把教学内容转化为高颜值、强交互的HTML网页课件。任务：请为以下课题生成一个交互式课堂测验网页。课题信息： - 学科：[填写学科] - 年级：[填写年级] - 课题：[填写课题名称] - 题目数量：[X]道 题目要求： 1. 题型：[选择题/判断题/填空题/混合] 2. 难度：[基础/中等/较难/梯度分布] 3. 覆盖范围：[列出需要考察的知识点] 功能要求： 1. 每道题有A、B、C、D四个选项（选择题）或填写框（填空题） 2. 点击选项后高亮显示选中状态 3. 点击"提交答案"按钮后： - 显示正确答案（绿色高亮） - 显示用户选择（错误的红色标记） - 显示详细解析 4. 底部显示总分统计：答对X题/共X题，正确率XX% 5. 全部答完后显示"再做一次"按钮 样式要求： 1. 整体风格：简洁清新，适合教学场景 2. 配色：主色调[蓝色/绿色/紫色/橙色]，背景浅色 3. 字体：中文用微软雅黑，英文用系统默认 4. 间距：题目之间适当留白，不要太拥挤 5. 响应式：支持手机和电脑查看 输出要求： 1. 生成一个完整的HTML文件，所有代码（HTML+CSS+JavaScript）都在一个文件内 2. 不依赖外部资源（图片、字体、CDN） 3. 代码有注释，方便后续修改 4. 直接保存为 [课题名称]_测验.html。

**完整用法：**① 打开 WorkBuddy，选 Craft 模式（可直接生成文件）；② 输入指令；③ 等 AI 自动编写 HTML，含题目、选项、提交按钮、答案判断、分数统计；④ 浏览器预览，不满意直接让 AI 改；⑤ 导出 HTML，发班级群或嵌入学习平台。

**同一篇文章另有两套可换用：**知识配对类（左列概念、右列解释打乱，配对正确连线变绿、错误变红抖动）与互动演示类（拖拽/输入/点击改参数触发动画），模板结构相同，改成 [课题名称]_配对.html 或 _演示.html 即可。

三条使用建议：题目自己过一遍（发学生前先自己做）；保存好源文件（换题只改内容）；先在一个班小范围试用。
