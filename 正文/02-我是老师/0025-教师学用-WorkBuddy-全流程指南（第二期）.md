# 教师学用 WorkBuddy 全流程指南（第二期）
第二期：装好技能再备课——3步安装+场景速查+全程案例。

## 教师AI暑期提升计划 · 第2期。
第一期我们学了怎么给 WorkBuddy 下指令，但有老师试了发现“让它写教案”效果一般。问题不在你——在于没装技能。技能（Skill）就是 WorkBuddy 的“App”，装上它才能真正干活。本期先装技能，再用备课4步法搞一堂真课出来。

认知篇先接第一期。

第一期我们学会了：装 WorkBuddy → 发第一句话 → 传文件 → 5场景速查。有老师后台问：“我让它写教案，它写得不够好”——那是因为你没装技能。

WorkBuddy 像一部智能手机，技能就是各种 App。出厂时它能干的事有限，装了对口的技能，它才能读 Word、搜资料、做PPT、分析成绩单。

操作篇3步装好第一个技能。第一步：打开技能市场——打开 WorkBuddy，左侧菜单找到「专家/技能」入口，点击进入技能市场。第二步：搜索技能——点击「添加技能」→「查找技能」，搜索框输入技能名称（比如 "docx"）。第三步：点击安装——找到目标技能，点「安装」，十几秒完成，装完即用。

装好后不需要专门“打开”——直接说你想做什么就行。上传一个 Word 文件说“帮我总结重点”，WorkBuddy 会自动调用 docx 技能处理。

操作篇装了能做什么——按场景速查。不用全装，按你马上要做的场景选：教学场景。装什么。搜索关键词。备课写教案。办公文档 + 网页搜索。docx + baidu-search。批改/成绩分析。表格处理。xlsx。做课件配图。PPT + 图片生成。

pptx + 搜索image。录课转文字。语音转录。openai-whisper。最低配置：先装 docx + baidu-search + pptx，这三个就能走完备课流程。操作篇教师刚入手最常见的3个疑问。

❓ Q1：我怎么知道装了什么技能。打开 WorkBuddy → 左侧「专家/技能」列表，有图标的就是已装好的。默认只有几个，大部分需要你去市场装。

❓ Q2：装了但感觉没变化。技能是“后台能力”不是“界面改变”。装好 docx 后，发一个 Word 给它说“总结重点”，它就能读——这才是变化。

## ❓ Q3：到底要先装哪几个。
先装办公文档四件套（docx/xlsx/pptx/pdf）+ 网页搜索（baidu-search），覆盖备课80%。其他以后遇到再说。

价值篇备课操作——装好技能后，你得到什么。

技能装好了，下面4步走一遍。不需要你一句一句教AI——每步一条指令，AI自动输出结果。你看到这些结果，就说明技能装成功了。

## 第一步：传素材——AI读教材，自动提炼重点。
上传教材文件，说：我是三年级语文老师，这是《荷花》课文，帮我分析教学重点和难点。

✅ 技能装好的标志：AI不是回一段"好的，我分析了"而是直接给出具体分析——  "教学重点：理解荷花形态描写，体会拟人手法。教学难点：三年级学生对象征意义理解有限，需要画面辅助。"。

## 第二步：定目标——AI联网搜课标，出三维目标。
帮我搜2022版语文课标对三下第一单元的要求，结合学情出三维教学目标。

✅ 技能装好的标志：AI自动联网搜索（baidu-search技能），搜索结果带来源，产出"知识技能/过程方法/情感态度"三维目标，每一条都是可检测的——不是"了解"而是"能说出""能举例"。

## 第三步：出框架——AI搭教学环节骨架。
根据目标和学情，出《荷花》第一课时教案框架：导入→新授→练习→小结，每个环节写清楚教师活动、学生活动、设计意图、时间。

✅ 技能装好的标志：AI直接产出完整结构，不是一段话而是分环节的表格/清单——每个环节有时间分配、有师生活动、有意图说明。如果AI输出的是笼统的一段话，说明文档技能（docx）可能没装好。

## 第四步：磨细节——AI出板书+提问+PPT大纲。
根据上面的框架，出板书设计、3个核心提问和6页PPT大纲。要求：提问层层递进，不用"是不是/对不对"；PPT每页不超过3个要点。

✅ 技能装好的标志：AI输出的板书是一句话+关键词结构（不是大段文字），PPT大纲是分页的（不是笼统一段），提问有三个层次（理解→分析→评价）。

✅ 结果验证：这4步走下来，教案框架已经成型。如果每一步AI输出的都是"具体结果"而不是"笼统回应"——说明你的技能装好了，可以正常用了。

价值篇各学科通用——换教材名就行。上面是以语文《荷花》为例。其他学科改一下教材名和年级，指令不用变：学科。教材。改哪里。AI产出亮点。语文。《荷花》（三年级）。换课文名。分析修辞手法+朗读指导+仿写拓展。数学。《分数初步认识》（四年级）。换单元名。

生活情境导入+3道递进练习+教具建议。英语。《My Day》（五年级）。换话题。重点句型操练+情境对话+分组活动。科学。《植物的生长》（三年级）。换课题。实验步骤拆解+观察记录表+拓展探究。资源包里已备好语数英三科的完整指令模板，复制后换教材名即可。

价值篇在资源包里——我们附了一份「备课技能」代码。

以上4步的指令模板 + 安装指引 + 一份备课4步法 Skill 配置代码（YAML格式），都做进了资源包。把代码导入后，以后说"开始备课"就能自动走完这4步。

行动篇后台回复「备课」领取资源包。
