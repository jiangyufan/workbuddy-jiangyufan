# 教师学用 WorkBuddy 全流程指南（第三期）
第三期：把备课4步法变成一个“一劳永逸”的技能——教你自己写一个"备课专家"。

## 教师AI暑期提升计划 · 第3期。
第二期我们学了装技能+备课4步法，但每次备课还是要手动输入4条指令。能不能一句话搞定。可以——把备课4步法打包成一个 Skill，以后说"备课"自动走。本期就教你怎么做。

认知篇先接第二期。第二期我们做了两件事：装好技能：docx + baidu-search + pptx。备课4步法：传素材→定目标→出框架→磨细节。

但有老师反馈：“如何保存成YAML文件”，“技能导入需要zip或者skill.md，YAML文件能不能使用”，我的回答是：能。WorkBuddy 能够通过文件自定义 Skill——把一系列指令打包成一个命令。这一期手把手教你解决这些问题。

本期教你把备课4步法打包成Skill，导入 WorkBuddy 后一劳永逸。操作篇3 步把 Skill 导入 WorkBuddy。

第 1 步：获取 YAML 文件 打开上期所获得的文档 → 找到“备课”Skill，复制下方 YAML 代码。

（还没获得文档的老师记得后台私信“备课”获取哦）。

第 2 步：用记事本保存为 .yaml 文件 ① 打开电脑上的「记事本」→ 粘贴刚才复制的代码 ② 另存为 → 保存类型选为“所有文件”→重命名为「xxx.yaml」（例如 bei-ke.yaml）。

关键：保存类型选「所有文件」，编码选 UTF-8 如果保存后图标还是记事本样子，说明后缀没改对——检查文件名是否真的以 .yaml 结尾。

第 3 步：导入 WorkBuddy 打开 WorkBuddy → 选择刚才保存的 .yaml 文件→ 拖动到聊天工作区 → 输入指令「导入技能」→ 确认发送。

第 4 步：说关键词触发 导入完成后，在对话框里输入对应的关键词——「备课」「改作业」「写通知」「学情分析」——就会自动触发对应的 Skill 流程。以后不用手动一步步下指令了。

转成 .md 格式：在记事本中打开 .yaml 文件 → 复制全部内容 → 粘贴到新记事本 → 保存为「备课4步法.md」（与上面是同样的方式，md格式是纯文本说明，对方用记事本就能打开看）。

转成 .yaml（给同事直接导入）：同事拿到 .yaml 文件后，打开WorkBuddy→导入技能→选择文件即可，不需要重新复制代码。

打包成 zip：把所有 .md 或 .yaml 文件放进一个文件夹 → 右键 → 发送到 → 压缩文件夹 → 生成 .zip → 发给同事。

价值篇YAML 配置拆解——你也能自己改。

- 触发条件（trigger）

trigger: keywords: - 备课 - 教学设计 - 教案 - 教学方案。老师说这些词时，Skill 自动触发。你可以改成"写教案""做教学设计"等。

- 4 个步骤（steps）

steps: - name: 传素材+定目标 tools: [docx, baidu-search] - name: 出教案框架 - name: 磨提问+板书 - name: 出PPT大纲 tools: [pptx]。

每个 step 是一个环节。你可以改 name、调顺序、加 tools。

- 输出格式（output）

output: format: markdown sections: [教学目标, 教案框架, 板书提问, PPT大纲]。

AI 会自动按这4个板块输出。你可以改成 [学情分析, 目标, 过程, 评价]。价值篇更多自定义场景——你也可以自己做。不只是备课。用同样的方法，给自己做更多 Skill：场景。触发词建议。4 个步骤建议。改作业。改作业 / 批改。

- 上传作业→②标出错题→③写评语→④统计成绩

写通知。写通知 / 家长通知。

- 定场景→②写草稿→③调语气→④定稿

学情分析。学情 / 复盘。

- 上传数据→②出统计→③归因分析→④分层建议

方法：复制 YAML 模板 → 改 trigger 关键词 → 改 steps 名称 → 保存为新的 .yaml → 导入 WorkBuddy。5 分钟搞定一个。

合规篇用之前过一眼。

## YAML 是纯文本配置文件，不会修改你的系统、不会泄露数据。
Skill 只是"指令打包"，AI 执行时仍需遵守原有的数据安全规范。自定义 Skill 别人看不到——只有你导入的那个账号能用。行动篇后台回复领取 Skill 配置。一共4个 Skill，panda老师也给你们做好了，后台私信“skill”或者“技能”可以领取哦：

关键词。Skill 名称。能干什么。备课。备课4步法·全学科版。传素材→定目标→出框架→磨细节。改作业·教师版。上传作业→标错题→写评语→统计成绩。写通知·教师版。定场景→写草稿→调语气→出定稿。学情分析·教师版。上传成绩→出统计→归因分析→分层建议。
