# 学生知识点讲解：拍照上传，要文字讲解 + 视频 + 同类题
**适用：一道题或一个知识点讲不明白，需要"适合孩子理解"的通俗讲解。**

**可复制提示词（输入时尽量说清楚学科年级、题目目标、讲解深度、想要的结果）：**

**操作步骤（四步流程：搜专家 → 传题目 → 出讲解 → 看视频）**。

找对专家——用学科关键词搜，看专家定位与标签是否匹配（如"初中数学专家：几何/代数/解题思路"）；

上传题目——拍照或截图，补一句需求，指定讲解方式（文字/视频等）；

等待交付——AI 识别题目、分析思路、生成文字讲解与讲解视频；

反复复习——跟着视频看、暂停回看、巩固错题。

**交付结果：**不只回一句答案，而是整理后交付——题目讲解视频（.mp4）、文字讲解与要点归纳（.md，含详细解题过程、关键知识点总结、不同解法对比、易错点提示）。

**看结果时优先检查：**讲解结构是否清楚、是否适合孩子理解。

另一条路径（上传试题入库 + 提问考点）：

告诉我这道题考察什么知识点，解题思考步骤是什么。

AI 会输出考点（如含参一元一次方程的解法、含参方程思想、由"解的性质"建立不等式、解一元一次不等式）和分步思考步骤。

知识点追问（互动智能体引导范式）：引导学生用乘法验证、说出自己怎么算的、错误归因，如"你能告诉我你是怎么计算的吗。你用了什么方法。"——这套"引导思考型/逻辑推理引导型/元认知引导型/错误分析引导型"话术示例可作教学参考。

**要点：**这套流程数学题讲解、英语阅读与语法、作文批改思路、错题复盘复习都适用。 家长使用建议：先从简单题开始，先跑通一次完整流程；把需求拆小，一次先解决一道题；结果要一起检查（家长看讲解是否清楚，孩子看自己是否真正听懂）。
