# WorkBuddy 教师工作台创建快速入门：把课程表、调课、公开课一站式装进工作
各位老师好。今天带你用 WorkBuddy 的资料库能力，搭一个专属于你的"教师工作台"。课程表、调课、公开课、教学日历、班级进度、每周复盘，全在一个页面里，云端同步、断网也能用。10 分钟建好，直接能用。

说明：本教程以一份真实生成的「教师办公工作台」为例（正是用 WorkBuddy 资料库能力搭建、存储和部署的网页应用），文中功能均来自该工作台实际模块，照着做即可。

## 一、WorkBuddy 教师工作台是什么。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/v4jwg7v2wPpq735vsEfAHGU6AS6cjmq7ibicy9nkYoSgw8qzflcicjS4AImLTwGZMb7k3GdUg4iagzzvibQ88PwicSy8icX8lXVsjnEn24jjJHcSaw/640?wx_fmt=png&amp;from=appmsg#imgIndex=0)

一句话：它是用 WorkBuddy「资料库」能力生成的一块网页版教师办公中枢，无需写代码，打开就能用。

它把你平时散落在纸面、微信群、备忘录里的教务琐事，集中到一个工作台里。核心模块有 9 个：模块。用来做什么。今天要处理。总览今日待办、调课、公开课等关键信息。今天待办。随手记任务，支持优先级与逾期提醒。灵感速记。课上冒出的点子、素材，随时记下来。

班级进度。跟踪每个班讲到哪一课、哪一节。每周复盘。周末花 5 分钟回顾本周教学。教学日历。整学期校历，关键日可加备注。课程表。本学期课表，单元格可编辑。调课记录。记录每一次调课，留痕可追溯。公开课 / 培训。公开课、听课、培训一站式存档，评优有据。

数据备份。一键导出 / 导入，云端 + 本地双保险。它的价值就三点：一处记录：课程、调课、公开课不再分散在五个地方；云端同步 + 本地离线双模式：联网自动存云端，没网也能用，联网后自动同步；复盘有据：期末评优、职称材料，调课和公开课记录直接导出当佐证。

## 二、实战：10 分钟搭好并跑通你的工作台。
我们用一个真实场景串起来：你是信息科技 + 科学老师，这学期带 12 个班，先用工作台把课程表排好，再记一次调课和一节公开课。

步骤 1：创建工作区。

在 WorkBuddy 中调用资料库能力，新建一个工作台空间，把工作台页面生成并部署好。生成后你就拥有了一个网页应用——顶部会显示同步状态（本地模式 / 同步中 / 已同步 / 离线），数据自动保存到云端，同时支持本地离线打开。

步骤 2：认识九大模块。

进工作台后，左侧是一列导航：今天要处理、今天待办、灵感速记、班级进度、每周复盘、教学日历、课程表、调课记录、公开课/培训、数据备份。点哪个，右侧就切到对应视图。先用"今天要处理"当首页总览。

步骤 3：基础配置——先把课程表排起来。这是让工作台"活"起来的第一步。进入课程表视图，系统已预填示例（信息科技 9 个班 + 科学 3 个班）；点击任意单元格就能编辑：填"科目 + 班级"，比如「信息科技 / 六(3)班」；首列「节次 / 时间」也可点右侧按钮修改，对齐你学校的实际作息；

如果预填的不合心意，可一键清空整张课表重新排；卡片标题会实时显示「已排 N 节」，随时掌握排课进度。步骤 4：记录一次调课。调课最怕忘、最怕说不清。在工作台里：进入调课记录 → 点「新增调课」；选择原课时和新课时（都可选周次，支持跨周调课，比如把第 3 周周三第 5 节调到周五第 5 节）；

填原因：公开课 / 教研活动 / 设备问题等；保存后自动进入「调课历史」，以后查哪天调过课，一目了然。步骤 5：顺手记好公开课与教学日历。

公开课 / 培训：选类型（公开课 / 培训 / 比赛评委 / 其他），填主题、日期、地点或形式、收获备注。例如「六上《光的折射》校级公开课，2026-10-15，录播室，用希沃动画突破折射难点，获评优」。学期末汇总评优材料时，这里就是现成的佐证库。

教学日历：整张 2026–2027 学年第一学期校历已铺好，点任意日期可加备注，如「教研组活动 / 公开课 / 学生请假」，重要日子不漏。

步骤 6：数据备份与同步。

顶部看同步状态：绿色「已同步」说明云端已存；黄色「同步中」正在上传；橙色「离线」则是本地模式，断网也能继续用。

进入数据备份视图，可一键导出备份（存成文件），也能导入恢复。建议期末或换设备前导一份，多一层保险。到这里，你的教师工作台就完整跑通了——建空间、排课表、记调课、存公开课、会备份。

## 三、要点小结。
把上面浓缩成三句话：先排课程表，工作台就"活"了——这是使用频率最高的模块，先填它；调课、公开课随手记，期末不抓瞎——平时多记一笔，材料季直接导出；云端 + 离线双模式，断网也能用——记得定期导出备份，数据更稳。

## 四、接下来可以探索的功能。
工作台跑顺后，这几块值得慢慢打开：班级进度：每个班讲到哪课哪节，一眼掌握，避免两个班进度错位；每周复盘：周末 5 分钟回顾，沉淀本周得失；灵感速记：课上灵光一现的点子，立刻记下不丢；多学期 / 多工作台：换学期时新建空间，旧数据保留可回溯；

待办优先级：给任务标 P0/P1/P2，重要的事永远在最上面。

基础版（生成上面那套 9 大模块）：

帮我用 WorkBuddy 的资料库能力，生成一个「教师办公工作台」单文件网页应用 （纯 HTML/CSS/JS，无需后端，数据用浏览器本地存储）。功能模块（左侧导航切换）： 1. 今天要处理：总览今日待办、近期调课、近期公开课 2. 今天待办：可增删改任务，支持优先级 P0/P1/P2 与逾期标记 3. 灵感速记：随手记录教学点子 4. 班级进度：按班级记录教学进度（第几课 / 第几节） 5. 每周复盘：周复盘笔记 6. 教学日历：学期校历，日期可加备注 7. 课程表：可点击单元格编辑（科目+班级），首列节次/时间可改， 可清空重排，显示已排节数 8. 调课记录：新增调课（原课时/新课时可选周次，支持跨周），填原因，保留历史 9. 公开课 / 培训：记录类型（公开课/培训/比赛评委/其他）、主题、日期、地点、收获 10. 数据备份：一键导出 JSON / 导入恢复 视觉：紫色主色 #7c5cff + 粉色点缀 #e879b9，卡片化布局， 左侧边栏 + 右侧内容区，响应式。请直接输出完整可用的 HTML 文件。

进阶版（加上云端同步与多学期）：

在上面的基础上，再增加： - 顶部同步状态指示（本地模式 / 同步中 / 已同步 / 离线） - 云端同步 + 本地离线双模式（数据自动保存，断网也能用） - 多学期切换（新建 / 切换空间，旧数据保留） - 公开课记录可一键导出为评优佐证表 请输出完整 HTML 文件。

怎么用：复制上面任一段提示词；发给 WorkBuddy，让它生成 HTML；用 WorkBuddy 的资料库能力把页面部署成可打开的网页；打开即用，之后按本文第二、三节的方法排课表、记调课。

提示词里的模块、配色、字段都可以按你的学科和习惯改——比如把"公开课 / 培训"换成"社团活动"，或把主色改成学校主题色。
