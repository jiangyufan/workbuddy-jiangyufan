# 学生论文阅读：文献初筛 + 结构化综述表
**适用：面对几十上百篇文献，先让 AI 初筛，再聚焦核心资料深读。**

场景化用法一（学生自述）：先建"论文创作库"，上传收集的文献，同时把学校给的《毕业论文格式模板》《参考文献规范》一起传进去；写论文时 ima 直接从库中提取相关文献，帮着整理出国内外研究现状，甚至自动标注文献来源，点一下就能打开原文核对。4 用 AI 做"创作助手"而非"代笔"：先输入简单提纲，再输入"/"唤起 AI，让它扩写、整理公式、生成思维导图，自己再补充思考。

场景化用法二（提炼核心资料）：把论文库交给 AI 初筛，直接说——。

我的论文与合金冶炼方面有关，帮我筛选出核心资料。

AI 会按重要性排序并标注关键信息（如核心内容要点）。

**可复制提示词（生成综述表）——ima 2.0 的实测指令原文：**

检索知识库中关于"RAG技术优化"的44篇论文，并生成一个包含"方法、数据集、核心结论"的综述表格。

**自动拆解五步：**①文献检索 → ②分类整理 → ③要点提取 → ④综述撰写 → ⑤图表生成。

**底层流程：**对每篇论文循环执行——PDF 读取单篇内容 → 定位"Methodology""Experiments""Conclusion"等关键章节 → 分别提取"方法""数据集""核心结论" → 汇总整合成 Markdown 表格。

**实测效果：综述撰写从 2 周缩短到 2 天，文献覆盖率提升 300%，自动生成 3 类可视化图表。**

通用阅读提示词（六步精读法，可复制）：

你是一名资深的文案阅读专家，请基于以下6个步骤来精读一篇文章。我将上传一篇文章给你，是《XXXXXX》。1.初步分析：请对文章进行初步分析，提供关键词列表和文章结构概览。2.深度解析：深入分析文章内容，总结每个主要段落或章节的核心内容，并阐述作者的主要论点。3.概念澄清：请解释文章中的[具体概念或观点]，并提供相关的背景信息。4.批判性分析：请评估文章中的主要论点，分析其有效性，并提出可能的反驳意见。5.知识应用：请提供将文章中的核心观点应用到实际情况的具体建议和例子。6.总结反思：请综合前面的分析，生成一个简洁而全面的文章总结，包括主要观点、批判性思考结果和应用建议。
