# 用WorkBuddy制作html交互式课件，离线可用（文末附提示词）
PPT做了20年，还是那个套路：放文字、插图片、加动画。学生看两页就走神，互动全靠点名提问。

今天换个思路——用AI直接生成交互式HTML网页课件。学生能在页面上点击、拖拽、输入、即时反馈，比PPT强太多。

## 1. 真正的交互，不是假动画
PPT的动画是"播放"，点一下跳一页。HTML交互是"操作"——学生可以拖拽元素、填写答案、点击按钮触发反馈，是真正的参与感。

## 2. 即时反馈，不用等老师批改
选择题点完立刻显示对错，填空题提交立刻显示答案，判断题做完立刻给出解析。学生做完就知道自己会不会。

## 3. 数据自动记录
学生答了几道题、对了几道、错在哪，网页后台自动统计。老师打开就能看到全班学情，不用再手动批改登记。

## 4. 一个链接，随时随地看
生成的是网页，发到班级群、嵌入学习平台、手机电脑都能打开。不用装软件，不用转格式。

## 5. AI一分钟生成
以前做PPT要半天，现在告诉AI你要什么内容，一分钟出成品。改起来也快，说一句话就重新生成。

场景很多，举几个教师常用的：

**课堂测验：**选择题、判断题、填空题，提交立刻显示答案和解析

**知识配对：**把左边的概念和右边的定义拖拽配对，全部正确才能提交

## 排序题：把打乱的历史事件、操作步骤拖拽排序
**互动图表：**点击不同选项显示不同数据，比如点击不同朝代显示对应地图

**模拟实验：**调节参数看结果变化，比如调节电压看电流变化

## 闯关游戏：答对一题解锁下一题，最后统计总分
1. 打开WorkBuddy，选择Craft模式。

Craft模式可以直接生成文件，适合"出成品"的任务。或者召唤对应的专家。

告诉AI你要什么内容，比如：

"帮我生成一个小学数学《观察简单几何体》的交互式动画，左边显示视角和网格数量，右边实时显示3D立体视角。"。

AI会自动编写HTML代码，包含题目、选项、提交按钮、答案判断、分数统计，全套交互逻辑。

## 4. 预览和修改
生成后直接在浏览器预览，看看题目对不对、样式好不好看。不满意直接告诉AI修改。

确认后导出HTML文件，发到班级群或嵌入学习平台即可。

以下是可直接复制使用的提示词，把方括号里的内容换成你自己的课题即可。

## 课堂测验类课件提示词

## 知识配对类课件提示词

## 互动演示类课件提示词

[具体交互方式] 2. [具体反馈形式] 3. [具体展示效果] 样式要求： 1. 整体风格：简洁清新，适合教学场景 2. 动画流畅，不要卡顿 3. 有文字说明，解释每个操作的含义 4. 响应式：支持手机和电脑查看 输出要求： 1. 生成一个完整的HTML文件，所有代码都在一个文件内 2. 不依赖外部资源 3. 直接保存为 [课题名称]_演示.html。

把上面任意一段提示词复制到WorkBuddy，把方括号里的内容换成你的课题，等1分钟就能拿到成品。

保存好源文件。HTML文件可以直接修改，下次换题目只需要改内容，不用重新生成。
