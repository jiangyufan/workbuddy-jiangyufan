# 从零把 WorkBuddy 用起来

这是一份阅读路线，不是软件说明书。完整的步骤、截图和后面的案例，放在网站上，打开就能看。站上有免费内容。

**在线阅读：[workbuddy.jiangyufan.com](https://workbuddy.jiangyufan.com/)**

## 第一次用，按这四步

1. 先看它能帮你干什么，再决定要不要往下装。
2. 按你的电脑系统装好，把主界面五个区域认一遍。
3. 用 15 分钟跑通一个真任务，看到一个实际结果。
4. 记住一条把话说清楚的写法。任务、材料、你要的结果，这三样写全，后面就稳很多。

逐步截图在这里：[闯关 · 从第 1 节开始](https://workbuddy.jiangyufan.com/index/camp)

闯关按五段往下排：零基础入门、进阶、提升、精通、实战，一共 76 节。学完当前一节，下一节马上打开。实战段是一条内容流水线，从选题、脚本、封面，到多平台改写和知识库沉淀。

## 三条现成路线

- **刚装好**：闯关前 18 节。装好、认出界面、跑通第一个任务。
- **要出内容**：闯关实战段，配合案例集里的内容创作和视频。
- **要接到现有软件**：工具包里的接入和配置，需要现成指令时再打开提示词。
